## 一、实训项目简介

本项目带领大家从零构建一个**企业级多模态多智能体（Multi-Agent）农业 AI 助手**：

- 用户可以用**文字提问**（施肥、灌溉、产量、补贴）；
- 可以**拍照上传**，由视觉模型诊断作物病害；
- 系统通过 **LLM 意图路由**自动把问题分发给不同专家 Agent；
- 补贴政策回答走 **RAG 检索增强**，保证不编造；
- 最终交付一个 **React 前端 + FastAPI 后端 + Redis + Docker** 的完整系统。

通过本项目，你将掌握当前 AI 应用工程师岗位的核心技能栈：

| 技能域 | 具体内容 |
|--------|----------|
| 大模型应用开发 | Prompt 工程、结构化输出、多模态调用、重试与降级 |
| Agent 架构 | 意图路由、专家 Agent 编排、并行执行、职责边界设计 |
| RAG | 向量库（FAISS）、嵌入模型、检索-生成链路、幻觉护栏 |
| 工程化 | FastAPI 分层架构、配置中心、日志、指标、Token 成本核算 |
| 前端 | React + TypeScript + Tailwind + Zustand + Axios |
| DevOps | pytest、Docker、docker-compose、云部署 |

## 四、实训开展方式（企业级流程）

每次实训按以下企业研发流程执行：

```
任务书阅读 → 分支开发（git checkout -b labXX）→ 编码实现
→ 自测验收（对照"验收标准"逐条勾选）→ 代码提交 → 教师评审
```

**编码规范要求（贯穿全程）：**

1. 目录分层严格遵循 `routes → agents → services → core` 单向依赖；
2. 所有外部配置（Key、模型名、阈值）进 `core/config.py` 或环境变量，禁止硬编码；
3. 提示词统一放 `prompts/prompts.yaml`，通过 `get_prompt()` 读取，禁止散落在代码里；
4. 任何 LLM/外部 API 调用必须有：超时或重试、失败降级文案；
5. 函数写清 docstring；错误处理不吞异常但不对用户暴露堆栈。

## 七、常见问题（FAQ）

**Q1：Python 版本装了 3.14 怎么办？**
`sentencepiece` 等依赖没有 3.14 轮子，请改装 3.11/3.12，并为项目单独建虚拟环境。

**Q2：Groq Key 从哪里来？**
注册 [console.groq.com](https://console.groq.com) → API Keys → 创建。免费额度足够完成全部实训。

**Q3：提示词里的 `{xxx}` 和 `{{xxx}}` 有什么区别？**
`{query}` 是模板变量（会被替换）；`{{ }}` 是转义后的字面量大括号（用于输出 JSON 示例）。

**Q4：Windows 下命令报错 `&&` 无效？**
PowerShell 用分号 `;` 分隔命令，本指导书的命令均按 PowerShell 编写。
