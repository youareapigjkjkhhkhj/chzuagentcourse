## 一、认识项目：AgriGPT 是什么

AgriGPT 是一个**多模态、多智能体（Multi-Agent）农业 AI 助手**。与"一个大模型回答所有问题"的普通聊天机器人不同，它把问题拆解后交给不同的"专家 Agent"：

| Agent | 职责 | 关键约束 |
|-------|------|----------|
| MasterAgent | 意图理解、路由调度、结果合成 | 单请求最多调度 3 个专家 |
| CropAgent | 种植、施肥、土壤 | 禁止诊断病虫害 |
| PestAgent | 病虫害诊断（图片优先） | 只描述可见症状，不臆测 |
| IrrigationAgent | 灌溉与水分管理 | 禁止推荐化学品 |
| YieldAgent | 产量分析与限制因素 | 禁止承诺具体产量数字 |
| SubsidyAgent | 补贴政策（RAG 检索增强） | 只能引用检索到的政策 |
| FormatterAgent | 最终排版输出 | 不做新推理，零幻觉面 |

一次典型请求的流转：

```
用户提问 → /ask/chat 接口 → MasterAgent 读取会话记忆
→ LLM 意图路由打分 → 并行执行选中的专家 Agent
→ FormatterAgent 合成 Markdown → 写回记忆与日志 → 返回前端
```

### 技术栈速览

| 端 | 技术 |
|----|------|
| 后端 | Python 3.11+、FastAPI、LangChain、Groq（Llama 3.3 70B / Llama 4 Scout）、FAISS、Redis |
| 前端 | React 18、TypeScript、Vite、Tailwind、shadcn/ui、Zustand、Axios |
| 交付 | pytest、Docker、docker-compose、Nginx |

## 二、安装基础工具链

### 步骤 1：安装 Python 3.11 或 3.12

到 [python.org](https://www.python.org/downloads/) 下载安装，**安装时勾选 "Add python.exe to PATH"**。

> ⚠️ 不要使用 Python 3.13/3.14：`sentencepiece` 等依赖尚无对应轮子，后续实训会安装失败。

验证（PowerShell）：

```powershell
python --version     # 应输出 Python 3.11.x 或 3.12.x
```

### 步骤 2：安装 Node.js ≥ 20

到 [nodejs.org](https://nodejs.org/) 下载 LTS 版，验证：

```powershell
node --version       # v20.x 以上
npm --version
```

### 步骤 3：安装 Git 与 VS Code

- Git：[git-scm.com](https://git-scm.com/)，验证 `git --version`；
- VS Code：安装插件 **Python**、**ESLint**、**Tailwind CSS IntelliSense**。

## 三、初始化项目工程

### 步骤 4：创建企业级目录结构

在你的工作盘创建项目根目录（示例用 `agrigpt`），并建立如下骨架——这就是贯穿全部实训的工程结构：

```
agrigpt/
├── backend/               # 后端（Python 包）
│   ├── agents/            # 多 Agent 系统
│   ├── core/              # 配置/提示词/记忆/护栏等横切能力
│   ├── routes/            # HTTP 接口层
│   ├── services/          # LLM/RAG/日志等服务层
│   ├── prompts/           # 提示词库（YAML 版本化）
│   ├── data/              # 运行数据（补贴库/日志/向量库）
│   ├── tests/             # 自动化测试
│   ├── main.py            # 应用入口
│   ├── requirements.txt   # 依赖清单
│   └── env.example        # 环境变量模板
├── frontend/              # 前端（实训10 再创建）
└── .gitignore
```

```powershell
mkdir agrigpt; cd agrigpt
mkdir backend\agents, backend\core, backend\routes, backend\services, backend\prompts, backend\data, backend\tests
git init
```

### 步骤 5：编写 `.gitignore`（企业红线：密钥不入库）

在 `agrigpt/.gitignore` 中写入：

```gitignore
# Python
__pycache__/
*.pyc
.venv/
venv/

# 密钥与本地配置（严禁提交！）
.env
backend/data/faiss_index/
backend/data/query_log.json
backend/data/feedback_log.json

# 前端
frontend/node_modules/
frontend/dist/

# IDE
.vscode/
.idea/
```

> **企业规范**：任何 API Key 只允许出现在 `.env` 中；`.env` 永远不进版本库，团队共享的是 `env.example` 模板。

## 四、搭建 Python 虚拟环境

### 步骤 6：创建并激活虚拟环境

```powershell
cd agrigpt
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> 若报"禁止运行脚本"，先执行一次：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
> 激活成功后命令行前会出现 `(.venv)` 前缀。以后每次开新终端都要先激活。

### 步骤 7：编写 `requirements.txt`

创建 `backend/requirements.txt`（这是全量依赖，后续实训都会用到）：

```text
fastapi
uvicorn
groq
pydantic
requests
langchain
langchain-community
langchain-core
langchain-groq
langsmith
# sentence-transformers needs sentencepiece; Python 3.11/3.12 required
sentencepiece>=0.2.0
sentence-transformers>=2.2.0
faiss-cpu
numpy
python-multipart
pydantic-settings
pyyaml
pinecone-client
langchain-pinecone
redis>=5.0.0
# Tests
pytest>=7.0.0
httpx>=0.24.0
```

### 步骤 8：安装依赖

```powershell
pip install -r backend\requirements.txt
```

> 该步骤会下载 PyTorch 等大包（约 2GB），耗时 10~30 分钟属正常现象。
> 国内网络可加镜像源：`pip install -r backend\requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

验证核心包：

```powershell
python -c "import fastapi, uvicorn, langchain; print('OK')"
```

## 五、获取并配置 Groq API Key

### 步骤 9：注册并创建 Key

1. 打开 [console.groq.com](https://console.groq.com) 注册账号；
2. 左侧 **API Keys → Create API Key**，复制保存（只显示一次）。

本项目使用两个模型（后续在配置中心声明）：

| 用途 | 模型 |
|------|------|
| 文本生成/路由 | `llama-3.3-70b-versatile` |
| 图片诊断（视觉） | `meta-llama/llama-4-scout-17b-16e-instruct` |

### 步骤 10：创建环境变量模板 `env.example`

创建 `backend/env.example`（这是可以提交入库的**模板**）：

```dotenv
# AgriGPT Environment Variables
# Copy this file to .env and fill in your values

# Required for LLM (text + vision)
GROQ_API_KEY=your_groq_api_key

# Optional – Weather in header
OPENWEATHER_API_KEY=your_openweather_api_key

# LangSmith tracing (optional)
LANGCHAIN_TRACING_V2=true
LANGSMITH_API_KEY=lsv2_pt_your_langsmith_key
LANGCHAIN_PROJECT=agrigpt

# Pinecone for RAG (falls back to FAISS if unset)
PINECONE_API_KEY=your_pinecone_api_key
PINECONE_INDEX_NAME=agrigpt-subsidies

# Redis for persistent chat memory (falls back to in-memory if unset)
REDIS_URL=redis://localhost:6379/0
```

然后复制出真正使用的 `.env`（**不入库**），填入真实 Key：

```powershell
cd backend
copy env.example .env
notepad .env     # 把 GROQ_API_KEY 改成你的真实 Key，其余可先不动
```

## 七、常见问题排查

| 现象 | 原因与解决 |
|------|-----------|
| `pip install` 卡在 `sentencepiece` | Python 版本过新；改装 3.11/3.12 重建虚拟环境 |
| 激活脚本被安全策略拦截 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `git status` 出现 `.env` | `.gitignore` 未生效——确认文件在项目根目录且无拼写错误 |
| 下载超时 | 换清华/阿里镜像源（见步骤 8） |
