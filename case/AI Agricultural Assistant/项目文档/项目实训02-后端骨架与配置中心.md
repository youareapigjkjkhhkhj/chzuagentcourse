## 一、知识点

### 1. 企业级 FastAPI 分层

```
routes/   → 只做协议适配：参数校验、状态码、调用编排层
agents/   → 业务编排与领域逻辑
services/ → 原子能力（LLM 调用、存储、外部 API）
core/     → 横切能力（配置、提示词、记忆、护栏）
```

依赖方向**自上而下单向**，`core/` 不依赖业务层。

### 2. 配置中心（Configuration Center）

企业项目禁止在代码里散落 API Key、模型名、阈值。统一做法：

- 所有可变项声明为 `Settings` 类字段（带默认值）；
- `pydantic-settings` 自动从 `.env` 与环境变量读取，**环境变量优先**（便于容器部署时注入）；
- 全局单例 `settings`，业务代码只 `from backend.core.config import settings`。

### 3. 包导入约定

所有代码使用**绝对包导入**：`from backend.core.config import settings`。
因此运行时必须站在 `backend` 的**父目录**：`uvicorn backend.main:app --reload`。

### 步骤 2：实现配置中心 `backend/core/config.py`

```python
from pydantic_settings import BaseSettings, SettingsConfigDict
from pathlib import Path

# Absolute path to backend/ - ensures .env is found regardless of cwd
_BASE = Path(__file__).resolve().parent.parent
_ENV_FILE = (_BASE / ".env").resolve()

class Settings(BaseSettings):
    """
    Safe configuration loader for all environment variables.
    """
    GROQ_API_KEY: str = ""
    OPENWEATHER_API_KEY: str = ""
    TEXT_MODEL_NAME: str = "llama-3.3-70b-versatile"
    VISION_MODEL_NAME: str = "meta-llama/llama-4-scout-17b-16e-instruct"

    # LangSmith observability (optional)
    LANGCHAIN_TRACING_V2: str = "false"
    LANGCHAIN_API_KEY: str = ""
    LANGSMITH_API_KEY: str = ""
    LANGCHAIN_PROJECT: str = "agrigpt"
    LANGSMITH_PROJECT: str = "agrigpt"

    # Pinecone (optional - falls back to FAISS if not set)
    PINECONE_API_KEY: str = ""
    PINECONE_INDEX_NAME: str = "agrigpt-subsidies"
    PINECONE_ENVIRONMENT: str = ""

    # Redis (optional - persistent chat memory; falls back to in-memory)
    REDIS_URL: str = ""

    DEBUG: bool = False

    model_config = SettingsConfigDict(
        env_file=str(_ENV_FILE),
        env_file_encoding="utf-8",
        extra="ignore",
        case_sensitive=False,
    )


settings = Settings()


def langsmith_api_key() -> str:
    """LangSmith API key from LANGSMITH_API_KEY or LANGCHAIN_API_KEY."""
    return str(settings.LANGSMITH_API_KEY or settings.LANGCHAIN_API_KEY or "").strip()


def langsmith_enabled() -> bool:
    """True if LangSmith tracing should be enabled."""
    v = str(settings.LANGCHAIN_TRACING_V2 or "").strip().lower()
    return v in ("true", "1", "yes") and bool(langsmith_api_key())


if not settings.GROQ_API_KEY:
    print(" WARNING: GROQ_API_KEY is missing. Image/text models may fail.")
else:
    k = settings.GROQ_API_KEY.strip()
    print(f" [CONFIG] GROQ_API_KEY loaded ({len(k)} chars): {k[:8]}...{k[-4:] if len(k) > 12 else '...'}")
```

**设计要点**：

1. `_ENV_FILE` 用 `__file__` 绝对定位——无论从哪个目录启动都能找到 `.env`；
2. 启动日志只打印密钥**长度和首尾片段**，绝不明文打印；
3. `extra="ignore"` 容忍 `.env` 中的多余变量，避免部署事故。

验证配置加载：

```powershell
python -c "from backend.core.config import settings; print(settings.TEXT_MODEL_NAME)"
```

### 步骤 3：实现健康检查路由 `backend/routes/health_router.py`

先实现基础版（实训 09 会升级为依赖全景探测版）：

```python
from fastapi import APIRouter
from datetime import datetime
import time

router = APIRouter(prefix="/health", tags=["Health"])

START_TIME = time.time()


@router.get("", include_in_schema=False)
@router.get("/")
async def health_check():
    uptime_sec = int(time.time() - START_TIME)
    return {
        "status": "OK",
        "service": "AgriGPT Backend",
        "timestamp_utc": str(datetime.utcnow().isoformat()),
        "uptime_seconds": uptime_sec,
    }
```

> **规范**：每个业务域一个 `APIRouter`，用 `prefix` + `tags` 归组；健康检查同时注册 `/health` 与 `/health/` 两种写法，兼容不同网关探活习惯。

### 步骤 4：实现应用入口 `backend/main.py`

```python
import os
from pathlib import Path

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles

# Routers
from backend.routes.health_router import router as health_router
from backend.core.config import settings

app = FastAPI(
    title="AgriGPT Backend",
    description="Multimodal AI farming assistant with Groq",
    version="1.0.0"
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(health_router)

# Ensure static dir exists before mounting (avoids startup failure)
_static_dir = Path(__file__).resolve().parent / "static"
_static_dir.mkdir(parents=True, exist_ok=True)
app.mount("/static", StaticFiles(directory=str(_static_dir)), name="static")


@app.get("/favicon.ico", include_in_schema=False)
async def favicon():
    favicon_path = _static_dir / "favicon.ico"
    if favicon_path.exists():
        return FileResponse(str(favicon_path))
    from fastapi.responses import Response
    return Response(status_code=204)


@app.get("/")
def root():
    return {
        "message": "AgriGPT Backend running successfully!",
        "endpoints": ["/health", "/docs"]
    }


@app.on_event("startup")
async def startup_event():
    from backend.core.config import langsmith_enabled, langsmith_api_key

    if langsmith_enabled():
        key = langsmith_api_key()
        proj = settings.LANGSMITH_PROJECT or "agrigpt"
        os.environ["LANGCHAIN_TRACING_V2"] = "true"
        os.environ["LANGCHAIN_API_KEY"] = key
        os.environ["LANGCHAIN_PROJECT"] = proj
        os.environ["LANGSMITH_API_KEY"] = key
        os.environ["LANGSMITH_TRACING"] = "true"
        os.environ["LANGSMITH_PROJECT"] = proj
        print("[LangSmith] Tracing enabled → smith.langchain.com")
    else:
        print("[LangSmith] Tracing disabled (set LANGCHAIN_TRACING_V2=true and LANGSMITH_API_KEY to enable)")

    print("AgriGPT Backend Started: Ready to accept queries")


@app.on_event("shutdown")
async def shutdown_event():
    print(" AgriGPT Backend Shutting down....")
```

**设计要点**：

1. **CORS 中间件**：前后端分离架构必需；生产环境应把 `"*"` 收紧为前端域名白名单；
2. **静态目录先创建再挂载**：避免首次启动因目录缺失而崩溃；
3. **startup 钩子**：把"可选依赖（LangSmith）按配置开关"的决策集中到启动时刻，而不是散落在业务代码里。
4. 后续实训会在此文件中逐个 `include_router`（ask → weather → metrics）。

## 四、常见问题排查

| 现象 | 原因与解决 |
|------|-----------|
| `ModuleNotFoundError: No module named 'backend'` | 启动目录不对——必须站在 `backend` 的父目录运行 `uvicorn backend.main:app` |
| `/docs` 打开是空白 | 浏览器缓存；或确认访问的是 `8000` 端口 |
| 8000 端口被占用 | `netstat -ano | findstr :8000` 找到 PID 结束，或 `--port 8001` |
| `.env` 修改不生效 | `Settings` 在进程启动时加载一次；改完必须重启（`--reload` 只监听 .py） |
