### 2.6 后端唯一部署缺口 ⚠️

`kaleido-ai-dev.yml`（Nacos）里模型配置引用环境变量：
```
base-url: ${AI_BASE_URL}   api-key: ${...}   model: ${CHAT_MODEL} / ${EMBEDDING_MODEL}
```
但 **`docker-compose.services.yml` 和 `dev-ops/docker-compose.yml` 都没有定义这些环境变量，也没有真实 API Key**。当前部署下 kaleido-ai 起来后无法调用大模型。需要在服务 compose 的 kaleido-ai 节点加 `environment:` 注入（或改 Nacos 里写死）。

## 四、用户端：不存在

- `source code/` 下只有 `frontend`（管理端）一个前端项目，无 App / 小程序 / H5
- 衣柜管理（服装录入、搭配、收纳位置）、AI 对话/工作流这些 **C 端功能后端全部实现了，但没有界面可用**
- 现在唯一能触达衣柜/AI 的方式：通过网关直接调 `/wardrobe/*`、`/ai/*` HTTP 接口（如 curl / Apifox）
