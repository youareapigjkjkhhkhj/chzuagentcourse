# 部署指南 — Agentic 供应链运营平台

## 一、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Python | 3.11+ | 后端运行环境 |
| Node.js | 18+ | 前端构建 |
| uv | 最新 | Python 包管理器 |
| PostgreSQL | 14+ | 主数据库（可选，模拟数据可用 SQLite） |
| ClickHouse | 最新 | 实时分析（可选） |

## 二、本地开发部署

### 2.1 安装依赖

```bash
# 后端依赖
uv sync --extra dev

# 前端依赖
cd frontend
npm install
cd ..
```

### 2.2 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```env
# LLM 配置（必须）
NEBIUS_API_KEY=your_api_key_here

# 数据库（可选，不配置则使用模拟数据）
DATABASE_URL=postgresql://user:password@localhost:5432/erp_simulation

# ClickHouse（可选）
CLICKHOUSE_HOST=localhost
CLICKHOUSE_PORT=8123
CLICKHOUSE_USER=default
CLICKHOUSE_PASSWORD=
CLICKHOUSE_DATABASE=supply_chain

# MLflow
MLFLOW_TRACKING_URI=sqlite:///mlflow.db
MLFLOW_EXPERIMENT_NAME=supply-chain-orchestrator
```

### 2.3 构建前端

```bash
cd frontend
npm run build
cd ..
```

### 2.4 启动服务

```bash
# 启动后端（端口 8000）
uv run python -m uvicorn main:app --app-dir src --host 127.0.0.1 --port 8000

# 启动 MLflow（端口 5001，可选）
uv run mlflow server --host 127.0.0.1 --port 5001 --backend-store-uri sqlite:///mlflow.db
```

### 2.5 验证

- 前端界面：`http://127.0.0.1:8000`
- API 文档：`http://127.0.0.1:8000/docs`
- MLflow：`http://127.0.0.1:5001`

## 三、Docker 部署（可选）

### 3.1 Dockerfile

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 安装 uv
RUN pip install uv

# 安装后端依赖
COPY pyproject.toml uv.lock ./
RUN uv sync --extra dev

# 复制源码
COPY src/ ./src/
COPY frontend/dist/ ./frontend/dist/

# 暴露端口
EXPOSE 8000

# 启动
CMD ["uv", "run", "python", "-m", "uvicorn", "main:app", "--app-dir", "src", "--host", "0.0.0.0", "--port", "8000"]
```

### 3.2 docker-compose.yaml

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "8000:8000"
    environment:
      - NEBIUS_API_KEY=${NEBIUS_API_KEY}
      - DATABASE_URL=postgresql://user:password@postgres:5432/erp_simulation
      - MLFLOW_TRACKING_URI=http://mlflow:5001
    depends_on:
      - postgres
      - mlflow

  postgres:
    image: postgres:15
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
      POSTGRES_DB: erp_simulation
    volumes:
      - pgdata:/var/lib/postgresql/data

  mlflow:
    image: ghcr.io/mlflow/mlflow:v2.10.0
    command: mlflow server --host 0.0.0.0 --port 5001 --backend-store-uri sqlite:///mlflow.db
    ports:
      - "5001:5001"

volumes:
  pgdata:
```

### 3.3 启动

```bash
docker-compose up -d
```

## 四、生产部署建议

| 项目 | 建议 |
|------|------|
| 反向代理 | Nginx / Caddy，配置 HTTPS |
| 进程管理 | Gunicorn + Uvicorn workers |
| 数据库 | PostgreSQL 高可用（主从复制） |
| LLM API | 配置有效的 API Key，监控调用配额 |
| 监控 | MLflow + Prometheus + Grafana |
| 日志 | 结构化日志 + ELK/Loki |

## 五、常见问题

### Q1: 启动后前端显示空白

A: 确保已执行 `npm run build` 构建前端，`dist/` 目录存在。

### Q2: LLM 调用失败

A: 检查 `.env` 中 `NEBIUS_API_KEY` 是否配置有效。未配置时 UI 仍可展示静态数据。

### Q3: ClickHouse 连接失败

A: ClickHouse 为可选组件，不影响核心功能。可跳过或单独安装。

### Q4: 端口被占用

A: 使用 `--port` 参数指定其他端口，或修改 `.env` 中的端口配置。
