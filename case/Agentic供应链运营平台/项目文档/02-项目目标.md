# 02 · 项目目标 — Agentic 供应链运营平台

## 一、功能目标

| 编号 | 功能 | 验收标准 |
|------|------|----------|
| F1 | 多智能体编排 | 5 阶段 LangGraph 工作流按 DAG 顺序执行，状态透传 |
| F2 | 库存监控 | 读取 ERP 库存数据，输出风险等级（critical/low/excess/normal） |
| F3 | 需求预测 | 基于历史销售数据生成未来需求预测 |
| F4 | 采购规划 | 结合风险与预测生成采购申请单（SKU/数量/供应商/预估单价） |
| F5 | 供应商谈判 | 模拟议价过程，输出谈判记录与最终价格 |
| F6 | 物流规划 | 生成运输方案（承运商/路线/成本/交付日期） |
| F7 | 控制塔仪表盘 | KPI 卡片、风险预警、仓库负载、决策剧本展示 |
| F8 | 工作流可视化 | 实时 WebSocket 推送智能体状态，DAG 可视化 |
| F9 | 场景实验室 | 供应冲击压力测试，概率/影响分析 |
| F10 | 治理中心 | 审批队列、护栏规则、智能体可靠性登记 |
| F11 | 供应商谈判工作台 | 实时对话、条款演变追踪、价格让步分析 |
| F12 | WebSocket 实时流 | 工作流事件实时推送至前端 |

## 二、非功能目标

| 维度 | 目标 |
|------|------|
| 可运行性 | `uv sync` + `npm install` 即可本地启动；Docker 部署可选 |
| 可观测性 | MLflow 记录每次工作流运行的元数据与结果 |
| 可扩展性 | 新增智能体只需继承 `BaseAgent` 并注册到编排器 |
| 前端体验 | 响应式布局、动画过渡、中文界面 |
| API 规范 | RESTful 路由 + WebSocket，统一 JSON 响应 |

## 三、5 阶段里程碑

| 阶段 | 智能体 | 输入 | 输出 | 达成标志 |
|------|--------|------|------|----------|
| 1 | 库存监控 | ERP 库存数据 | 风险告警列表 | 风险等级正确分类 |
| 2 | 需求预测 | 历史销售数据 | 需求预测结果 | 预测值合理 |
| 3 | 采购规划 | 风险 + 预测 | 采购申请单 | 包含 SKU/数量/供应商/价格 |
| 4 | 供应商谈判 | 采购单 + 供应商信息 | 谈判记录 + 最终价格 | 价格低于初始报价 |
| 5 | 物流规划 | 采购单 + 谈判结果 | 物流方案 | 包含承运商/路线/成本/日期 |

## 四、验收测试清单

| 测试 | 覆盖 | 说明 |
|------|------|------|
| 后端单元测试 | `uv run pytest -q` | 智能体逻辑、API 路由 |
| 前端构建 | `npm run build` | TypeScript 编译 + Vite 打包 |
| API 健康检查 | `GET /api/platform/control-tower` | 返回控制塔快照 |
| WebSocket 连接 | `ws://127.0.0.1:8000/ws/workflow/{id}` | 事件流正常推送 |
| 工作流端到端 | `POST /api/analyze/SKU-001` | 五阶段完整执行 |

## 五、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| LLM API Key 未配置 | 智能体对话功能不可用 | 文档标注配置步骤；UI 仍可展示静态数据 |
| PostgreSQL/ClickHouse 未安装 | 可观测性功能受限 | 核心功能不依赖；MLflow 用 SQLite 本地存储 |
| ERP 数据为模拟数据 | 非真实业务场景 | 架构支持替换为真实 ERP 接口 |
| 前端为演示级别 | 缺少用户认证/权限 | 后续可扩展 |

## 六、范围外（后续增强）
