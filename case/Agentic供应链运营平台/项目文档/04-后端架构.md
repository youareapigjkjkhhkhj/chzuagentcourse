# 04 · 后端架构 — Agentic 供应链运营平台

## 一、目录结构

```text
src/
├── main.py                 # FastAPI 应用入口
├── config.py               # 配置管理（环境变量加载）
├── agents/                 # 智能体层
│   ├── base.py             # AgentState 类型定义 + BaseAgent 抽象类
│   ├── orchestrator.py     # LangGraph 编排器
│   ├── inventory_monitor.py
│   ├── demand_forecast.py
│   ├── procurement.py
│   ├── vendor_negotiation.py
│   └── logistics.py
├── api/                    # 路由层
│   ├── routes.py           # REST API 路由
│   └── websocket.py        # WebSocket 处理
├── services/               # 服务层
│   ├── erp_gateway.py      # ERP 数据访问
│   ├── platform_intelligence.py  # 控制塔/场景/治理
│   ├── mlflow_tracker.py   # MLflow 追踪
│   └── clickhouse_analytics.py   # ClickHouse 分析
├── llm/                    # LLM 客户端
│   └── client.py           # OpenAI 兼容 API 封装
└── db/                     # 数据层
    ├── connection.py       # PostgreSQL 连接
    ├── erp_simulator.py    # ERP 模拟查询
    └── schema.sql          # 数据库 Schema
```

## 二、FastAPI 入口（main.py）

```python
app = FastAPI(title="Supply Chain Orchestrator", version="1.0.0")
app.include_router(router)  # /api 前缀路由

# 静态文件服务（前端 dist）

```

### 4.3 各智能体

| 智能体 | 输入 | 处理逻辑 | 输出 |
|--------|------|----------|------|
| 库存监控 | ERP 库存数据 | 比较库存与再订货点，分类风险 | `risk_alerts` |
| 需求预测 | 历史销售数据 | 统计分析 + LLM 预测 | `demand_forecast` |
| 采购规划 | 风险 + 预测 | 计算采购量，选择供应商 | `purchase_requisition` |
| 供应商谈判 | 采购单 + 供应商 | LLM 模拟议价对话 | `negotiation_result` |
| 物流规划 | 采购单 + 谈判结果 | 选择承运商，计算路线 | `logistics_plan` |

## 六、数据层（db/）

- **connection.py**：PostgreSQL 连接池管理
- **erp_simulator.py**：封装 ERP 查询（库存、销售历史、供应商、产品）
- **schema.sql**：数据库表结构定义
