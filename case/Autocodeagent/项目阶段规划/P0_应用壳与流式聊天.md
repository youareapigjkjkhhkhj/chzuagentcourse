# P0 · 应用壳与流式聊天

> 周期参考：3–5 天 ｜ 前置：无 ｜ 产出：能流式对话、可中断、会话落盘的桌面应用壳

## 阶段目标

搭好 Electron + Vue3 工程地基，打通「输入 → LLM 流式 → 渲染 → 落盘」的最小链路。本期不做任何工具调用。

## 范围

**包含**：工程骨架、应用壳与路由、IPC 通道、LLM Adapter（流式）、模型配置、会话持久化
**不包含**：工具、权限、Diff、Skills、MCP

## 工作分解

| # | 任务 | 说明 |
| --- | --- | --- |
| 1 | 工程骨架 | monorepo（apps/desktop + packages/agent-core + packages/shared）；Electron 31+、Vite、Vue3 + TS、Tailwind；contextIsolation 开、nodeIntegration 关 |
| 2 | 应用壳与路由 | 顶栏、左栏导航骨架、主工作区；五个视图占位（assistant / skills / mcp / models / usage）；样式基线迁移自原型 |
| 3 | IPC 通道 | preload 白名单；`shared` 包建 zod schema；`agent.startSession / sendMessage / abort` 三条通道先行 |
| 4 | LLM Adapter | `POST {baseUrl}/chat/completions` 流式 SSE 解析；`NormalizedLLMResponse` 归一（message / usage / finishReason）；指数退避重试（网络错误与 5xx，最多 3 次） |
| 5 | 流式渲染 | `onStreamToken` 增量拼接；打字光标态；AbortController 中断（半截消息标记 `interrupted`） |
| 6 | 会话持久化 | `~/.agent/sessions/{id}.json`；关键事件即时落盘、普通消息防抖、流式 token 不落盘；重启后会话可恢复 |
| 7 | 模型配置页 | Provider / Model ID / Base URL / 温度 / Max Tokens；Key 输入暂存本地（掩码展示，P6 迁入 safeStorage） |
| 8 | 工作区选择 | 原生目录选择对话框；`workspace` 模块雏形（open / current） |

## 验收条件

- [ ] 应用启动后能与任一 OpenAI 兼容端点流式对话，token 逐字渲染
- [ ] 点击停止可中断流式输出，半截消息标记 `interrupted` 且不阻塞下一条消息
- [ ] 关闭重开应用，会话列表与消息完整恢复
- [ ] 断网 / 5xx 时自动重试（≤3 次），最终失败在 UI 显示错误而非崩溃
- [ ] Renderer 进程中不存在任何 `fs` / `child_process` / `nodeIntegration` 入口（静态检查通过）
- [ ] 所有 IPC payload 经 zod 校验，非法入参被拒绝并记录

## 交付检查点

真模型冒烟 1 次：流式对话 10 轮 + 中途中断 + 重启恢复。
