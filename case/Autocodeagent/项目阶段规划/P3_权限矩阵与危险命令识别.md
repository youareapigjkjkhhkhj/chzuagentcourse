# P3 · 权限矩阵与危险命令识别

> 周期参考：3–5 天 ｜ 前置：P1（可与 P4 / P5 并行）｜ 产出：模式 × 风险五档的完整权限体系

## 阶段目标

把 P1 的 Ask 单模式扩展为完整决策矩阵，新增 Plan / Auto 模式与命令风险启发式检测，安全边界经单测全覆盖锁定。

## 范围

**包含**：三模式决策矩阵、危险命令识别、低风险命令白名单、模式切换 UI
**不包含**：权限持久化（刻意不做，DANGEROUS 永不持久）

## 工作分解

| # | 任务 | 说明 |
| --- | --- | --- |
| 1 | 决策矩阵 | `MATRIX` 查表：Plan（仅 READ）/ Ask（副作用全询问）/ Auto（READ+WRITE 工作区内自动、EXEC 白名单自动）；DANGEROUS 任何模式必询问 |
| 2 | 模式切换 | 输入框盾牌按钮 = 工作区默认权限（Plan / Ask / Auto 三档描述），写入 `config.json` |
| 3 | `assessRisk` 启发式 | 正则命中 `rm -rf` / `sudo` / `git push --force` / `git reset --hard` / `npm publish` / `DROP TABLE` 等 → 升级 DANGEROUS；文档明确定位为启发式而非安全边界 |
| 4 | 低风险白名单 | `ls` / `git status` / `npm test` 等 Auto 模式自动执行的命令清单，可配置 |
| 5 | 授权记忆 | `allow_always_session` 按命令模式 / 文件路径匹配复用；会话结束清空；DANGEROUS 不提供该选项 |
| 6 | Plan 模式 | 仅允许 READ 工具；模型可产出执行计划但任何写操作被拒（拒绝信息回灌） |
| 7 | 单测矩阵 | 3 模式 × 5 风险 = 15 格全覆盖；含白名单命中 / 未命中两条 EXEC 分支 |

## 验收条件

- [x] 权限矩阵 15 格单测全过；Auto 下 `rm -rf` 仍弹确认且只有「允许一次」
- [x] Plan 模式下任何 edit / write / bash 写命令被拒，模型收到拒绝说明并转为纯分析
- [x] Auto 模式下：读文件、写工作区文件、`npm test` 自动执行；`npm install x` 类非白名单命令仍询问
- [x] 「始终允许 `npm test`」后，同模式命令本会话不再弹窗；新会话恢复询问
- [x] `sudo apt install x`、`git push --force` 被识别为 DANGEROUS 并强制确认
- [x] 工作区默认权限切换后立即生效，状态条同步显示当前模式

## 交付检查点

《设计方案》成功标准 5：工作区外路径无法读写；Auto 模式下 `rm -rf` 仍会弹确认。
