**多智能体互动智能课堂系统设计方案**

### 1. 项目概述

本项目旨在构建一个**多智能体驱动的互动智能课堂平台**。用户只需输入学习主题或上传相关材料，系统即可自动生成包含幻灯片、测验、交互式模拟和项目式学习活动的完整课堂，并由多个 AI 角色（教师、同学）进行语音讲解、白板板书和实时讨论，提供沉浸式学习体验。

**核心目标**：
- 一键将任意主题转化为结构完整的互动课堂
- 支持多智能体协作授课与实时互动
- 提供可干预的课程规划与生成工作台
- 支持多种媒体能力（语音、图像、视频）与灵活导出
- 具备良好的可扩展性与本地/云端混合部署能力

**适用场景**：在线教育、企业培训、个人自学、职业技能学习、翻转课堂等。

---

### 2. 系统总体架构

系统采用分层架构，核心为多智能体编排引擎与课堂运行时：

```
┌─────────────────────────────────────────────────────────────┐
│                      用户入口层                              │
│          Web 前端 / 即时通讯机器人 / API 接口                 │
└────────────────────────────┬────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────┐
│                   应用服务层（Next.js / FastAPI）             │
│     课程生成 · 工作台 · 编辑器 · 播放器 · 用户设置            │
└────────────┬───────────────────────────────┬────────────────┘
             │                               │
┌────────────▼────────────┐     ┌────────────▼────────────┐
│   多智能体编排与生成引擎  │     │   课堂运行时与交互引擎    │
│  状态机编排 + Skills     │     │  幻灯片 / 测验 / 交互     │
│  材料解析 + 工具调用     │     │  白板 · 语音 · 讨论      │
└────────────┬────────────┘     └────────────┬────────────┘
             │                               │
┌────────────▼───────────────────────────────▼────────────┐
│                    能力抽象层（可插拔）                     │
│  大模型 · 语音合成 · 语音识别 · 图像 · 视频 · 搜索 · 文档解析 │
└────────────┬───────────────────────────────┬────────────┘
             │                               │
┌────────────▼────────────┐     ┌────────────▼────────────┐
│   数据与资产层            │     │   渲染与导出服务          │
│  数据库 + 对象存储        │     │  视频导出 / PPTX 生成    │
└─────────────────────────┘     └─────────────────────────┘
```

**推荐技术栈**：
- 前端：Next.js + React + TypeScript + Tailwind CSS
- 智能体编排：LangGraph（或同类状态机框架）
- 后端服务：Next.js API Routes 或独立 FastAPI
- 数据库：PostgreSQL（会话与课程持久化）
- 向量/文档：可选轻量向量库辅助材料检索
- 部署：Docker Compose / 云平台

### 3. 核心功能模块设计

#### 3.1 课程生成引擎
- **一键生成模式**：用户输入主题或上传材料 → 系统自动规划大纲 → 生成完整课堂内容。
- **Agent 工作台模式**（重点）：
  - 聊天式交互界面，用户可与生成 Agent 持续对话。
  - Agent 负责课程规划、页面构建、内容修订。
  - 支持上传文档、音频、视频或网络搜索结果作为生成素材。
  - 会话可中断、恢复、随时人工干预。
  - 内置可扩展 Skills（幻灯片生成、测验设计、交互组件、项目式学习、图像/视频生成、语音配置、PPT 导入等）。

#### 3.2 多智能体课堂运行时
- **角色设计**：AI 教师（主讲）+ 若干 AI 同学（讨论、提问、补充）。
- **场景类型**：
  - 幻灯片讲解
  - 测验与即时反馈
  - 交互式 HTML 模拟实验
  - 项目式学习（PBL）活动
  - 深度交互场景（可视化、游戏化、在线编程、思维导图等）
- **互动能力**：
  - 白板实时板书与绘图
  - 语音讲解（TTS）与语音输入（ASR）
  - 多轮讨论与实时问答
  - 沉浸模式与快捷键操作

#### 3.3 编辑与导出模块
- 可视化幻灯片编辑器：支持拖拽、缩放、旋转、多选、历史回退。
- AI 辅助编辑：通过自然语言指令修改已有内容。
- 导出能力：
  - 可编辑 PPTX
  - 交互式 HTML（支持离线）
  - 课程视频（MP4）

#### 3.4 能力抽象层（Provider 中立）
将外部能力统一抽象，支持灵活替换：
- 大语言模型（云端/本地）
- 语音合成与识别
- 图像与视频生成
- 文档解析（多格式 + 音视频抽取）
- 网络搜索

启动时进行能力校验，失败时给出明确提示，避免强绑定单一厂商。

#### 3.5 材料与知识处理
- 支持上传文档、音频、视频。
- 自动解析、切分、提取关键内容。
- 可作为生成 Agent 的上下文材料。
- 可选向量检索增强长材料利用效率。

### 4. 数据与状态设计

**核心数据模型**：
- **课程文档**：内部 DSL 描述场景结构（页面、元素、测验、交互组件、时间线等）。
- **会话状态**：生成过程的中间状态、消息历史、材料引用，支持持久化与恢复。
- **资产库**：图片、音频、视频等统一注册与管理。
- **用户进度**：测验答题状态、课程完成情况。

**持久化策略**：
- 开发阶段可用本地存储或 SQLite。
- 生产环境推荐 PostgreSQL + 对象存储。
- 支持增量保存与会话回放。

### 5. 关键流程设计

**一键生成流程**：
1. 用户输入主题或上传材料
2. 大纲规划 Agent 生成课程结构
3. 用户确认或微调大纲
4. 并行/串行生成各场景内容
5. 组装完整课堂并进入播放器

**Agent 工作台流程**：
1. 用户进入聊天工作区
2. 上传材料或描述需求
3. Agent 规划 → 调用 Skills 生成内容 → 展示中间结果
4. 用户可随时打断、修改指令或直接编辑
5. 最终确认并保存/导出

**课堂运行流程**：
1. 加载课程 DSL
2. 按时间线驱动 AI 教师讲解与白板操作
3. 触发测验或交互时暂停等待用户输入
4. AI 同学可插入讨论或提问
5. 记录进度并支持断点续学

### 7. 实施路线建议

**第一阶段（MVP）**：
- 一键主题生成（幻灯片 + 简单测验）
- 基础多智能体讲解与 TTS
- 简单 Web 播放器
- 本地或单一大模型接入

**第二阶段**：
- Agent 工作台与会话持久化
- 材料上传与解析
- 白板 + 基础交互场景
- PPTX / HTML 导出

**第三阶段**：
- 完整 Skills 体系
- 深度交互场景与 PBL
- 视频导出
- 多 Provider 支持与编辑器增强
- 即时通讯机器人接入
