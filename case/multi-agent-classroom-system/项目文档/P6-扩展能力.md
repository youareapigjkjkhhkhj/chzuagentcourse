## 6.1 随堂测验即时反馈与学情总览

### 目标
把测验做成课堂时间线上的**暂停节点**：答对快速带过；答错由陈默补充讲解；连错则插入一页复习。课后生成按章掌握度报告。

### 功能
1. 三档分支：`pass`（答对，教师一句话带过）/ `remedial`（答错，AI 同学补充讲解该概念）/ `review`（同章连错 ≥2 题，动态插入复习页）。
2. 每题记录作答耗时、选项、对错、概念标签（`conceptTag` 复用大纲页标题）。
3. 章级掌握度 = 该章正确题数 / 总题数，落 `chapter_mastery` 视图。
4. 首页「最近课堂」卡片显示掌握度角标（如 `掌握度 78%`）。
5. 学情总览页：按章柱状图 + 错题列表 + 「重听该节」跳转。

### 数据
```
quiz_attempts（P3 已建，补齐 concept_tag 字段）
chapter_mastery（VIEW：course_id, chapter_no, total, correct, mastery）
review_pages(id, session_id, source_page_no, inserted_after_page_no, dsl_json, trigger_reason)
```

### 验收
| 编号 | 条件 |
|------|------|
| P6.1-A1 | 答对 → 教师一句话反馈并继续（不额外产生讨论轮次）；答错 → 陈默发言补充该 `conceptTag`，且发言内容与该概念相关（人工抽 5 条 ≥4 条） |
| P6.1-A2 | 同章连错 2 题 → 自动插入复习页并在时间线中可见，跳过复习页后正常继续 |
| P6.1-A3 | 课堂结束 → 首页卡片显示掌握度百分比，与 `quiz_attempts` 计算值一致 |
| P6.1-A4 | 学情总览页图表数据与数据库一致，点击错题可跳回原页原题 |
| P6.1-A5 | 关闭「每章自动测验」开关后课堂无 quiz 停顿（回归 P3 行为） |
| P6.1-D1 | 分支讲解（LLM）≤ 3s，超时降级为「显示参考答案」不阻塞课堂 |

## 6.2 个人学习笔记簿

### 目标
把讨论区的「划重点 / 生成笔记 / 引用」三个按钮真正落地为**与课程页绑定的笔记库**，可一键导出 Markdown。

### 功能
1. 「划重点」：收藏消息/要点，自动附页号、概念标签、来源角色。
2. 「生成笔记」：聚合本章已划重点 + 错题 → 结构化的「本章回顾」（要点 / 疑问 / 错题），可选用 AI 教师润色。
3. 「引用」：把消息文本插入「我的提问」输入框（课堂内即时提问）。
4. 课堂内新增「我的笔记」Tab：按章分组，点击跳回原页原消息（复用 `msg__quote` 跳页能力）。
5. 一键导出 Markdown / 追加到 P5 的 PDF 讲义。
6. 后端优先存储（`notes` 表），前端 localStorage 仅作离线缓存 —— 跨设备可见。

### 数据
```
notes(id, owner_id, course_id, page_no, message_id, concept_tag,
      type[highlight|qa|error|custom], text, source_role, created_at, updated_at)
```

### 验收
| 编号 | 条件 |
|------|------|
| P6.2-A1 | 点「划重点」→ 笔记 Tab 出现该条，含页号与概念标签；取消划重点则移除 |
| P6.2-A2 | 点「生成笔记」→ 本章回顾按「要点/疑问/错题」三节生成，内容均来自已划重点与错题（无凭空内容） |
| P6.2-A3 | 笔记项点击跳回原页并高亮原消息，位置正确率 100%（10 次） |
| P6.2-A4 | 导出 Markdown 结构清晰（章/节/条目层级正确），中文无乱码 |
| P6.2-A5 | 换浏览器/设备登录后笔记仍在（后端存储生效） |
| P6.2-A6 | 无 AI 可用（未配置 Provider）时「生成笔记」仍可用（降级为规则聚合） |
| P6.2-F1 | 笔记内容仅本人可见；越权访问他人笔记返回 404 |

## 6.3 材料溯源测验生成（强化）

> P4 已实现基础的 chunk 溯源；本子项把**测验题**也做成材料溯源，达到「讲的、考的、都出自原资料」。

### 目标
测验题只从材料出题，每题携带 `source{fileId, chunkId, page, quote}`，题目卡显示「出处：讲义第 12 页」并可跳转原文。

### 功能
1. 考点抽取：先基于材料 chunk 抽取候选考点实体（术语/公式/关键结论），存 `concepts`。
2. 组题约束：prompt 强制「题干必须命中 ≥2 个取自某 chunk 的考点」，输出必带 source。
3. 后端校验：source 必须存在且 quote 在 chunk 原文中匹配，否则拒收并重生成（最多 2 次）。
4. 题目卡渲染出处徽标，点击打开材料预览抽屉并定位高亮。
5. 教师复核模式：列出全部题目与出处，支持一键标记「此题不采用」。

### 数据
```
concepts(id, material_id, chunk_id, name, kind[term|formula|conclusion], page, quote)
quiz_sources(id, quiz_page_id, question_id, material_id, chunk_id, page, quote, verified)
```

### 验收
| 编号 | 条件 |
|------|------|
| P6.3-A1 | 生成 10 题 → 每题均有 source，且 quote 能在对应 chunk 原文中匹配（校验通过率 100%） |
| P6.3-A2 | 出题内容 100% 落在材料范围内（人工核对 10 题，无材料外知识点） |
| P6.3-A3 | 出处徽标点击跳转正确，高亮位置与 quote 一致（10 次点击 100% 正确） |
| P6.3-A4 | 材料未覆盖某章时，该章不生成测验题并提示「材料未涉及」，而非编题 |
| P6.3-A5 | 教师复核模式可标记不采用，标记后该题不出现在课堂 |
| P6.3-E1 | 题目质量人工评分 ≥ 4/5（题干清晰、答案唯一、干扰项合理） |

## 6.4 AI 同学人设库与研讨辩论

### 目标
同学角色从「三句写死的台词」升级为**可配置人设卡**；「研讨模式」真正跑一场有立场的辩论。

### 功能
1. 人设卡：`{性格标签, 专长学科, 提问倾向, 反驳概率, 知识储备等级, 音色, 头像色}`，设置页可增删改，内置 3 个默认人设可一键复原。
2. `AI 同学数量` 滑杆真实生效（0~5 位），角色按人设参与讨论。
3. 研讨子图：`topic_select → stance_assign → debate_round(N) → arbiter_summary`；`讨论激烈程度` 映射轮次 `{低:1, 适中:2, 高:4}`。
4. 每位同学发言前注入「人设卡 + 立场 + 已发言摘要」防复读。
5. 辩论产出落为 `kind=debate` 页面（正反观点 + 教师仲裁总结）。
6. 讨论区渲染立场徽标（支持 / 反对 / 中立）。

### 数据
```
personas(id, owner_id, name, tags_json, expertise, question_bias, rebuttal_prob,
         knowledge_level, voice_profile_id, avatar_color, builtin)

course_agents(course_id, role_code, persona_id, appear_chapters_json)

debate_sessions(id, session_id, topic, stances_json, rounds, summary, created_at)
```

### 验收
| 编号 | 条件 |
|------|------|
| P6.4-A1 | 设置页可新增人设（名称+3 个标签）→ 新课堂中该同学出现并按其标签发言（人工判定 ≥4/5 符合） |
| P6.4-A2 | 「AI 同学数量」设为 0 → 课堂无同学发言；设为 5 → 5 位均至少发言一次（长课） |
| P6.4-A3 | 研讨模式产生 ≥ 2 轮交锋，正反双方观点不重复（相似度 ≤ 0.8） |
| P6.4-A4 | 辩论必产出教师仲裁总结页，总结包含双方核心观点（人工判定） |
| P6.4-A5 | 激烈程度=低 时辩论轮次 ≤ 2；=高 时 ≥ 3（脚本从 `debate_sessions.rounds` 断言） |
| P6.4-A6 | 「默认人设集」可一键复原，复原后自定义人设被清除且内置 3 人回来 |
| P6.4-E1 | 同学发言人设一致性人工评分 ≥ 4/5（抽 10 条判断是否符合其性格标签） |

## 6.5 学习者画像与自适应节奏

### 目标
用**规则引擎**（不上模型）把学习行为转成画像，产出可执行的复习清单并做轻度自适应。

### 功能
1. 行为埋点：`page_view`（含 `replayCount`）、`speed_change`、`quiz_submit`、`pause_replay`、`ask` 入 `behavior_events`。
2. 规则引擎（纯函数 `rules.py`，阈值可配）：
   - 某页回看 ≥2 次 或 该章错 ≥2 题 或 提问命中同页 → 该 `conceptTag` 记 `weak`；
   - 连续 3 页倍速 ≥1.5 且无回看 → 该章记 `easy`。
3. 自适应动作（三类）：
   - 建议语速档（播放器提示「已为你提速到 1.25x，可随时调整」）；
   - 讲稿插句（「上一页的 X 我们再快速过一遍」，由 LLM 生成一句 ≤30 字）；
   - 课后复习清单（薄弱点 + 对应页链接 + 错题）。
4. 显式「没听懂」按钮：单次点击即高权重记为 `weak`（避免仅靠行为误判）。
5. 隐私默认：画像数据本地存储，云端同步需显式开启。

### 数据
```
behavior_events(id, session_id, user_id, course_id, type, page_no, payload_json, ts)

learner_profile(id, user_id, course_id, concept_tag, mastery[weak|normal|easy],
                evidence_json, updated_at)

review_lists(id, user_id, course_id, items_json, created_at)
```

### 验收
| 编号 | 条件 |
|------|------|
| P6.5-A1 | 同一页回看 2 次 → 该页 `conceptTag` 在画像中标记 `weak`（查库断言） |
| P6.5-A2 | 同章答错 2 题 → 同样触发 `weak`，且课后复习清单包含该章与错题链接 |
| P6.5-A3 | 点「没听懂」→ 立即（无需等待规则累积）标记 `weak` 并在下一节开始时出现复讲句 |
| P6.5-A4 | 复习清单页：每项可点击跳回原页；清单导出 Markdown 可用 |
| P6.5-A5 | 未达阈值时不产生误报：正常听完一门课不生成任何 `weak` 标记 |
| P6.5-A6 | 关闭自适应开关后行为仅埋点不干预（回归） |
| P6.5-F1 | 画像数据默认仅本地；开启云端同步时有明确提示与开关 |
| P6.5-D1 | 埋点写入不阻塞播放：单次事件落库 ≤ 50ms，批量合并写 |

## 6.6 同步共学房间

### 目标
课堂可「开播」成房间：多端同页播放、板书同步、举手点名广播——把原型里假的「在线 5」变成真的。

### 功能
1. 房主（真人教师或 AI 教师代理）点「开播」→ 生成 6 位房间码与分享链接。
2. 加入者同步：当前页、播放/暂停、倍速、字幕、白板笔画、讨论消息。
3. 举手队列 → 房主/AI 教师点名 → 点名者发言广播全房间。
4. 在线成员列表实时更新；房主退出时房间转入「AI 教师自动主持」或结束（可配）。
5. 房间结束生成统一课堂记录（复用 P3 记录 + P5 导出）。

### 数据
```
rooms(id, code, course_id, owner_id, state_json{pageNo, playing, beatIdx, speed},
      status[live|ended], created_at, ended_at)

room_members(id, room_id, user_id, role[host|member], online, joined_at, left_at)

room_events(id, room_id, seq, type, payload_json, created_at)   # 增量同步（复用 session_events 结构）
```

### 技术方案
- **P3 的 WS 通道直接复用**：`/ws/classroom/{sessionId}` 增加 `roomId` 维度，房主与成员在同一事件流上，权限不同（成员只读播放状态，可举手/发言）。
- 不引入新协议；房主端发状态（`play/pause/seek/speed`），服务端校验房主身份后广播。
- 时钟同步：服务端时间为基准，成员端按 `serverTs` 校正本地播放位置，误差 > 1s 时强制对齐。

### 验收
| 编号 | 条件 |
|------|------|
| P6.6-A1 | 房主翻页 → 成员端 500ms 内跟随到同页同步；播放/暂停/倍速一致 |
| P6.6-A2 | 成员端字幕与房主端一致（同一 beat），误差 ≤ 1 个 beat |
| P6.6-A3 | 板书：房主端播放板书时成员端同步绘制 |
| P6.6-A4 | 成员举手 → 房主端队列出现；点名后该成员可发言且其他成员能听到/看到 |
| P6.6-A5 | 10 人房间内，事件延迟 P95 ≤ 800ms；成员端无法改变播放状态（越权被拒） |
| P6.6-A6 | 房主退出 → 房间按配置结束或转 AI 主持，成员端有明确提示不卡死 |
| P6.6-A7 | 房间结束后统一课堂记录包含全部成员消息，可导出 |
| P6.6-F1 | 房间码需鉴权（6 位码 + 可选密码），错误码有限次尝试后锁定 |
| P6.6-F2 | 成员不能访问房主的课程编辑接口（越权 404） |
