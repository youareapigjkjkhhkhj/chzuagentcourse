# Ragent AI 部署启动手册

## 1. 环境要求

### 1.1 基础环境

| 组件 | 版本要求 | 说明 |
|:---|:---|:---|
| JDK | 17+ | 推荐 OpenJDK 17 或 21 |
| Maven | 3.8+ | 用于构建项目 |
| Node.js | 18+ | 用于前端项目 |
| npm | 9+ | 用于前端依赖安装 |

### 1.2 中间件

| 组件 | 版本要求 | 说明 |
|:---|:---|:---|
| PostgreSQL | 14+ | 主数据库 |
| pgvector | 0.5+ | 向量扩展 |
| Redis | 7+ | 缓存与限流 |
| Milvus | 2.3+ | 向量数据库 |
| Elasticsearch | 8+ | 关键词检索（可选） |

## 2. 本地开发环境搭建

### 2.1 克隆项目

```bash
git clone <repository-url>

```

```bash

```

### 2.3 安装 Maven

```bash
# Windows
# 下载: https://maven.apache.org/download.cgi

# macOS

sudo apt install maven
```

```bash

# 启动中间件
docker-compose up -d
```

## 3. 中间件配置

### 3.1 docker-compose.yml

在项目根目录创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  postgres:
    image: pgvector/pgvector:pg16
    container_name: ragent-postgres
    ports:
      - "5432:5432"
    environment:
      POSTGRES_DB: ragent
      POSTGRES_USER: ragent
      POSTGRES_PASSWORD: ragent123
    volumes:
      - postgres-data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    container_name: ragent-redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data

  milvus:
    image: milvusdb/milvus:v2.3.4
    container_name: ragent-milvus
    ports:
      - "19530:19530"
    environment:
      ETCD_ENDPOINTS: etcd:2379
    volumes:
      - milvus-data:/var/lib/milvus
    depends_on:
      - etcd

  etcd:
    image: quay.io/coreos/etcd:v3.5.5
    container_name: ragent-etcd
    environment:
      ETCD_AUTO_COMPACTION_MODE: revision
      ETCD_AUTO_COMPACTION_RETENTION: "1000"
      ETCD_QUOTA_BACKEND_BYTES: "4294967296"
      ETCD_SNAPSHOT_COUNT: "50000"
    volumes:
      - etcd-data:/etcd

  elasticsearch:
    image: elasticsearch:8.11.0
    container_name: ragent-elasticsearch
    ports:
      - "9200:9200"
    environment:
      - discovery.type=single-node
      - xpack.security.enabled=false
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
    volumes:
      - es-data:/usr/share/elasticsearch/data

volumes:
  postgres-data:
  redis-data:
  milvus-data:
  etcd-data:
  es-data:
```

### 3.2 启动中间件

```bash
docker-compose up -d
```

### 3.3 初始化数据库

```bash
# 连接 PostgreSQL
psql -h localhost -U ragent -d ragent

# 执行初始化脚本（如果有的话）
\i docs/schema.sql
```

### 3.4 初始化 pgvector

```bash
# 连接 PostgreSQL
psql -h localhost -U ragent -d ragent

# 启用 pgvector 扩展
CREATE EXTENSION IF NOT EXISTS vector;
```

## 4. 后端项目配置

### 4.1 配置文件

编辑 `bootstrap/src/main/resources/application.yml`：

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/ragent
    username: ragent
    password: ragent123
    driver-class-name: org.postgresql.Driver

  data:
    redis:
      host: localhost
      port: 6379

ragent:
  # 向量数据库配置
  vector:
    type: milvus
    milvus:
      host: localhost
      port: 19530
  
  # 检索配置
  retrieval:
    channels:
      - type: vector
        enabled: true
      - type: keyword
        enabled: true
        elasticsearch:
          host: localhost
          port: 9200
      - type: graph
        enabled: false
  
  # 模型配置
  model:
    default: openai
    candidates:
      - name: openai
        type: openai-compatible
        api-key: ${OPENAI_API_KEY:your-api-key}
        base-url: ${OPENAI_BASE_URL:https://api.openai.com/v1}
        model: gpt-4
```

### 4.2 环境变量

```bash
# Windows PowerShell
$env:OPENAI_API_KEY="your-api-key"
$env:OPENAI_BASE_URL="https://api.openai.com/v1"

# Linux/macOS
export OPENAI_API_KEY="your-api-key"
export OPENAI_BASE_URL="https://api.openai.com/v1"
```

## 5. 构建与启动

### 5.1 构建后端

```bash
# 进入项目根目录
cd ragent

# 编译项目
mvn clean compile

# 运行测试
mvn test

# 打包
mvn clean package -DskipTests
```

### 5.2 启动后端

```bash
# 方式一：直接运行
mvn spring-boot:run -pl bootstrap

# 方式二：运行 jar 包
java -jar bootstrap/target/bootstrap-0.0.1-SNAPSHOT.jar
```

### 5.3 验证后端

```bash
# 健康检查
curl http://localhost:8080/actuator/health

# 测试问答 API
curl -X POST http://localhost:8080/api/qa/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "你好", "knowledgeBaseId": 1}'
```

## 7. 常见问题

### 7.1 端口被占用

```bash
# 查看端口占用
netstat -ano | findstr :8080

# Windows: 结束进程
taskkill /PID <PID> /F

# Linux/macOS
kill -9 <PID>
```

### 7.2 数据库连接失败

检查：
1. PostgreSQL 服务是否启动
2. 数据库名称、用户名、密码是否正确
3. pgvector 扩展是否安装

### 7.3 Milvus 连接失败

检查：
1. Milvus 服务是否启动
2. etcd 服务是否正常
3. 端口 19530 是否开放

### 7.4 内存不足

```bash
# 增加 JVM 内存
java -Xmx2g -jar bootstrap/target/bootstrap-0.0.1-SNAPSHOT.jar
```

## 9. 生产部署

### 9.1 Docker 部署

```bash
# 构建镜像
mvn clean package -DskipTests
docker build -t ragent:latest .

# 运行容器
docker run -d \
  --name ragent \
  -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=jdbc:postgresql://host:5432/ragent \
  -e SPRING_DATA_REDIS_HOST=host \
  -e OPENAI_API_KEY=your-key \
  ragent:latest
```

### 9.2 Docker Compose 部署

```bash
# 完整的 docker-compose.yml（包含应用）
docker-compose -f docker-compose.prod.yml up -d
```

### 9.3 配置外部化

生产环境建议使用环境变量或配置中心管理敏感配置：

```bash
export SPRING_DATASOURCE_URL=jdbc:postgresql://prod-db:5432/ragent
export SPRANT_DATASOURCE_PASSWORD=secure-password
export OPENAI_API_KEY=sk-xxx
```
