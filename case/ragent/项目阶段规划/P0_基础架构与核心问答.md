# P0 基础架构与核心问答

## 目标

搭建 Spring Boot 4 项目骨架，实现基础 RAG 问答能力，支持流式对话和会话记忆。

## 工作分解

### 1. 项目初始化

- [ ] Spring Boot 4.1.0 + Java 17 项目搭建
- [ ] Maven 多模块结构（framework / infra-ai / rag / bootstrap）
- [ ] 依赖管理与版本锁定
- [ ] 开发环境配置（IDE、Maven、JDK）

### 2. 基础设施层 (framework)

- [ ] 统一响应封装（Response / ErrorCode）
- [ ] 全局异常处理
- [ ] 认证上下文透传
- [ ] Redis 配置与连接
- [ ] PostgreSQL 配置与连接

### 3. AI 基础设施层 (infra-ai)

- [ ] ChatClient 接口定义
- [ ] OpenAI Compatible API 适配
- [ ] 流式响应支持（SSE）
- [ ] EmbeddingClient 接口定义

### 4. RAG 核心 (rag)

- [ ] 知识库管理（CRUD）
- [ ] 向量存储（Milvus）
- [ ] 基础向量检索
- [ ] 问答链路（检索 + 生成）
- [ ] 流式输出到前端

### 5. 会话管理

- [ ] 会话创建与列表
- [ ] 消息持久化
- [ ] 最近 N 轮消息拼接

### 6. 启动装配 (bootstrap)

- [ ] 启动类与主配置
- [ ] 端口与环境配置
- [ ] 启动验证

## 验收条件

- [ ] 项目能正常启动，无报错
- [ ] 能通过 API 创建知识库
- [ ] 能上传文档并建立向量索引
- [ ] 能发起问答并获得流式响应
- [ ] 会话消息能持久化和查询
- [ ] 单元测试覆盖核心链路

## 技术选型

| 组件 | 选型 | 版本 |
|:---|:---|:---|
| 框架 | Spring Boot | 4.1.0 |
| JDK | OpenJDK | 17 |
| 向量库 | Milvus SDK | 2.6.6 |
| 数据库 | PostgreSQL + pgvector | - |
| 缓存 | Redis + Redisson | 4.6.1 |
| ORM | MyBatis-Plus | 3.5.17 |
| 认证 | Sa-Token | 1.45.0 |
