# P1 多路检索与意图识别

## 目标

实现向量、关键词、知识图谱、联网搜索多路并行召回，支持 RRF 融合与 Rerank，实现意图识别和问题重写。

## 工作分解

### 1. 检索通道抽象

- [ ] SearchChannel 接口定义
- [ ] 检索结果统一模型
- [ ] 并行检索调度器
- [ ] 单通道失败隔离

### 2. 向量检索通道

- [ ] Milvus 向量检索实现
- [ ] TopK 与阈值配置
- [ ] 元数据过滤

### 3. 关键词检索通道

- [ ] Elasticsearch 关键词检索
- [ ] 分词与查询构建
- [ ] 与向量结果去重

### 4. 知识图谱检索通道

- [ ] LightRAG 客户端集成
- [ ] 图谱查询与结果解析
- [ ] 结果格式统一

### 5. 联网搜索通道

- [ ] You.com API 集成
- [ ] 搜索结果摘要提取
- [ ] 结果缓存

### 6. 检索后处理

- [ ] RRF 融合算法
- [ ] Rerank 重排序
- [ ] 结果富化（元数据、来源）

### 7. 意图识别

- [ ] 意图树定义
- [ ] 查询词映射
- [ ] 问题重写与拆分
- [ ] 多知识库路由

### 8. 会话记忆增强

- [ ] 持久化摘要生成
- [ ] 摘要与近期消息拼接
- [ ] Token 预算控制

## 验收条件

- [ ] 能配置启用/禁用检索通道
- [ ] 多通道并行检索，单通道失败不影响主链
- [ ] RRF 融合结果质量优于单路
- [ ] 意图识别准确率 > 80%
- [ ] 问题重写后检索召回率提升
- [ ] 会话摘要能控制 Token 成本

## 技术选型

| 组件 | 选型 |
|:---|:---|
| 关键词检索 | Elasticsearch |
| 知识图谱 | LightRAG |
| 联网搜索 | You.com API |
| 重排序 | Rerank 模型 |
