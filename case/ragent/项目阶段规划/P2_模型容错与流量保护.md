# P2 模型容错与流量保护

## 目标

实现模型档位、多候选路由、首包探测、熔断降级，以及 Redis 公平排队与分布式并发控制。

## 工作分解

### 1. 模型档位管理

- [ ] 模型候选配置
- [ ] 档位定义（fast / standard / premium）
- [ ] 配置校验与启动检查

### 2. 模型路由

- [ ] 候选模型选择策略
- [ ] 负载均衡
- [ ] 手动切换与降级

### 3. 首包探测

- [ ] 首包超时检测
- [ ] 空响应检测
- [ ] 异常响应检测

### 4. 熔断降级

- [ ] 三态熔断器（CLOSED / OPEN / HALF_OPEN）
- [ ] 故障节点隔离
- [ ] 自动恢复机制

### 5. 健康状态

- [ ] 模型健康检查
- [ ] 状态持久化
- [ ] 状态变更事件

### 6. Redis 限流

- [ ] ZSET 公平排队
- [ ] Lua 原子抢占
- [ ] 过期信号量
- [ ] Pub/Sub 唤醒

### 7. 并发控制

- [ ] 分布式信号量
- [ ] 进度查询
- [ ] 超时取消
- [ ] 许可回收

### 8. 流量保护集成

- [ ] 请求入口限流
- [ ] 模型调用限流
- [ ] 限流状态展示

## 验收条件

- [ ] 模型故障时自动切换到候选
- [ ] 首包超时能触发降级
- [ ] 熔断器能正确隔离故障节点
- [ ] 高并发下限流生效
- [ ] 排队公平性可验证
- [ ] 超时取消能正确释放资源

## 技术选型

| 组件 | 选型 |
|:---|:---|
| 分布式锁 | Redisson |
| 限流 | Redis ZSET + Lua |
| 消息 | Redis Pub/Sub |
