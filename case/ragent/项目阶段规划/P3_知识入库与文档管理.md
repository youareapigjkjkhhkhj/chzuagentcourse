# P3 知识入库与文档管理

## 目标

实现可编排的文档入库 Pipeline，支持多格式文档解析、分块、索引，以及远程文档定时刷新。

## 工作分解

### 1. 文档解析

- [ ] PDF 解析（Apache Tika）
- [ ] Word / DOCX 解析
- [ ] Markdown 结构化解析
- [ ] 网页内容提取

### 2. 分块策略

- [ ] 按段落分块
- [ ] 按固定字数分块
- [ ] 按语义分块
- [ ] 分块大小与重叠配置

### 3. 入库 Pipeline

- [ ] Pipeline 节点抽象
- [ ] 节点配置存储
- [ ] 条件执行
- [ ] 输出链式传递

### 4. 入库任务

- [ ] 任务创建与状态机
- [ ] 节点执行日志
- [ ] 失败定位与重试

### 5. 远程文档刷新

- [ ] 定时任务配置
- [ ] 分布式锁防并发
- [ ] 增量更新

### 6. 文档管理

- [ ] 文档列表与详情
- [ ] 文档删除与索引清理
- [ ] Chunk 管理

### 7. 存储抽象

- [ ] ObjectStorageClient 接口
- [ ] S3 实现
- [ ] 阿里云 OSS 实现

## 验收条件

- [ ] 支持 PDF/Word/Markdown/网页解析
- [ ] 分块策略可配置
- [ ] Pipeline 节点可编排
- [ ] 任务失败能定位到具体节点
- [ ] 远程文档能定时刷新
- [ ] 文档删除能清理索引

## 预估周期

1-2 周
