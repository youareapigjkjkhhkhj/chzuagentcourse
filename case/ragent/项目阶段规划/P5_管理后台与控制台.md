# P5 管理后台与控制台

## 目标

实现 React 管理后台，提供知识库管理、Chunk 管理、Trace 查看、配置变更等功能。

## 工作分解

### 1. 前端项目初始化

- [ ] React 18 项目搭建
- [ ] 路由配置
- [ ] 状态管理
- [ ] UI 组件库集成

### 2. 用户问答界面

- [ ] 问答输入框
- [ ] 流式回答展示
- [ ] Markdown 渲染
- [ ] 来源引用展示
- [ ] 深度思考模式

### 3. 知识库管理

- [ ] 知识库列表
- [ ] 知识库创建/编辑
- [ ] 文档上传与管理
- [ ] Chunk 查看

### 4. 意图管理

- [ ] 意图树查看
- [ ] 查询词映射配置
- [ ] 示例问题管理

### 5. 入库任务管理

- [ ] 任务列表
- [ ] 任务状态查看
- [ ] 节点执行日志

### 6. Trace 管理

- [ ] Trace 列表
- [ ] Trace 详情
- [ ] 耗时分析

### 7. 系统设置

- [ ] 模型配置
- [ ] 检索配置
- [ ] 系统参数

### 8. 用户与权限

- [ ] 用户列表
- [ ] 角色管理
- [ ] 操作审计

## 验收条件

- [ ] 用户能通过界面发起问答
- [ ] 能管理知识库和文档
- [ ] 能查看入库任务和日志
- [ ] 能查看 Trace 和耗时
- [ ] 能进行系统配置
- [ ] 界面美观、交互友好
