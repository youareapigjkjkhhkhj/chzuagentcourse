# P6 安全与可观测

## 目标

完善安全体系，实现 Sa-Token 认证、幂等、链路追踪、审计日志等生产级特性。

## 工作分解

### 1. 认证授权

- [ ] Sa-Token 集成
- [ ] 登录/登出
- [ ] 权限校验
- [ ] 数据归属校验

### 2. 幂等控制

- [ ] 幂等注解
- [ ] 幂等拦截器
- [ ] Token 管理

### 3. 链路追踪

- [ ] Trace ID 生成
- [ ] Span 记录
- [ ] 耗时统计
- [ ] 异常记录

### 4. 审计日志

- [ ] 操作日志记录
- [ ] 配置变更 Diff
- [ ] 日志查询

### 5. 参数校验

- [ ] 请求参数校验
- [ ] 上传限流
- [ ] 敏感词过滤

### 6. 统一异常

- [ ] 异常分类
- [ ] 错误码规范
- [ ] 异常上报

### 7. 敏感配置

- [ ] 环境变量注入
- [ ] 配置加密
- [ ] 密钥管理

### 8. 日志规范

- [ ] 日志格式规范
- [ ] 日志级别管理
- [ ] 日志脱敏

## 验收条件

- [ ] 未登录请求被拒绝
- [ ] 幂等控制生效
- [ ] 链路追踪能定位耗时
- [ ] 操作有审计日志
- [ ] 敏感配置不泄露
- [ ] 异常有统一处理

| 组件 | 选型 |
|:---|:---|
| 认证 | Sa-Token |
| 追 Trace | 自定义 + AOP |
