# Ragent AI 项目阶段规划 · 总览

> 基于 Agentic RAG 演进的生产级 Java AI 应用平台开发规划。

## 路线总览

```
P0 基础架构与核心问答 ──▶ P1 多路检索与意图识别 ──▶ P2 模型容错与流量保护
                                                        │
                                                  ══ 可用 MVP ══
                                                        │
                              ┌─────────────────┬───────────┴──────────┐
                              ▼                 ▼                      ▼
                        P3 知识入库        P4 Agent 与 MCP         P5 管理后台
                              └─────────────────┴───────────┬──────────┘
                                                            ▼
                                                    P6 安全与可观测
```

## 阶段一览

| 阶段 | 主题 | 交付物 |
| --- | --- | --- |
| [P0](./P0_基础架构与核心问答.md) | Spring Boot 4 + Milvus + 基础问答 | 能流式对话、会话记忆、基础 RAG |
| [P1](./P1_多路检索与意图识别.md) | 向量/关键词/图谱/联网多路召回 | 混合检索、RRF 融合、意图路由 |
| [P2](./P2_模型容错与流量保护.md) | 模型档位、熔断降级、Redis 限流 | 多候选切换、公平排队、熔断隔离 |
| [P3](./P3_知识入库与文档管理.md) | 可编排 Pipeline、远程刷新 | 文档解析、分块、索引、溯源 |
| [P4](./P4_Agent与MCP接入.md) | Agent 执行架构 + MCP 工具 | ReAct 骨架、工具发现、Schema 校验 |
| [P5](./P5_管理后台与控制台.md) | React 管理后台 | 知识库管理、Trace、配置变更 |
| [P6](./P6_安全与可观测.md) | Sa-Token + Trace + 审计 | 认证、幂等、链路追踪、审计日志 |

## 关键边界

- **MVP = P0 + P1 + P2**：达成后即为「能问答、能多路检索、能容错」的 RAG 系统。
- **P3–P6 为扩展收口**，可并行启动（P4 / P5 互不依赖）。
- **后置候选（不进当前规划）**：子 Agent、MCP SSE/HTTP 传输、多租户隔离。
- 每期结束时统一执行：单元测试回归 + 真模型手工冒烟。

## 核心模块职责

| 模块 | 职责 |
|:---|:---|
| `framework` | 统一响应与异常、认证上下文、幂等、分布式 ID、MQ 适配、Trace、SSE |
| `infra-ai` | Chat / Embedding / Rerank / VLM 模型客户端、模型档位、路由、首包探测 |
| `system` | 用户认证与审计日志，系统支撑域 |
| `rag` | RAG 问答、知识库、入库 Pipeline、意图树、检索、会话及管理端 API |
| `agent` | Agent 执行架构（v2 ReAct）骨架 |
| `bootstrap` | 启动装配层，仅含启动类与主配置 |
| `mcp-server` | 基于 MCP Java SDK 的独立工具服务 |
