# 04 · 阶段 1 — 环境与配置中枢

> 本阶段目标：建立项目运行环境（Python 3.11 限定 + 清华源依赖），掌握配置中枢 `common/core/config.py` 与 `.env` 的关系，明确本地验证与完整部署的边界。

---

## 1. 目标

- 创建 Python 3.11 虚拟环境（项目 `requires-python = "==3.11.*"`，`pyproject.toml:5`）。
- 区分两套依赖：**全量**（`pyproject.toml`，含私有包与数据库驱动全家桶）与**本地核心验证**（`requirements-local.txt`）。
- 验证 `config.Settings` 正确加载 `源码/.env`。
- 明确部署边界：完整启动需 PostgreSQL + `sqlbot-xpack`（商业包）。

## 2. 目录结构（本阶段涉及）

```text
源码/
├── .env                        # 配置（backend 上一级；config.py:27 固定读取 "../.env"）
└── backend/
    ├── pyproject.toml          # 全量依赖（uv/poetry；requires-python ==3.11.*）
    ├── requirements-local.txt  # 本地核心验证依赖（精简）
    ├── common/core/config.py   # Settings 配置中枢
    └── common/core/db.py       # 主库引擎（启动时建链）
```

## 3. 实操步骤

### 3.1 建虚拟环境并安装本地验证依赖

```bash
cd 源码/backend
"D:/Program Files/Python311/python.exe" -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-local.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 本地验证依赖是 `pyproject.toml:6-60` 的精简子集（fastapi/sqlmodel/langchain/pyyaml/sqlglot 等），**不含** `sqlbot-xpack`（私有包）、torch/llama_index（embedding）、12 种数据库驱动。

### 3.2 配置 `.env`

`common/core/config.py:24-30` 的 `Settings` 基于 `pydantic-settings`，`env_file="../.env"`（即 `源码/.env`）。核心配置：

| 配置项 | 锚点 | 说明 |
|--------|------|------|
| `PROJECT_NAME` | `config.py:31` | 应用名（FastAPI title） |
| `CONTEXT_PATH` / `API_V1_STR` | `config.py:33,52` | 路由前缀（默认 `/api/v1`） |
| `POSTGRES_*` | `config.py:55-59` | 主库连接 |
| `SQLBOT_DB_URL` | `config.py:60-61` | 覆盖默认 PG URI（支持 MySQL 等） |
| `CACHE_TYPE` | `config.py:67` | `memory`/`redis`/`None`（默认 memory，无需 Redis） |
| `BASE_DIR` 等路径 | `config.py:74-77` | 默认 Linux 容器路径，本地需覆盖 |
| `SQLBOT_ALLOW_METADATA_QUERIES` | `config.py:118` | 安全开关：默认禁止元数据查询 |

### 3.3 验证配置加载

```bash
cd 源码/backend
.venv/Scripts/python.exe -c "
from common.core.config import settings
print('PROJECT_NAME =', settings.PROJECT_NAME)
print('DB URI       =', settings.SQLALCHEMY_DATABASE_URI)
print('CACHE_TYPE   =', settings.CACHE_TYPE)
print('API_V1_STR   =', settings.API_V1_STR)
"
```

实测输出：`PROJECT_NAME = 智能数据分析系统`、`CACHE_TYPE = memory`、`API_V1_STR = /api/v1`。

## 6. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| Python 3.13 建 venv 后安装报版本错 | 项目限定 3.11 | 改用 Python 3.11 解释器建 venv |
| `import sqlbot_xpack` 失败 | 私有商业包未安装 | 属预期；用官方 Docker 镜像或获取 xpack 包；本地用 stub 验证 |
| `.env` 未生效 | 位置不对 | 放 `源码/.env`（backend 上一级），勿放 backend 内 |
