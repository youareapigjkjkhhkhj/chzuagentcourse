# 05 · 阶段 2 — 数据源接入与多引擎

> 本阶段目标：掌握 13 种数据源类型体系、多方言数据库引擎（`apps/db/`）、ES 引擎与 Excel 建表工具，理解数据源接入的完整链路。

---

## 1. 目标

- 掌握 `apps/db/constant.py` 的 13 种数据源枚举与 SQL 方言映射。
- 掌握 `apps/db/engine.py` 多方言引擎与 `apps/db/es_engine.py` ES 引擎。
- 掌握 `apps/datasource/` 数据源 API（增删改查/连通性/选表/表结构）。
- 命令行实测：DB 枚举加载、SQL 模板方言映射。

## 2. 关键设计

### 2.1 数据源类型（`apps/db/constant.py`）

`DB` 枚举（实测 13 种）：`excel / redshift / ck / dm / doris / es / kingbase / sqlServer / mysql / oracle / pg / starrocks / hive`。

对应 `templates/sql_examples/*.yaml` 方言模板（见阶段 4）。

### 2.2 多引擎（`apps/db/engine.py`）

| 锚点 | 作用 |
|------|------|
| `engine.py:13-16` | `get_engine_config()`：读 settings 的 PG 配置 |
| `engine.py:19-20` | `get_engine_uri()`：拼 `postgresql+psycopg2` DSN |
| `engine.py:23-29` | `get_engine_conn()`：SQLAlchemy engine（search_path + 超时） |
| `engine.py:39-61` | `create_table()`：字段类型映射（object→text/int→bigint/float→numeric/datetime→timestamp）后建表 |
| `engine.py:64-71` | `insert_data()`：MetaData 反射建表插入 |

### 2.3 ES 引擎（`apps/db/es_engine.py`）

`es_engine.py:14-57`：`get_es_auth` / `get_es_connect` / `get_es_index` / `get_es_fields`（索引与字段枚举）；`get_es_data_by_http`（`es_engine.py:106`）通过 HTTP 查询 ES。

### 2.4 数据源 API（`apps/datasource/api/datasource.py`）

`router = APIRouter(prefix="/datasource")`（`datasource.py:36`）：

| 路由 | 锚点 | 作用 |
|------|------|------|
| `GET /list` | `datasource.py:46` | 数据源列表 |
| `POST /get/{id}` | `datasource.py:52` | 详情 |
| `POST /check` | `datasource.py:58` | 连通性检查 |
| `POST /add` | `datasource.py:77` | 新增 |
| `POST /chooseTables/{id}` | `datasource.py:84` | 选表 |
| `POST /update` | `datasource.py:94` | 更新 |

## 3. 实操步骤

### 3.1 验证数据源枚举

```bash
cd 源码/backend
.venv/Scripts/python.exe -c "
from apps.db.constant import DB
print('数据源类型数 =', len(DB))
for e in DB:
    print(' ', e.name, '->', getattr(e, 'template_name', e.value) if hasattr(e, 'value') else '')
"
```

### 3.2 验证引擎 URI 构造（不连接）

```bash
.venv/Scripts/python.exe -c "
from apps.db.engine import get_engine_uri
from apps.datasource.models.datasource import DatasourceConf
conf = DatasourceConf(username='root', password='pw', host='localhost', port=5432, database='sqlbot', dbSchema='public', timeout=30)
print('引擎 URI =', get_engine_uri(conf).replace('pw', '***'))
"
```

## 5. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| 建表/查询报驱动缺失 | 对应数据库驱动未装 | 按需安装（`pyproject.toml:31-57` 分类） |
| ES 连接失败 | 集群不可达/未配置 | 检查 `DatasourceConf` 与网络 |
