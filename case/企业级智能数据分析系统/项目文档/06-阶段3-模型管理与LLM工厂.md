> 本阶段目标：掌握大模型配置管理（`apps/system/api/aimodel.py` + `AiModelDetail` 模型表）与 LLM 工厂（`apps/ai_model/model_factory.py`），理解 12+ 服务商如何统一为 4 类 LangChain 实例。

## 1. 目标

- 掌握 `LLMConfig`（`model_factory.py:21-47`）与 `BaseLLM` 抽象（`model_factory.py:50-65`）。
- 掌握 `LLMFactory` 的 4 类注册与缓存实例化（`model_factory.py:112-128`）。
- 掌握默认模型解析 `get_default_config`（`model_factory.py:148-181`）与密钥解密。
- 命令行实测：实例化 OpenAI 兼容 LLM、注册新类型。

## 2. 关键设计

### 2.1 四类模型实现

| 类 | 锚点 | 底层 | 适用 |
|----|------|------|------|
| `OpenAILLM` | `model_factory.py:98-109` | `BaseChatOpenAI`（自定义，`apps/ai_model/openai/llm.py`） | OpenAI 及全部 OpenAI 兼容服务商 |
| `OpenAIvLLM` | `model_factory.py:68-76` | `langchain_community.llms.VLLMOpenAI` | vLLM 部署 |
| `OpenAIAzureLLM` | `model_factory.py:79-95` | `langchain_openai.AzureChatOpenAI` | Azure OpenAI |
| `tongyi` | 映射到 `OpenAILLM` | `model_factory.py:117` | 通义（OpenAI 兼容） |

### 2.2 LLMFactory

`model_factory.py:112-128`：`_llm_types` 字典映射 + `lru_cache(maxsize=32)` 按 `LLMConfig` 哈希缓存实例。扩展机制 `register_llm`（`model_factory.py:131-133`）。

### 2.3 默认模型解析

`get_default_config`（`model_factory.py:148-181`）：
1. `custom_model_id` 指定 → `session.get(AiModelDetail, id)`。
2. 否则查 `default_model == True`（`model_factory.py:154-156`），未设置抛异常。
3. `additional_params` 从 `db_model.config` JSON 解析（`model_factory.py:160-167`）。
4. **密钥解密**：`api_domain`/`api_key` 非 http 开头时 `sqlbot_decrypt`（`model_factory.py:168-171`）。

## 3. 实操步骤

### 3.1 实例化 OpenAI 兼容模型

```bash
cd 源码/backend
.venv/Scripts/python.exe -c "
import sys, types, warnings
warnings.filterwarnings('ignore')
# 本地验证：注入 sqlbot_xpack stub（生产为官方包）
pkg = types.ModuleType('sqlbot_xpack'); core = types.ModuleType('sqlbot_xpack.core')
async def _d(t): return t
async def _e(t): return t
core.sqlbot_decrypt = _d; core.sqlbot_encrypt = _e
pkg.core = core; sys.modules['sqlbot_xpack'] = pkg; sys.modules['sqlbot_xpack.core'] = core

from apps.ai_model.model_factory import LLMFactory, LLMConfig
print('注册类型 =', sorted(LLMFactory._llm_types.keys()))
cfg = LLMConfig(model_type='openai', model_name='gpt-5-mini',
                api_key='sk-test', api_base_url='https://api.chatanywhere.tech')
llm = LLMFactory.create_llm(cfg)
print('实例化成功:', type(llm).__name__)
print('streaming =', getattr(llm.llm, 'streaming', None))
"
```

### 3.2 注册自定义类型

```bash
.venv/Scripts/python.exe -c "
import sys, types, warnings
warnings.filterwarnings('ignore')
pkg = types.ModuleType('sqlbot_xpack'); core = types.ModuleType('sqlbot_xpack.core')
core.sqlbot_decrypt = async_ = lambda t: t
pkg.core = core; sys.modules['sqlbot_xpack'] = pkg; sys.modules['sqlbot_xpack.core'] = core
from apps.ai_model.model_factory import LLMFactory
LLMFactory.register_llm('my_provider', LLMFactory._llm_types['openai'])
print('扩展后类型 =', sorted(LLMFactory._llm_types.keys()))
"
```

## 5. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| `sqlbot_xpack` ImportError | 商业包缺失 | 官方镜像内置；本地验证用 stub（见 3.1） |
| `default_model 未设置` | 系统管理页未配默认模型 | 登录工作台 → 模型管理 → 设为默认 |
| 密钥解密失败 | 库中密钥非密文 | 正常流程由 `async_model_info`（`main.py:76`）迁移加密 |
