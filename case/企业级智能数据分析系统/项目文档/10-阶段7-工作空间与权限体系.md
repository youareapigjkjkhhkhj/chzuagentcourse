# 10 · 阶段 7 — 工作空间与权限体系

> 本阶段目标：掌握企业级安全体系——认证中间件（TokenMiddleware）、工作空间资源隔离、行/列级数据权限与 SQL 注入防护（CWE-89），以及 MCP 集成服务。

---

## 1. 目标

- 掌握 `apps/system/middleware/auth.py` 的 Token 认证中间件与登录/登出。
- 掌握 `apps/system/api/workspace.py` 工作空间隔离与用户绑定。
- 掌握 `apps/datasource/crud/row_permission.py` 的 SQL 注入转义与白名单。
- 掌握 `apps/mcp/mcp.py` 的 MCP 集成（8 个操作）。
- 命令行实测：SQL 注入转义测试（本地可跑）。

## 2. 关键设计

### 2.1 认证（`apps/system/api/login.py` + 中间件）

- `router = APIRouter(prefix="/login")`（`login.py:18`）；`POST /access-token`（`login.py:20`）、`POST /logout`（`login.py:48`）。
- `TokenMiddleware`（`main.py:238` 注册；`apps/system/middleware/auth.py`）校验 `X-SQLBOT-TOKEN`。
- 密码哈希：`common/core/security.py`（passlib/bcrypt）；Token：PyJWT（`ACCESS_TOKEN_EXPIRE_MINUTES=8天`，`config.py:36`）。
- 默认账户：`admin / SQLBot@123456`（`config.py:64`）。

### 2.2 工作空间（`apps/system/api/workspace.py`）

`router = APIRouter(prefix="/system/workspace")`（`workspace.py:18`）：

| 路由 | 锚点 | 作用 |
|------|------|------|
| `GET /uws/option/pager/{page}/{size}` | `workspace.py:20` | 工作空间用户分页 |
| `POST /uws` | `workspace.py:125` | 用户绑定工作空间 |
| `GET ""` | `workspace.py:188` | 工作空间列表 |
| `POST ""` | `workspace.py:198` | 创建工作空间 |
| `GET /{id}` | `workspace.py:220` | 详情 |

数据模型：`apps/system/models/system_model.py`（Workspace / UserWorkspace）。

### 2.3 行列权限与注入防护（`apps/datasource/crud/row_permission.py`）

- `_escape_sql_value`（`row_permission.py:18-29`）：单引号双写 + 反斜杠转义（标准 SQL 注入防护）。
- `_VALID_LOGIC_OPS` 白名单：仅允许 `AND/OR` 等合法操作符拼接权限条件。
- `transFilterTree`（`row_permission.py:31`）：权限树 → SQL 过滤条件。
- 列权限：`apps/datasource/crud/permission.py` + `apps/datasource/crud/field.py`。

## 5. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| 登录 401 | Token 失效/中间件 | 重新 `POST /login/access-token` |
| 权限条件被拒 | 白名单外操作符 | 检查 `_VALID_LOGIC_OPS`（`row_permission.py`） |
| MCP 调用失败 | 8001 未启动 | `uvicorn main:mcp_app --port 8001`（`main.py:255`） |
