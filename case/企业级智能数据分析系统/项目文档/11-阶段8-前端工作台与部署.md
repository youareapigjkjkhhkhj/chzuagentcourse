## 4. 部署方式

### 4.1 Docker 一键部署（推荐，官方镜像）

```bash
cd 部署参考
docker run -d --name sqlbot --restart unless-stopped \
  -p 8000:8000 -p 8001:8001 \
  -v ./data/sqlbot/excel:/opt/sqlbot/data/excel \
  -v ./data/sqlbot/file:/opt/sqlbot/data/file \
  -v ./data/sqlbot/images:/opt/sqlbot/images \
  -v ./data/postgresql:/var/lib/postgresql/data \
  --privileged=true dataease/sqlbot
# 访问 http://<IP>:8000   admin / SQLBot@123456
```

`部署参考/` 含：`Dockerfile`、`Dockerfile-base`、`docker-compose.yaml`、`installer/`（Linux 一键安装脚本 `install.sh`）。

## 5. FAQ

| 现象 | 原因 | 处理 |
|------|------|------|
| 前端接口 401 | Token 过期 | 重新登录获取 `X-SQLBOT-TOKEN` |
| `import sqlbot_xpack` 失败 | 商业包缺失 | 官方镜像内置；本地开发用 stub 或获取 xpack |
| 启动卡在迁移 | PG 不可达 | 启动 PostgreSQL，或配 `SQLBOT_DB_URL` 指向现有库 |
| embedding 初始化失败 | 模型未下载 | 预置 text2vec 到 `LOCAL_MODEL_PATH`；或 `EMBEDDING_ENABLED=False` |
| npm build 内存不足 | 大项目 | `NODE_OPTIONS=--max_old_space_size=4096`（package.json:14 已内置） |
| 图表不渲染 | g2-ssr 未启动 | 运行 `源码/g2-ssr`（`npm install && npm start`，图表 SSR 服务） |

## 6. 部署建议

- 生产：Docker 单容器（内置 PG + 迁移 + 前后端 + MCP + g2-ssr），一个命令完成。
- 内网离线：使用 `installer/` 离线安装包脚本。
- 安全加固：替换默认 `admin/SQLBot@123456`、修改 `SECRET_KEY`、开启 HTTPS 反代。
- 多实例：`SingleWorkerGuard`（PG advisory lock）保证 embedding 初始化单实例执行（`tests/test_distributed_lock.py` 覆盖）。
