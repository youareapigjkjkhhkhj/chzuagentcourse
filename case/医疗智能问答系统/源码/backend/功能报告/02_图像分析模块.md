# 图像分析模块功能报告

## 一、模块概述与功能定位

### 1.1 模块概述
图像分析模块是糖尿病视网膜病变诊断系统的核心功能模块，负责接收眼底图像，通过深度学习模型进行智能分析，提供诊断结果和临床建议。该模块集成了多种先进的深度学习模型，采用集成学习方法提高诊断准确性和可靠性。

### 1.2 功能定位
- 接收和预处理眼底图像
- 图像质量评估与验证
- 多模型并行分析与预测
- 集成诊断结果生成
- 诊断报告生成与管理
- 分析历史记录查询

## 二、核心功能说明

### 2.1 图像上传与处理
- **图像上传**：支持多种图像格式（PNG、JPG、JPEG、BMP、TIFF）
- **图像预处理**：自动调整图像尺寸、归一化、格式转换
- **图像质量评估**：评估图像清晰度、亮度、对比度
- **图像哈希计算**：使用SHA-256算法生成图像唯一标识
- **图像存储**：将原始图像保存到指定目录

### 2.2 图像质量检查
- **清晰度评估**：使用拉普拉斯方差计算图像清晰度
- **亮度评估**：计算图像平均亮度
- **对比度评估**：计算图像标准差
- **质量等级判定**：根据综合评分判定图像质量等级（good/fair/poor）

### 2.3 模型分析与预测
- **多模型支持**：集成多种深度学习模型（EfficientNet、ResNet、DenseNet、ViT等）
- **并行预测**：多个模型同时进行预测，提高效率
- **概率输出**：输出每个诊断级别的概率分布
- **置信度计算**：计算预测结果的置信度分数
- **处理时间记录**：记录每个模型的处理时间

### 2.4 集成诊断
- **多模型集成**：采用投票或加权平均方法集成多个模型的结果
- **诊断级别判定**：根据集成结果确定最终诊断级别（0-4级）
- **置信度融合**：融合多个模型的置信度
- **风险等级评估**：根据诊断级别和置信度评估风险等级

### 2.5 诊断报告生成
- **报告内容生成**：包含患者信息、诊断结果、模型预测详情
- **临床建议生成**：提供随访计划、生活方式建议等
- **报告导出**：支持PDF和JSON格式导出
- **报告管理**：支持报告查询、更新、删除

### 2.6 历史记录管理
- **分析记录查询**：按时间、患者、诊断级别等条件查询
- **结果详情查看**：查看详细的分析结果和模型预测
- **数据统计**：统计分析次数、诊断分布等

## 三、技术实现细节

### 3.1 数据模型

#### ImageAnalysis（图像分析记录表）
- `id`：主键，UUID
- `image_filename`：图像文件名
- `image_path`：图像存储路径
- `image_hash`：图像SHA-256哈希值（唯一）
- `image_size`：图像文件大小（字节）
- `image_format`：图像格式
- `analysis_status`：分析状态（pending/processing/completed/failed）
- `created_at`：创建时间
- `updated_at`：更新时间

#### AnalysisResult（分析结果表）
- `id`：主键，UUID
- `image_analysis_id`：关联图像分析记录ID
- `model_name`：使用的模型名称
- `prediction_level`：预测的诊断级别（0-4）
- `confidence_score`：置信度分数（0-1）
- `processing_time`：处理时间（秒）
- `image_quality`：图像质量（good/fair/poor）
- `features_extracted`：提取的特征描述
- `created_at`：创建时间

#### ModelPrediction（模型预测详细结果表）
- `id`：主键，UUID
- `analysis_result_id`：关联分析结果ID
- `class_0_prob`：类别0概率（无糖尿病视网膜病变）
- `class_1_prob`：类别1概率（轻度非增殖性）
- `class_2_prob`：类别2概率（中度非增殖性）
- `class_3_prob`：类别3概率（重度非增殖性）
- `class_4_prob`：类别4概率（增殖性）
- `raw_prediction`：模型原始预测输出
- `created_at`：创建时间

#### DiagnosisReport（诊断报告表）
- `id`：主键，UUID
- `image_analysis_id`：关联图像分析记录ID
- `patient_id`：患者ID
- `patient_name`：患者姓名
- `patient_age`：患者年龄
- `patient_gender`：患者性别
- `ensemble_diagnosis_level`：集成模型最终诊断级别（0-4）
- `ensemble_confidence`：集成模型置信度
- `report_content`：报告内容（JSON格式）
- `recommendations`：建议内容（JSON格式）
- `risk_level`：风险等级（low/medium/high/critical）
- `follow_up_plan`：随访计划
- `created_at`：创建时间

### 3.2 图像预处理流程
1. **图像读取**：支持OpenCV和PIL两种读取方式
2. **格式转换**：统一转换为RGB格式
3. **尺寸调整**：调整为224x224像素
4. **归一化处理**：使用ImageNet均值和标准差进行归一化
5. **张量转换**：转换为PyTorch张量格式

### 3.3 图像质量评估算法
- **清晰度评分**：`min(laplacian_variance / 100, 1.0) * 0.4`
- **亮度评分**：`(1 - abs(brightness - 128) / 128) * 0.3`
- **对比度评分**：`min(contrast / 50, 1.0) * 0.3`
- **综合评分**：清晰度40% + 亮度30% + 对比度30%

### 3.4 模型集成策略
- **投票法**：多个模型投票选择最可能的诊断级别
- **加权平均**：根据模型性能加权平均概率分布
- **置信度融合**：结合多个模型的置信度计算最终置信度

### 3.5 诊断级别定义
| 级别 | 名称 | 说明 |
|------|------|------|
| 0 | 无糖尿病视网膜病变 | 眼底正常，无需治疗 |
| 1 | 轻度非增殖性 | 少量微血管瘤，建议定期随访 |
| 2 | 中度非增殖性 | 微血管瘤增多，有出血点，建议密切随访 |
| 3 | 重度非增殖性 | 大量出血和渗出，建议转诊眼科 |
| 4 | 增殖性 | 新生血管形成，需要立即治疗 |

### 3.6 风险等级计算
- **low**：诊断级别0-1，置信度>0.8
- **medium**：诊断级别2，或置信度0.5-0.8
- **high**：诊断级别3，或置信度<0.5
- **critical**：诊断级别4

## 五、数据流程

### 5.1 图像分析流程
1. 客户端上传眼底图像
2. 服务器接收并验证图像格式
3. 图像预处理（调整尺寸、归一化）
4. 图像质量评估
5. 计算图像哈希值
6. 保存图像到存储目录
7. 创建图像分析记录
8. 多个模型并行预测
9. 集成模型结果
10. 保存分析结果到数据库
11. 返回诊断结果给客户端

### 5.2 报告生成流程
1. 客户端请求创建报告
2. 服务器验证分析记录存在
3. 获取分析结果和模型预测
4. 构建报告内容
5. 生成临床建议
6. 计算风险等级
7. 保存报告到数据库
8. 返回报告信息给客户端

### 5.3 报告导出流程
1. 客户端请求导出报告
2. 服务器查询报告数据
3. 解析报告内容和建议
4. 根据格式生成导出数据
5. 返回导出数据给客户端
6. 客户端处理并下载文件

## 六、错误处理机制

### 6.1 错误码定义
| 错误码 | 说明 | HTTP状态码 |
|--------|------|-----------|
| INVALID_IMAGE_FORMAT | 图像格式无效 | 400 |
| IMAGE_TOO_LARGE | 图像文件过大 | 400 |
| IMAGE_QUALITY_POOR | 图像质量过低 | 400 |
| ANALYSIS_NOT_FOUND | 分析记录不存在 | 404 |
| ANALYSIS_FAILED | 分析失败 | 500 |
| MODEL_LOAD_ERROR | 模型加载失败 | 500 |
| REPORT_NOT_FOUND | 报告不存在 | 404 |
| REPORT_ALREADY_EXISTS | 报告已存在 | 409 |
| INVALID_REPORT_FORMAT | 报告格式无效 | 400 |

### 6.2 错误响应格式
```json
{
  "success": false,
  "message": "错误描述",
  "error_code": "ERROR_CODE",
  "details": {}
}
```

### 6.3 异常处理
- 图像读取异常：返回图像格式或读取错误
- 模型预测异常：记录日志并返回分析失败
- 数据库操作异常：回滚事务并返回错误
- 文件存储异常：检查目录权限并返回错误

## 七、性能与安全考量

### 7.1 性能优化
- **并行处理**：多个模型并行预测，减少总处理时间
- **图像缓存**：相同哈希图像可跳过重复分析
- **分页查询**：分析记录和报告列表支持分页
- **异步处理**：大批量分析可采用异步处理（待实现）
- **模型预热**：系统启动时预加载模型

### 7.2 安全措施
- **图像验证**：验证图像格式和大小，防止恶意文件
- **文件隔离**：上传文件存储在隔离目录
- **哈希校验**：使用SHA-256哈希防止重复上传
- **访问控制**：需要登录才能访问分析功能
- **数据加密**：敏感数据传输使用HTTPS

### 7.3 数据隐私
- **患者信息保护**：患者信息单独存储，与图像数据分离
- **访问日志**：记录所有分析操作
- **数据脱敏**：导出报告时可选择脱敏处理
