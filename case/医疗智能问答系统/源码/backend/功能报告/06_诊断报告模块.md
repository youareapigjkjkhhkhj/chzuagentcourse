# 诊断报告模块功能报告

## 一、模块概述

### 1.1 功能定位
诊断报告模块是系统的核心业务模块，负责生成、管理和导出糖尿病视网膜病变的诊断报告。该模块基于图像分析结果，结合多个深度学习模型的预测结果，生成集成诊断报告，包括诊断级别、置信度、风险等级、临床建议等关键信息，为医生和患者提供全面的诊断参考。

### 1.2 模块架构
```
诊断报告模块
├── 数据层
│   ├── DiagnosisReport (诊断报告数据模型)
│   ├── ImageAnalysis (图像分析记录)
│   ├── AnalysisResult (分析结果)
│   └── ModelPrediction (模型预测详情)
├── 业务逻辑层
│   ├── 报告创建与生成
│   ├── 风险等级计算
│   ├── 报告内容构建
│   ├── 报告查询与过滤
│   └── 报告导出（JSON/PDF）
└── API接口层
    ├── POST /api/reports - 创建诊断报告
    ├── GET /api/reports - 获取报告列表
    ├── GET /api/reports/<id> - 获取报告详情
    ├── PUT /api/reports/<id> - 更新报告
    ├── GET /api/reports/export/<id> - 导出单个报告
    └── POST /api/reports/export - 批量导出报告
```

## 二、核心功能说明

### 2.1 报告创建与生成
基于图像分析结果创建完整的诊断报告，集成多个模型的预测结果。

**功能特性：**
- 支持基于图像分析ID创建报告
- 集成多个模型的预测结果
- 自动计算风险等级
- 生成临床建议和随访计划
- 防止重复创建报告（同一分析只能有一个报告）

**报告内容包括：**
- 患者基本信息（ID、姓名、年龄、性别）
- 集成诊断级别（0-4级）
- 集成置信度
- 各模型预测详情
- 临床摘要
- 检测到的特征
- 图像信息
- 主要建议
- 随访计划
- 生活方式建议
- 监测计划

### 2.2 风险等级计算
根据诊断级别和置信度自动计算患者的风险等级。

**风险等级定义：**
| 诊断级别 | 基础风险 | 说明 |
|---------|---------|------|
| 0 | low | 无糖尿病视网膜病变 |
| 1 | low | 轻度非增殖性视网膜病变 |
| 2 | medium | 中度非增殖性视网膜病变 |
| 3 | high | 重度非增殖性视网膜病变 |
| 4 | critical | 增殖性视网膜病变 |

**置信度调整规则：**
- 当置信度 > 0.9 且诊断级别 ≥ 2 时，风险等级提升一级
- 例如：诊断级别2（medium）+ 高置信度 → high
- 诊断级别3（high）+ 高置信度 → critical

### 2.3 报告查询与过滤
支持多种条件的报告查询和分页展示。

**查询条件：**
- 患者ID过滤
- 日期范围过滤
- 诊断级别过滤
- 分页查询

**排序方式：**
- 按创建时间降序排列（最新的报告在前）

### 2.4 报告导出
支持多种格式的报告导出，满足不同的使用场景。

**导出格式：**
- **JSON格式**: 结构化数据，便于系统集成
- **PDF格式**: 可打印的医疗报告，包含完整的报告内容和图像

**导出功能：**
- 单个报告导出
- 批量报告导出
- 自动生成报告HTML模板

### 3.2 风险等级计算实现

**风险等级计算函数** (`backend/routes/reports.py:506-526`)
```python
def calculate_risk_level(diagnosis_level: int, confidence: float) -> str:
    """根据诊断级别和置信度计算风险等级"""
    # 基础风险等级由诊断级别决定
    base_risk = {
        0: 'low',
        1: 'low', 
        2: 'medium',
        3: 'high',
        4: 'critical'
    }
    
    base_level = base_risk.get(diagnosis_level, 'medium')
    
    # 如果置信度很高，可能提升风险等级
    if confidence > 0.9 and diagnosis_level >= 2:
        if base_level == 'medium':
            return 'high'
        elif base_level == 'high':
            return 'critical'
    
    return base_level
```

```python
@reports_bp.route('', methods=['POST'])
def create_report():
    """创建诊断报告"""
    try:
        data = request.get_json()
        
        # 验证必需参数
        required_fields = ['analysis_id', 'patient_id', 'ensemble_diagnosis_level', 'ensemble_confidence']
        for field in required_fields:
            if field not in data:
                return error_response(f'缺少必需参数: {field}', 400)
        
        analysis_id = data['analysis_id']
        patient_id = data['patient_id']
        patient_name = data.get('patient_name', '')
        patient_age = data.get('patient_age')
        patient_gender = data.get('patient_gender')
        ensemble_diagnosis_level = data['ensemble_diagnosis_level']
        ensemble_confidence = data['ensemble_confidence']
        
        # 检查图像分析记录是否存在
        image_analysis = ImageAnalysis.query.get(analysis_id)
        if not image_analysis:
            return error_response('图像分析记录不存在', 404)
        
        # 检查是否已经存在该分析的报告
        existing_report = DiagnosisReport.query.filter_by(image_analysis_id=analysis_id).first()
        if existing_report:
            return error_response('该分析已经存在报告', 409)
        
        # 构建报告内容
        report_content = {
            'analysis_results': data.get('analysis_results', []),
            'model_predictions': data.get('model_predictions', []),
            'clinical_summary': data.get('clinical_summary', ''),
            'features_detected': data.get('features_detected', []),
            'image_info': {
                'filename': image_analysis.image_filename,
                'format': image_analysis.image_format,
                'size': image_analysis.image_size,
                'quality': 'good'
            }
        }
        
        # 构建建议内容
        recommendations = {
            'primary_recommendations': data.get('primary_recommendations', []),
            'follow_up_plan': data.get('follow_up_plan', ''),
            'lifestyle_advice': data.get('lifestyle_advice', []),
            'monitoring_schedule': data.get('monitoring_schedule', '')
        }
        
        # 计算风险等级
        risk_level = calculate_risk_level(ensemble_diagnosis_level, ensemble_confidence)
        
        # 创建诊断报告
        diagnosis_report = DiagnosisReport(
            image_analysis_id=analysis_id,
            patient_id=patient_id,
            patient_name=patient_name,
            patient_age=patient_age,
            patient_gender=patient_gender,
            ensemble_diagnosis_level=ensemble_diagnosis_level,
            ensemble_confidence=ensemble_confidence,
            report_content=str(report_content),
            recommendations=str(recommendations),
            risk_level=risk_level,
            follow_up_plan=data.get('follow_up_plan', '')
        )
        
        db.session.add(diagnosis_report)
        db.session.commit()
        
        return success_response({
            'report_id': diagnosis_report.id,
            'message': '报告创建成功',
            'report': diagnosis_report.to_dict()
        })
        
    except Exception as e:
        current_app.logger.error(f"创建报告失败: {str(e)}")
        db.session.rollback()
        return error_response(f'创建报告失败: {str(e)}', 500)
```

```python
            if isinstance(report.report_content, str):
                report_content = eval(report.report_content)
            else:
                report_content = report.report_content

            report_content = {}

                recommendations = report.recommendations
```

## 六、错误处理

### 6.1 常见错误类型

| 错误类型 | HTTP状态码 | 错误信息 | 处理方式 |
|---------|-----------|---------|---------|
| 缺少必需参数 | 400 | 缺少必需参数: xxx | 返回具体缺少的参数名称 |
| 图像分析记录不存在 | 404 | 图像分析记录不存在 | 检查analysis_id是否正确 |
| 报告已存在 | 409 | 该分析已经存在报告 | 同一分析只能有一个报告 |
| 报告不存在 | 404 | 报告不存在 | 检查report_id是否正确 |
| 数据库错误 | 500 | 创建/更新报告失败 | 回滚事务，返回错误信息 |
| 导出失败 | 500 | 导出报告失败 | 记录错误日志，返回错误信息 |

### 6.2 错误处理实现

**创建报告错误处理** (`backend/routes/reports.py:13-82`)
```python
@reports_bp.route('', methods=['POST'])

            if field not in data:
                return error_response(f'缺少必需参数: {field}', 400)
        
        # ... 其他逻辑 ...

        db.session.commit()
        
        return success_response({
```

## 七、性能与安全

### 7.1 性能优化
- 数据库索引：在 `image_analysis_id`、`patient_id`、`created_at` 字段上建立索引
- 分页查询：支持大数据量的报告列表查询
- 关联查询优化：使用join减少数据库查询次数
- 图像URL缓存：避免重复计算图像路径

### 7.2 安全措施
- 报告唯一性验证：防止同一分析创建多个报告
- 数据验证：严格的输入验证防止注入攻击
- 错误日志：记录详细的错误信息便于排查
- 事务管理：使用数据库事务确保数据一致性
- 敏感信息保护：患者信息加密存储
