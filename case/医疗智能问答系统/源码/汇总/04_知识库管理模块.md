# 知识库管理模块功能报告

## 1. 模块概述

### 1.1 功能定位
知识库管理模块是系统的核心组件之一，负责管理医学知识文档的存储、检索和向量化。该模块通过向量数据库技术实现语义搜索，为AI助手提供专业的医学知识支持，特别是糖尿病视网膜病变诊断相关的专业知识。

### 1.2 核心价值
- **专业知识库**: 集中存储和管理医学文献、临床指南、诊断标准等专业知识
- **智能检索**: 基于向量相似度的语义搜索，提供精准的知识匹配
- **多格式支持**: 支持TXT、PDF、DOCX、XLSX、PPTX等多种文档格式的导入
- **向量化存储**: 使用pgvector实现高效的向量存储和相似度计算

### 1.3 技术架构
```
知识库管理模块
├── 数据层
│   ├── SQLite: 存储知识库和文档元数据
│   └── PostgreSQL + pgvector: 存储向量数据
├── 业务层
│   ├── 知识库管理服务
│   ├── 文档管理服务
│   └── 向量管理服务
├── 处理层
│   ├── 文件处理器
│   └── 文本分割器
└── 接口层
    └── RESTful API
```

## 2. 核心功能说明

### 2.1 知识库管理
提供知识库的完整生命周期管理功能。

#### 2.1.1 创建知识库
- 支持自定义知识库名称和描述
- 可指定嵌入模型（如nomic-embed-text、bge-m3等）
- 自动生成唯一知识库ID
- 支持设置知识库状态（active/archived）

#### 2.1.2 查询知识库
- 支持分页查询知识库列表
- 提供按名称和描述的模糊搜索
- 支持按状态过滤
- 返回知识库统计信息（文档数、向量数等）

#### 2.1.3 更新知识库
- 支持修改知识库名称、描述
- 可更换嵌入模型
- 支持状态切换

#### 2.1.4 删除知识库
- 级联删除知识库下的所有文档
- 自动清理关联的向量数据
- 提供删除确认信息

### 2.2 文档管理
提供文档的创建、编辑、删除和查询功能。

#### 2.2.1 文档创建
- **手动录入**: 支持直接输入标题和内容创建文档
- **文件上传**: 支持上传多种格式的文件自动创建文档
- **批量导入**: 支持ZIP/TAR.GZ压缩包批量导入文档
- 自动提取文件元数据（文件名、类型、大小）
- 支持设置文档分类和标签

#### 2.2.2 文档查询
- 支持分页查询文档列表
- 提供按标题和内容的全文搜索
- 支持按状态、分类过滤
- 记录文档浏览次数

#### 2.2.3 文档更新
- 支持修改文档标题、内容、分类、标签
- 内容变更时自动触发重新向量化
- 支持文档状态切换

#### 2.2.4 文档删除
- 删除文档及其关联的向量数据
- 支持单个删除和批量删除

### 2.3 向量管理
提供文档向量化、存储和检索功能。

#### 2.3.1 文本分割
- 使用RecursiveCharacterTextSplitter进行智能分块
- 可配置块大小和重叠大小
- 支持中文和英文分隔符
- 默认参数：块大小1000字符，重叠200字符

#### 2.3.2 向量生成
- 调用外部嵌入API生成向量
- 支持OpenAI和Ollama两种API格式
- 自动处理API调用失败情况
- 支持多种嵌入模型（nomic-embed-text、bge-m3等）

#### 2.3.3 向量存储
- 使用PostgreSQL + pgvector存储向量数据
- 独立的向量数据库，与业务数据分离
- 存储文本块、向量、元数据
- 支持向量维度配置（默认1024维）

#### 2.3.4 相似度搜索
- 使用pgvector的余弦距离操作符进行相似度计算
- 支持设置相似度阈值
- 可限制搜索范围到指定知识库
- 返回最相关的文本块及其相似度分数

#### 2.3.5 混合搜索
- 结合向量搜索和SQL全文搜索
- 当向量搜索结果不足时补充SQL搜索结果
- 提供更全面的搜索覆盖

### 2.4 文件处理
提供多种文件格式的文本提取功能。

#### 2.4.1 支持的格式
- **文本文件**: TXT、MD
- **PDF文档**: 使用pypdf库提取文本
- **Word文档**: 使用python-docx库提取文本
- **Excel表格**: 使用openpyxl库提取表格数据
- **PowerPoint**: 使用python-pptx库提取幻灯片文本
- **压缩包**: ZIP、TAR.GZ批量导入

#### 2.4.2 文件验证
- 文件大小限制（50MB）
- 文件格式验证
- 压缩包有效性检查

#### 2.4.3 文本提取
- 自动识别文件编码（支持UTF-8、GBK、GB2312）
- 提取文档结构信息（页码、表格、幻灯片等）
- 处理特殊字符和格式

```python
def generate_embedding(self, text: str) -> Optional[List[float]]:
    """生成文本嵌入向量"""
    try:
        headers = {'Content-Type': 'application/json'}
        
        # 尝试Ollama风格
        payload_ollama = {
            'model': self.embedding_model,
            'prompt': text
        }
        resp = requests.post(self.embeddings_api_url, headers=headers, 
                           data=json.dumps(payload_ollama), timeout=30)
        
        if resp.status_code == 200:
            data = resp.json()
            if 'embedding' in data:
                return data['embedding']
        
        # 尝试OpenAI风格
        payload_openai = {
            'model': self.embedding_model,
            'input': text
        }
        resp2 = requests.post(self.embeddings_api_url, headers=headers, 
                            data=json.dumps(payload_openai), timeout=30)
        
        if resp2.status_code == 200:
            data2 = resp2.json()
            if 'data' in data2 and data2['data']:
                return data2['data'][0].get('embedding')
        
        return None
    except Exception as e:
        logger.error(f"Embedding generation failed: {e}")
        return None
```

#### 3.2.2 文本分割
```python
def split_text(self, text: str, chunk_size: Optional[int] = None, 
               chunk_overlap: Optional[int] = None) -> List[str]:
    """将文本分割成块"""
    cs = chunk_size or self.default_chunk_size
    co = chunk_overlap or self.default_chunk_overlap
    
    text_splitter = RecursiveCharacterTextSplitter(
        chunk_size=cs,
        chunk_overlap=co,
        length_function=len,
        separators=["\n\n", "\n", "。", "！", "？", ".", "!", "?", " ", ""]
    )
    
    chunks = text_splitter.split_text(text)
    return chunks
```

#### 3.2.3 相似度搜索
```python
def search_similar(self, query: str, kb_id: Optional[str] = None, 
                  limit: int = 10, similarity_threshold: float = 0.7) -> List[Dict[str, Any]]:
    """向量相似度搜索"""
    query_embedding = self.generate_embedding(query)
    if query_embedding is None:
        return []
    
    vector_session = get_vector_session()
    
    query_sql = text("""
        SELECT 
            dv.document_id,
            dv.kb_id,
            dv.chunk_text,
            dv.chunk_index,
            dv.meta_data,
            (1 - (dv.embedding <=> :query_embedding)) as similarity
        FROM document_vectors dv
        WHERE (:kb_id IS NULL OR dv.kb_id = :kb_id)
            AND (1 - (dv.embedding <=> :query_embedding)) >= :threshold
        ORDER BY dv.embedding <=> :query_embedding
        LIMIT :limit
    """)
    
    result = vector_session.execute(
        query_sql,
        {
            'query_embedding': str(query_embedding),
            'kb_id': kb_id,
            'threshold': similarity_threshold,
            'limit': limit * 3
        }
    )
    
    chunks = []
    for row in result:
        metadata = row.meta_data if isinstance(row.meta_data, dict) else {}
        chunks.append({
            'document_id': row.document_id,
            'kb_id': row.kb_id,
            'title': metadata.get('title', ''),
            'content': row.chunk_text,
            'category': metadata.get('category', ''),
            'author': metadata.get('author', ''),
            'chunk_index': row.chunk_index,
            'similarity': float(row.similarity),
            'search_type': 'vector'
        })
    
    chunks.sort(key=lambda x: x['similarity'], reverse=True)
    return chunks[:limit]
```

### 3.3 文件处理器实现

#### 3.3.1 PDF处理
```python
def process_pdf(self, file_path: str) -> str:
    """处理PDF文件"""
    reader = PdfReader(file_path)
    text_parts = []
    
    for page_num, page in enumerate(reader.pages, 1):
        try:
            text = page.extract_text()
            if text.strip():
                text_parts.append(f"--- 第 {page_num} 页 ---\n{text}")
        except Exception as e:
            logger.warning(f"PDF 第 {page_num} 页提取失败: {str(e)}")
            continue
    
    return "\n\n".join(text_parts)
```

#### 3.3.2 DOCX处理
```python
def process_docx(self, file_path: str) -> str:
    """处理DOCX文件"""
    doc = DocxDocument(file_path)
    text_parts = []
    
    # 提取段落文本
    for para in doc.paragraphs:
        text = para.text.strip()
        if text:
            text_parts.append(text)
    
    # 提取表格文本
    for table in doc.tables:
        for row in table.rows:
            row_text = []
            for cell in row.cells:
                cell_text = cell.text.strip()
                if cell_text:
                    row_text.append(cell_text)
            if row_text:
                text_parts.append(" | ".join(row_text))
    
    return "\n\n".join(text_parts)
```

## 5. 数据流程

### 5.1 文档创建和向量化流程
```
用户上传文件
    ↓
文件处理器提取文本
    ↓
创建文档记录（状态：draft）
    ↓
用户发布文档（状态：published）
    ↓
触发向量化
    ↓
文本分割器分割文本
    ↓
调用嵌入API生成向量
    ↓
存储向量到pgvector
    ↓
更新文档状态（vector_status：completed）
```

### 5.2 向量搜索流程
```
用户输入查询
    ↓
调用嵌入API生成查询向量
    ↓
pgvector执行相似度搜索
    ↓
返回最相关的文本块
    ↓
（可选）补充SQL全文搜索
    ↓
返回搜索结果
```

### 5.3 批量导入流程
```
用户上传压缩包
    ↓
验证压缩包格式
    ↓
解压到临时目录
    ↓
遍历所有文件
    ↓
验证文件格式
    ↓
提取文本内容
    ↓
创建文档记录
    ↓
触发向量化
    ↓
清理临时文件
    ↓
返回导入结果
```

## 6. 错误处理

### 6.1 常见错误类型

| 错误码 | 错误信息 | 处理方式 |
|--------|----------|----------|
| KB_NOT_FOUND | 知识库不存在 | 返回404错误 |
| DOC_NOT_FOUND | 文档不存在 | 返回404错误 |
| INVALID_FILE_FORMAT | 不支持的文件格式 | 返回400错误，列出支持的格式 |
| FILE_TOO_LARGE | 文件大小超过限制 | 返回400错误，提示大小限制 |
| EMBEDDING_FAILED | 向量生成失败 | 更新文档状态为failed，记录错误信息 |
| VECTOR_SEARCH_FAILED | 向量搜索失败 | 记录错误日志，返回空结果 |
| ZIP_INVALID | 无效的压缩文件 | 返回400错误 |

### 6.2 错误处理策略

#### 6.2.1 文件上传错误
- 验证文件格式和大小
