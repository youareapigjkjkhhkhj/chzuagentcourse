# 糖尿病视网膜病变诊断系统 - 相关知识表格

## 一、深度学习模型架构

| 模型名称               | 核心机制           | 关键创新                     | 优势                     |
| ---------------------- | ------------------ | ---------------------------- | ------------------------ |
| **CNN**                | 卷积操作+池化操作  | 局部感受野、权值共享         | 有效提取图像空间特征     |
| **ResNet**             | 残差连接(Shortcut) | 跳跃连接结构                 | 解决深层网络梯度消失问题 |
| **DenseNet**           | 密集连接           | 每层连接所有前驱层           | 特征复用、参数效率高     |
| **EfficientNet**       | 复合缩放           | 网络深度×宽度×分辨率协同放大 | 参数效率高、精度好       |
| **Vision Transformer** | 自注意力机制       | 图像分块+位置编码            | 全局依赖建模能力强       |

## 二、模型训练核心知识点

| 知识领域       | 关键概念                        | 技术要点                           |
| -------------- | ------------------------------- | ---------------------------------- |
| **数据处理**   | 数据采集、标注、清洗            | 公开数据集选择、标注流程、异常处理 |
| **类别不平衡** | 数据级、算法级解决方案          | 过采样、欠采样、类别权重调整       |
| **数据增强**   | 几何变换、像素变换              | 翻转、旋转、亮度调整、混合增强     |
| **超参数**     | 学习率、批量大小、Epoch         | 学习率衰减策略、Early Stopping     |
| **正则化**     | L1/L2、Dropout、Label Smoothing | 防止过拟合、提升泛化能力           |
| **交叉验证**   | K折、分层K折                    | 充分利用数据、可靠性能评估         |

## 三、模型评估指标

| 指标类型     | 具体指标                              | 适用场景             |
| ------------ | ------------------------------------- | -------------------- |
| **分类指标** | Accuracy, Precision, Recall, F1-Score | 多类别分类任务       |
| **概率指标** | AUC-ROC, PR曲线                       | 类别不平衡、概率输出 |
| **混淆矩阵** | TP/FP/TN/FN                           | 详细错误分析         |
| **医学指标** | Sensitivity, Specificity, Kappa值     | 临床诊断可靠性       |

## 四、糖尿病视网膜病变分级

| 等级    | 病变程度 | 特征描述             |
| ------- | -------- | -------------------- |
| **0级** | 无DR     | 无明显病变           |
| **1级** | 轻度NPDR | 仅有微动脉瘤         |
| **2级** | 中度NPDR | 微动脉瘤外可见病变   |
| **3级** | 重度NPDR | 符合4-3-2规则        |
| **4级** | PDR      | 新生血管或玻璃体出血 |

## 五、实验设计方法

| 实验类型       | 设计目的       | 常用方法                 |
| -------------- | -------------- | ------------------------ |
| **消融实验**   | 验证各模块贡献 | 逐个移除/添加组件        |
| **对比实验**   | 与SOTA方法比较 | 统一数据集、相同评估标准 |
| **鲁棒性实验** | 验证模型稳定性 | 噪声干扰、质量退化测试   |
| **推理速度**   | 评估部署可行性 | FPS、延迟时间、参数量    |

## 六、系统核心流程

```
图像输入 → 图像质量评估 → 预处理(ROI裁剪) → 模型推理 → 后处理 → 诊断结果
```
