# 糖尿病视网膜病变智能辅助诊断系统 - 实验报告

## 一、实验背景与目标

### 1.1 研究背景

糖尿病视网膜病变（Diabetic Retinopathy, DR）是糖尿病最严重的微血管并发症之一，已成为工作年龄人群致盲的首要病因。据统计，全球约有5亿糖尿病患者，其中约三分之一会发展为不同程度的视网膜病变。早期筛查和及时干预对于预防视力丧失具有重要意义。然而，传统的人工眼底检查方法存在眼科医师资源稀缺、诊断主观性强、效率低下等问题，难以满足大规模筛查的需求。深度学习技术的快速发展为眼底图像自动化分析提供了新的技术路径，本研究旨在构建基于深度卷积神经网络的糖尿病视网膜病变智能辅助诊断系统。

### 1.2 实验目标

本实验的核心目标是构建并评估多种深度学习模型在糖尿病视网膜病变五级分类任务上的性能表现。具体而言，实验围绕以下几个维度展开：首先，系统性地比较不同深度学习骨干网络（包括传统卷积神经网络和新兴的Transformer架构）的分类性能；其次，分析各模型在医学诊断场景下的可靠性指标，特别是加权Kappa系数这一关键评价标准；再次，评估模型的推理效率，为后续的临床部署提供决策依据；最后，通过模型可解释性分析，探究模型决策的依据，增强临床应用的可信度。

### 1.3 数据集描述

本实验采用APTOS 2019公开数据集作为研究对象，该数据集包含大量真实临床环境采集的眼底图像。每张图像均由专业眼科医师依据国际标准进行标注，标注结果涵盖五个等级：无糖尿病视网膜病变（0级）、轻度非增殖性DR（1级）、中度非增殖性DR（2级）、重度非增殖性DR（3级）和增殖性DR（4级）。数据集的类别分布呈现明显的不平衡特征，各类别的样本数量分别为1805例、370例、999例、193例和295例。这种不平衡分布对模型训练和评估都带来了额外的挑战，需要在损失函数设计和评估指标选择上予以特别考虑。

## 二、实验设计与方法

### 2.1 骨干网络选择与对比

本实验选取了七种具有代表性的深度学习模型作为研究对象，涵盖了从传统卷积神经网络到最新Transformer架构的多种技术路线。选择这些模型的理由如下：

**ResNet系列**（ResNet50和ResNet152）是深度学习发展史上的里程碑式工作，通过引入残差连接（Shortcut Connection）有效解决了深层网络梯度消失的问题，使得训练更深的网络成为可能。ResNet50包含50层网络结构，参数量约为23M，在图像分类任务上具有良好的性能表现。ResNet152则是更深层次的变体，包含152层网络，通过更深的网络结构尝试捕获更复杂的图像特征。

**DenseNet系列**（DenseNet121）采用密集连接机制，每一层都与之前的所有层直接相连，实现了特征复用，能够以更少的参数达到与其他网络相当甚至更好的性能。DenseNet121包含121层网络，其独特的连接方式使得梯度能够更直接地传播到浅层网络，有助于训练过程的稳定性。

**EfficientNet系列**（EfficientNet-B3、B5、B8）是当前卷积神经网络效率优化的典范之作。该系列模型通过神经架构搜索（Neural Architecture Search）和复合缩放策略（Compound Scaling）联合优化网络的深度、宽度和输入分辨率，实现了参数量与精度的最佳平衡。EfficientNet-B3参数量约为12M，B5约为30M，B8约为88M，为不同计算资源条件下的部署提供了灵活选择。

**Vision Transformer**（ViT-Base-Patch16-224）代表了深度学习从卷积范式向注意力机制范式转变的最新趋势。该模型将图像分割为固定大小的图块（Patch），通过自注意力机制（Self-Attention）建模全局依赖关系，在大规模预训练数据集上展现出了优异的性能。本实验采用16×16像素的图块划分策略，输入图像尺寸为224×224像素。

### 2.2 模型训练配置

实验采用统一的训练配置以确保对比的公平性。核心超参数设置如下：随机种子固定为42以保证实验的可复现性；输入图像统一Resize至256×256像素后进行中心裁剪至224×224像素；批量大小（Batch Size）设置为32；训练轮次（Epoch）设置为50；初始学习率设为1e-4，采用余弦退火策略进行动态调整；优化器选用AdamW，权重衰减系数设为0.05以实现正则化效果；采用早停策略（Patience=15）防止过拟合。

数据预处理方面，实验采用Albumentations库实现图像增强。基础预处理包括CLAHE（对比度受限自适应直方图均衡化）用于增强眼底图像的局部对比度、Resize操作统一图像尺寸、以及基于ImageNet统计量的标准化处理。训练阶段还应用了随机翻转、随机旋转等数据增强策略以提升模型的泛化能力。

考虑到数据集中存在的类别不平衡问题，实验采用加权交叉熵损失函数。各类别的权重根据其在数据集中的频率进行设定，频率越低的类别获得越高的权重，以此来缓解模型对多数类的偏好。

### 2.3 模型评估指标

医学诊断模型的评估需要综合考虑多个维度的性能指标。本实验选取了以下几类评估指标：

**准确率（Accuracy）** 是最基本的分类性能指标，衡量模型正确预测的样本占总样本的比例。然而，在类别不平衡的场景下，准确率可能产生误导性结果，因此需要结合其他指标综合评估。

**二次加权Kappa系数（Quadratic Weighted Kappa, QWK）** 是本实验最重要的评价指标。该指标考量了预测类别与真实类别之间的不一致程度，并对不一致的程度进行加权惩罚。相邻类别之间的不一致（如将1级预测为2级）受到的惩罚较轻，而相差较远类别之间的不一致（如将0级预测为4级）受到的惩罚较重。这一特性使得QWK特别适合有序分类任务，如本研究的五级DR分类任务。一般认为，QWK系数大于0.8表示模型具有几乎完美的诊断一致性，0.6-0.8之间表示实质性一致，0.4-0.6之间表示中等一致性。

**分类报告（Classification Report）** 提供每个类别的精确率（Precision）、召回率（Recall）和F1-Score，帮助识别模型在哪些类别上表现较好、在哪些类别上存在不足。

**混淆矩阵（Confusion Matrix）** 以矩阵形式直观展示各真实类别被预测为各类别的分布情况，是分析模型错误模式的重要工具。

**推理效率指标** 包括模型参数量（Parameters，单位：百万）和单张图像推理时间（Inference Time，单位：毫秒）。这两个指标直接影响模型的部署可行性和实际应用成本。

### 2.4 模型可解释性分析

为增强模型决策的可解释性并为临床医师提供参考，本实验采用Grad-CAM（Gradient-weighted Class Activation Mapping）技术生成热力图，可视化模型在做出预测时关注的图像区域。Grad-CAM通过计算目标类别相对于最后一层卷积特征图的梯度，生成与输入图像尺寸相同的类激活映射图，直观展示模型"看"到了什么位置的信息。

## 三、实验结果与分析

### 3.1 整体性能对比

七种模型在验证集上的核心性能指标对比如下表所示：

| 模型            | QWK    | Accuracy | 参数量(M) | 推理时间(ms) |
| --------------- | ------ | -------- | --------- | ------------ |
| EfficientNet-B8 | 0.8751 | 80.87%   | 84.6      | 42.9         |
| EfficientNet-B3 | 0.8692 | 81.42%   | 10.7      | 18.8         |
| EfficientNet-B5 | 0.8689 | 79.78%   | 28.4      | 27.5         |
| ResNet50        | 0.8535 | 80.87%   | -         | -            |
| ResNet152       | 0.8593 | 79.78%   | -         | -            |
| DenseNet121     | 0.8257 | 75.96%   | -         | -            |
| ViT-Base        | 0.8273 | 74.32%   | -         | -            |

从综合性能来看，EfficientNet系列模型表现最为优异，其中EfficientNet-B8以0.8751的QWK系数位居首位，展现出复合缩放策略在大规模模型上的优势。EfficientNet-B3以更少的参数量（仅10.7M）和更快的推理速度（18.8ms）达到了与B8相当的性能水平（QWK=0.8692），体现了该系列模型优秀的效率-精度权衡特性。EfficientNet-B5则处于两者之间，提供了另一种资源配置选择。

ResNet系列模型表现稳健，ResNet50和ResNet152的QWK系数分别达到0.8535和0.8593。值得注意的是，更深的ResNet152并未带来显著的性能提升，反而在准确率指标上略低于ResNet50，这可能与数据量有限导致的过拟合风险有关。

DenseNet121作为参数量效率最高的网络之一，在本任务上的QWK系数为0.8257，略低于其他模型。这可能与其特征复用的机制在有限数据集上未能充分发挥优势有关。

Vision Transformer（ViT-Base）在本任务上的表现相对较弱，QWK系数为0.8273，低于大多数卷积神经网络。这一结果印证了在中小规模数据集上，Transformer架构可能不如经过充分优化的卷积网络，同时也暗示了针对医学图像领域进行预训练的重要性。

### 3.2 分类性能详细分析

为深入理解各模型在不同DR等级上的表现差异，实验对各模型的分类报告进行了详细分析。以DenseNet121为例进行说明：

- **0级（无DR）**：精确率95%，召回率92%，F1-Score 0.94。模型在该类别上表现优异，这与该类别样本量最大、特征最为明显有关。
- **1级（轻度NPDR）**：精确率40%，召回率57%，F1-Score 0.47。该类别是模型表现最差的类别之一，主要原因是轻度病变的特征不够显著，容易与无病变类别混淆。
- **2级（中度NPDR）**：精确率71%，召回率70%，F1-Score 0.71。模型在该类别上的表现尚可，但存在与相邻类别（1级和3级）相互混淆的情况。
- **3级（重度NPDR）**：精确率42%，召回率65%，F1-Score 0.51。该类别样本量最少（仅20例），模型难以学习到足够的判别特征。
- **4级（增殖性DR）**：精确率89%，召回率28%，F1-Score 0.42。虽然精确率较高，但召回率极低，说明模型倾向于将真正的增殖性DR误判为其他等级，这是临床应用中需要特别关注的问题。

EfficientNet-B3在各类别上的表现整体优于DenseNet121，特别是在中度NPDR（召回率83%）和增殖性DR（召回率45%）类别上有明显提升。然而，轻度NPDR和重度NPDR仍然是所有模型的共同难点，需要进一步优化。

### 3.3 混淆矩阵分析

混淆矩阵揭示了模型预测错误的模式。从所有模型的混淆矩阵可以观察到以下共性规律：

**相邻类别混淆**：最常见的错误模式是将真实类别预测为相邻的等级。例如，1级（轻度）经常被误判为0级（无）或2级（中度），2级（中度）经常被误判为1级（轻度）或3级（重度）。这种错误模式是合理的，因为相邻等级之间的眼底病变特征确实存在一定的相似性和过渡性。

**边界病例误判**：0级与1级之间的混淆尤为频繁，部分"临界"病例（具有极轻微病变特征但尚未达到诊断标准）存在标注一致性问题，这可能是模型难以学习的主要原因。

**罕见类别漏检**：3级（重度）和4级（增殖性）样本量较少，模型对这些类别的召回率普遍较低。增殖性DR作为最严重的病变等级，其特征（如新生血管、玻璃体出血）本应非常明显，但模型召回率不足30%，这是需要重点改进的方向。

### 3.4 推理效率分析

在实际临床应用中，模型的推理效率直接影响其部署成本和用户体验。实验对各模型的推理时间进行了测试，结果如下：

| 模型            | 推理时间(ms) | 参数量(M) | 效率评级 |
| --------------- | ------------ | --------- | -------- |
| EfficientNet-B3 | 18.8         | 10.7      | 最佳     |
| EfficientNet-B5 | 27.5         | 28.4      | 良好     |
| EfficientNet-B8 | 42.9         | 84.6      | 一般     |
| ResNet50        | -            | -         | -        |
| ResNet152       | -            | -         | -        |
| DenseNet121     | -            | -         | -        |
| ViT-Base        | -            | -         | -        |

EfficientNet-B3在推理效率上具有显著优势，单张图像推理时间仅为18.8毫秒，能够支持每秒50帧以上的实时处理需求。结合其优异的分类性能（QWK=0.8692，Accuracy=81.42%），EfficientNet-B3是本实验中综合性价比最高的模型，适合作为临床部署的首选方案。

EfficientNet-B5和B8的推理时间分别为27.5ms和42.9ms，虽然性能略有提升，但推理成本的增加与性能提升不成比例，在资源受限的边缘设备上可能不具备优势。

### 3.5 模型可解释性分析

Grad-CAM热力图分析显示，不同模型在学习眼底图像特征方面存在一定差异。大多数模型能够聚焦于眼底图像的特定区域，如视盘、黄斑、血管异常区域等，这对于临床医师理解模型决策具有重要参考价值。

典型案例分析表明，对于0级（无DR）病例，模型通常不会在特定区域产生强烈激活，这与预期一致。对于存在明显病变（如微动脉瘤、硬性渗出、棉絮斑）的病例，模型能够在相应区域产生明显的激活响应，显示出一定的病变检测能力。

然而，热力图分析也揭示了一些值得注意的问题。部分病例中，模型的激活区域与实际病变位置存在偏差，这可能解释了某些误判案例的原因。此外，对于边界模糊的病例，模型的激活模式较为弥散，反映出在这些困难案例上的决策不确定性。

## 四、讨论

### 4.1 模型选择建议

基于本实验的综合分析，针对不同的应用场景，提出以下模型选择建议：

**高性能优先场景**：若计算资源充足且对诊断准确性要求极高，可选择EfficientNet-B8。该模型在本实验中取得了最高的QWK系数（0.8751），能够提供最可靠的诊断参考。但需要注意其较大的模型体积和较长的推理时间。

**平衡优先场景**：若需要在诊断性能和资源消耗之间取得平衡，EfficientNet-B3是最佳选择。该模型以仅10.7M的参数量实现了QWK=0.8692的优异性能，推理速度最快，适合大规模筛查场景和边缘设备部署。

**轻量化场景**：若需要在移动设备或嵌入式系统上运行，可考虑对EfficientNet-B3进行进一步压缩（如知识蒸馏、剪枝等），或者选用更轻量的MobileNet、ShuffleNet等架构。

### 4.2 存在的问题与改进方向

本实验揭示了当前模型存在的若干问题，也指明了后续改进的方向：

**类别不平衡问题**：尽管采用了加权损失函数，模型在罕见类别（特别是3级和4级）上的表现仍然不理想。未来的改进方向包括：采用更先进的数据重采样策略（如SMOTE）、引入焦点损失（Focal Loss）降低易分类样本的权重、以及通过数据增强增加罕见类别的训练样本。

**边界病例区分能力不足**：0级与1级、2级与3级之间的混淆问题反映模型对边界病例的区分能力有限。未来的改进方向包括：引入对比学习增强特征判别能力、采用序数回归（Ordinal Regression）替代普通分类、以及引入不确定性估计机制对边界病例进行标记。

**小样本问题**：3级和4级样本量较少，限制了模型学习这些关键类别判别特征的能力。未来的改进方向包括：引入域自适应技术从其他眼底图像数据集迁移知识、采用自监督预训练提升特征提取能力、以及探索小样本学习方法。

**模型可解释性**：虽然Grad-CAM提供了一定的可解释性，但其解释能力有限。未来的改进方向包括：采用更精细的可解释性方法（如积分梯度、注意力可视化）、引入概念瓶颈模型将医学知识嵌入网络结构、以及开发针对医学影像的专门解释工具。

### 4.3 临床应用可行性

从实验结果来看，基于深度学习的DR诊断模型已经展现出辅助临床诊断的潜力。在常见类别（0级、2级）的识别上，模型达到了较高的准确性，能够有效辅助初级筛查工作。然而，在罕见类别和边界病例上，模型的可靠性仍需提升，短期内无法完全替代专业眼科医师的诊断。

建议的临床应用模式是"AI初筛+医师复核"。AI模型负责大规模筛查和初步分级，将高风险病例和边界病例优先推送给眼科医师进行复核，既能提高筛查效率，又能确保诊断质量。

## 五、实验结论

本实验系统性地评估了七种深度学习模型在糖尿病视网膜病变五级分类任务上的性能表现，得出以下主要结论：

1. **EfficientNet系列模型在本任务上表现最优**，其中EfficientNet-B3以优秀的效率-精度权衡特性成为最具实用价值的模型选择，EfficientNet-B8则以最高的诊断一致性系数（QWK=0.8751）代表了当前最佳性能。

2. **Vision Transformer在本任务上的表现未达预期**，可能需要更大规模的预训练数据集或针对医学图像的领域适应策略来充分释放其潜力。

3. **类别不平衡是影响模型性能的关键因素**，特别是3级（重度）和4级（增殖性）病变的识别召回率普遍较低，需要专门针对这些罕见类别进行优化。

4. **推理效率与诊断性能之间存在权衡**，但EfficientNet系列模型成功地在较高诊断性能的前提下保持了较快的推理速度，为临床部署提供了可行性。

5. **模型可解释性分析显示**，大多数模型能够聚焦于与病变相关的图像区域，为临床医师理解模型决策提供了参考。
