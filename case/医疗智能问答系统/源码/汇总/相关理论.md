第二章 相关理论与技术基础
2.1 糖尿病及其并发症概述
2.1.1 糖尿病分型与诊断标准
糖尿病是一类由胰岛素分泌不足、胰岛素作用受损或两者共同作用导致的慢性代谢性疾病，其核心特征为持续性高血糖。根据病因及发病机制，国际医学界通常将糖尿病分为四类，即Ⅰ型糖尿病、Ⅱ型糖尿病、妊娠期糖尿病以及其他特殊类型糖尿病。其中，Ⅱ型糖尿病是最常见的类型，其发病与遗传、环境、生活方式等多因素相关。
临床上糖尿病的诊断依据国际糖尿病联盟（IDF）和世界卫生组织（WHO）的标准，主要包括以下指标：
（1）空腹血糖（FPG）≥7.0 mmol/L；
（2）口服葡萄糖耐量试验（OGTT）2 小时血糖≥11.1 mmol/L；
（3）随机血糖≥11.1 mmol/L，伴典型临床症状；
（4）糖化血红蛋白（HbA1c）≥6.5%。
这些指标为临床提供了明确的诊断依据，可用于糖尿病的初筛与确诊。
随着生活方式变化和人口老龄化趋势加剧，全球糖尿病患病率持续上升。由于其早期症状不典型，部分患者往往在出现并发症后才被诊断，因此提高糖尿病及其并发症的早期识别显得尤为重要。
2.1.2 糖尿病主要并发症
糖尿病若未得到有效控制，长期高血糖会损伤全身多个系统的微血管和大血管，进而引发一系列并发症。这些并发症大体可分为急性并发症和慢性并发症两类，其中慢性并发症对患者健康和生活质量影响更为深远。
（1）心血管疾病
糖尿病患者患冠心病、心肌梗死和脑血管疾病的风险显著高于普通人群。高血糖状态会导致血管内皮功能受损，加速动脉粥样硬化的形成，是糖尿病患者主要致死原因之一。
（2）糖尿病肾病
肾脏微血管长期处于高血糖环境中，易导致滤过功能下降，逐渐发展为蛋白尿、肾小球硬化，最终可能进展为终末期肾病。糖尿病肾病是全球范围内导致透析治疗的重要原因。
（3）糖尿病神经病变
包括周围神经病变和自主神经病变，表现为肢体麻木、刺痛、冷热感觉减退、胃肠功能障碍等。长期神经损伤会增加足部溃疡和截肢风险。
（4）糖尿病视网膜病变（Diabetic Retinopathy, DR）
糖尿病视网膜病变是本课题重点关注的并发症。它是由于视网膜微血管长期受高血糖影响而出现病理性改变，包括微动脉瘤、出血点、渗出物、棉絮斑以及新生血管形成等。DR 的发展通常经历非增殖期（NPDR）和增殖期（PDR）两个阶段，前期症状较隐匿，往往在严重阶段才引起明显视力下降。一旦出现新生血管破裂或玻璃体出血，可能导致不可逆的视力损伤甚至失明。
全球范围内，DR 已成为成人视力损伤的主要原因之一。由于其早期症状缺乏典型表现，依赖定期眼底检查进行早期筛查是控制病程的关键。然而实际临床中，眼底图像判读对专业经验要求较高，人工筛查耗时较长，因此对自动化、智能化的辅助诊断技术需求日益增长。
糖尿病及其并发症具有高患病率、高危害性和隐匿性等特点，加强对 DR 的早期识别和干预具有重要意义，也为本研究开展基于机器学习的辅助诊断系统建设提供了现实需求基础。
2.2 机器学习基础
机器学习作为人工智能的重要分支，主要研究如何从数据中学习规律并进行预测或决策。在医学图像分析任务中，机器学习技术能够通过对大量样本的学习提取关键信息，有效辅助疾病的自动筛查和识别。本节介绍监督学习的基本概念，并对常用的机器学习方法进行说明，为后续模型构建奠定理论基础。
2.2.1 监督学习基本概念
监督学习是机器学习中应用最广泛的方法之一，其基本思想是在已标注的样本数据集基础上，通过训练过程学习输入与输出之间的映射关系。对于给定的输入特征X和对应的标签Y，监督学习的目标是构建一个函数f(X)，使其在面对未见过的新样本时能够给出尽可能准确的预测结果。
监督学习任务主要分为分类和回归两类：
（1）分类任务：输出为离散类别，如糖尿病视网膜病变分级任务中，模型需要判断眼底图像属于哪一等级；
（2）回归任务：输出为连续数值，如预测疾病风险评分等。
监督学习的核心步骤通常包括数据预处理、特征选择、模型训练、模型验证和性能评估。在医学诊断中，由于数据维度高、噪声多、样本不均衡等问题，如何通过合理的训练策略提升模型鲁棒性是关键环节。
2.2.2 常用机器学习算法简介
在早期医学图像处理任务中，传统机器学习算法凭借其计算效率高、易解释的特点得到广泛应用。尽管深度学习在近年来成为主流，但这些传统算法在某些场景中依然具有参考价值。本节选取几种典型算法进行概述。
（1）逻辑回归（Logistic Regression）
逻辑回归是一种常用于二分类问题的统计学习方法，通过将线性组合的特征映射到 Sigmoid 函数，实现输出为概率值的分类结果。其优点是模型简单、可解释性强，易于分析各特征对预测结果的影响。在疾病筛查等二分类任务中，逻辑回归常作为基线模型进行对比。
（2）支持向量机（Support Vector Machine, SVM）
SVM 通过构建最大间隔超平面来实现分类，具有较强的泛化能力。在处理高维、小样本数据时效果较好，并可通过引入核函数应对非线性问题。SVM 在医学图像分类中曾广泛应用，但其训练成本较高，对大规模数据的扩展能力有限。
（3）决策树（Decision Tree）
决策树是一种基于树状结构的分类与回归方法，通过递归地选择特征划分数据，使得样本在叶节点得到分类结果。该方法结构直观、易解释，但容易出现过拟合现象。为提升性能，常结合剪枝或集成学习策略进行改进。
（4）随机森林（Random Forest）
随机森林由多棵决策树构成，通过集成学习思想提升模型的稳定性和准确性。其对异常值和噪声具有较强的鲁棒性，适用于特征维度高、样本量较大的任务。在医学数据分析中，随机森林常用于特征筛选和分类预测。
（5）梯度提升树（XGBoost 等）
XGBoost 是一种基于梯度提升思想的集成模型，通过对弱学习器进行逐步优化，获得较高的预测性能。相比传统 boosting 方法，XGBoost 在正则化、并行计算和缺失值处理方面进行了改进，因此在多种结构化数据任务中表现优异。在医学数据建模中，它常用于疾病风险预测和诊断辅助决策。
传统机器学习方法在医疗数据分析中具有重要作用，但在处理高维图像数据时往往需要人工设计特征。随着深度学习的发展，模型能够自动从图像中学习多层次特征，使得其在医学图像分类任务中展现出更大优势。本章后续将进一步介绍深度学习相关理论，为图像诊断模型的构建提供支持。
2.3 深度学习与神经网络基础
深度学习是近年来人工智能发展的重要方向，通过多层结构的神经网络实现对数据特征的自动提取与表示学习。与传统机器学习依赖人工特征工程不同，深度学习可以直接从原始数据中学习层次化特征，特别适用于图像、音频等复杂数据的处理。在医学图像分析领域，深度学习凭借其强大的特征表达能力，已成为辅助诊断系统的核心技术之一。
2.3.1 神经网络基本原理
人工神经网络（Artificial Neural Network, ANN）由多层神经元组成，包括输入层、隐藏层和输出层。每个神经元通过加权求和和激活函数完成对输入特征的非线性变换。典型的神经元计算过程可表示为：
y=f(Wx+b)
其中，x为输入向量，W为权重矩阵，b为偏置，f(⋅)为激活函数（如 ReLU、Sigmoid、Tanh等）。通过多层结构的堆叠，神经网络能够学习从低级到高级的特征表示。
神经网络训练过程通常采用梯度下降及其变体（如 Adam、RMSprop 等）进行参数更新。通过反向传播算法计算梯度，使得网络在训练数据上逐步减少损失函数，提高预测准确度。随着网络层数的增加，模型表征能力显著增强，但也面临梯度消失、过拟合等挑战，因此需要合理的网络设计和正则化策略。
2.3.2 卷积神经网络原理与结构
卷积神经网络（Convolutional Neural Network, CNN）是深度学习中最常用于图像处理的网络结构。与全连接网络相比，CNN 通过卷积操作实现权值共享和局部连接，有效降低模型参数数量并保留图像的空间结构信息。
CNN 的核心结构包括卷积层、池化层和全连接层：
卷积层（Convolution Layer）：通过卷积核在图像上滑动，实现局部特征提取，如边缘、纹理等。在深层网络中，卷积核可逐渐捕捉更高级的语义信息。
池化层（Pooling Layer）：用于降维和特征压缩，提高模型的计算效率和鲁棒性。常用的池化方式包括最大池化和平均池化。
全连接层（Fully Connected Layer）：通常位于网络末端，用于综合已有特征并完成分类任务。
典型的 CNN 模型包括 AlexNet、VGG、ResNet、DenseNet 和 EfficientNet 等。其中，ResNet 通过引入残差连接解决深层网络训练困难的问题；DenseNet 通过特征层间的直接连接促进信息流动；EfficientNet 则通过复合缩放方法实现模型性能与计算效率的均衡。这些模型在医学图像分类任务中均取得了良好效果，是本课题的重要参考架构。
2.3.3 Transformer模型原理简介
近年来，Transformer 模型逐渐应用于计算机视觉任务，并形成视觉 Transformer（Vision Transformer, ViT）等结构。与 CNN 强调局部感受野不同，Transformer 通过自注意力机制（Self-Attention）建模图像区域之间的长距离依赖关系，使得模型在理解整体结构和全局特征方面具有优势。
ViT 的主要处理流程包括：
将图像划分为固定大小的图像块（patch），并将其线性映射到向量空间；
结合位置编码（Position Embedding）保持图像空间信息；
使用多头自注意力机制处理所有图像块，实现全局特征提取；
通过多层 Transformer 编码器获取最终特征表示，并用于分类输出。
在医学图像分析中，视觉 Transformer 展现出优异的泛化能力和特征表达能力，尤其在高分辨率图像处理方面具有明显优势，因此逐渐成为与 CNN 并行发展的重要方向。
本课题主要基于卷积神经网络（CNN）架构（EfficientNet、ResNet、DenseNet）进行糖尿病视网膜病变分级研究。CNN 在医学图像分析领域具有成熟的应用基础，其局部感受野和权值共享机制特别适合捕捉眼底图像中的局部病变特征（如微动脉瘤、出血点等）。
2.3.4 模型评估指标
为了评估深度学习模型在医学诊断任务中的表现，常使用以下指标：
准确率（Accuracy）：反映整体预测正确的比例。
精确率（Precision）：表示模型预测为阳性中真正阳性的比例。
召回率（Recall）：衡量模型对阳性样本的识别能力。
F1 值（F1-score）：精确率与召回率的调和平均。
AUC-ROC（曲线下面积）：衡量模型在不同阈值下的分类性能。
2.4 Web开发技术栈
在构建基于机器学习的糖尿病辅助诊断系统过程中，Web 技术为系统提供了数据交互、界面呈现和服务部署的基础支撑。合理选择前后端开发框架及数据库技术，是保证系统稳定性、可用性和扩展性的关键。本节将介绍本课题涉及的主要 Web 技术栈及其特点。
2.4.1 前端框架
前端部分主要负责用户界面呈现与交互逻辑设计。本课题采用 React 18 框架，通过组件化思想和虚拟 DOM 技术构建用户界面。
React 由 Facebook 开发并维护，采用声明式编程范式，通过组件化方式组织代码结构。其核心特性包括：
（1）虚拟 DOM 机制：通过在内存中维护虚拟 DOM 树，对比前后状态差异后批量更新真实 DOM，显著提高页面渲染性能；
（2）组件化架构：将界面拆分为独立、可复用的组件，每个组件管理自身状态，便于开发和维护；
（3）丰富的生态系统：配合 TypeScript 提供类型安全，使用 Vite 作为构建工具提升开发效率，采用 Tailwind CSS 进行样式管理，集成 Framer Motion 实现流畅的交互动画。
在医疗诊断场景中，React 能够为医生界面提供快速响应和流畅操作体验，尤其在处理图像上传、诊断结果展示、历史记录查询等多模块信息时具有优势。本系统前端技术栈包括 React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion。
2.4.2 后端框架
后端主要承担业务逻辑处理、数据管理和模型服务调用等功能，是整个系统的核心组成部分。本课题采用 Flask 轻量级 Python Web 框架。
Flask 是一个微框架，设计简洁、扩展性强，核心特性包括：
（1）轻量灵活：只提供核心功能（路由、请求处理、模板渲染），其他功能通过扩展实现，开发者可根据需求自由组合；
（2）易于集成：特别适合部署深度学习模型，能够方便地加载 PyTorch 模型并提供 RESTful API 接口；
（3）丰富的扩展生态：通过 Flask-SQLAlchemy 实现 ORM 数据库操作，Flask-JWT-Extended 提供身份认证，Flask-CORS 处理跨域请求。
在本课题中，Flask 负责处理图像上传、模型推理调用、诊断报告生成、AI 助手对话等核心业务逻辑。系统采用 RESTful API 设计规范与前端交互，通过 SQLAlchemy ORM 进行数据库操作，实现前后端分离架构下的高效数据交换。
2.4.3 数据库技术
数据库是系统中用于存储用户信息、图像记录、诊断结果和知识库内容的重要部分。本课题采用混合数据存储方案，结合关系型数据库和向量数据库满足不同数据类型的存储需求。
（1）SQLite 关系型数据库
SQLite 是一种嵌入式关系型数据库，具有零配置、轻量级、单文件存储等特点。其优势在于：
- 无需独立的数据库服务器进程，直接以文件形式存储数据；
- 支持标准 SQL 语法和事务管理，满足 ACID 特性；
- 适合开发和中小型应用场景，部署简单便捷。
在本课题中，SQLite 用于存储用户信息、图像分析记录、诊断报告、AI 对话历史等结构化数据。
（2）pgvector 向量数据库
pgvector 是 PostgreSQL 的扩展插件，为数据库添加向量相似度搜索能力。其核心特性包括：
- 支持高维向量存储（最多 16000 维）；
- 提供余弦相似度、欧氏距离等多种相似度计算方法；
- 支持向量索引（IVFFlat、HNSW）加速检索。
在本课题中，pgvector 用于存储医学知识库文本的向量表示（Embedding），支持基于语义相似度的知识检索，为 RAG-based AI 助手提供向量检索能力。
本系统采用 SQLite + pgvector 的混合存储架构，兼顾结构化数据的完整性和语义检索的灵活性。
2.5 医学图像处理基础
医学图像处理是利用计算机技术对医学图像进行分析、增强和特征提取的过程，是构建视觉辅助诊断系统的重要前提。对于糖尿病视网膜病变的自动识别任务而言，图像质量参差不齐、结构复杂、病灶细微等特点，使得有效的图像处理尤为关键。本节将从医学图像的基本特性、常见图像格式以及图像预处理方法等方面进行介绍。
2.5.1 医学图像常见格式与特点
医学图像来源多样，包括放射影像（如 X 光、CT、MRI）、超声图像、病理切片图像以及数字化眼底图像等。不同成像方式具有不同的物理原理、分辨率和噪声特性，因此图像处理方法需要结合具体场景进行调整。
在眼底图像分析中，常见图像格式主要包括 JPEG、PNG 以及医学领域常见的 DICOM（Digital Imaging and Communications in Medicine）格式。其中：
JPEG 格式：压缩率高，存储空间占用小，是公开数据集中最常见的图像格式，但可能存在轻微压缩损失。
PNG 格式：无损压缩，图像质量较高，在需要保持细节特征的医学分析中较为常用。
DICOM 格式：包含图像及大量医疗相关元数据（如成像设备参数、患者信息等），是一种标准化医疗图像格式。
眼底图像的特点包括分辨率高、色彩信息丰富、病灶区域细小、光照变化明显等。由于拍摄设备和操作方式的差异，眼底照片可能出现亮度不均匀、模糊、遮挡等问题，这些因素都会影响后续模型的诊断效果，因此在模型训练前对图像进行规范化处理十分必要。
2.5.2 图像预处理技术
图像预处理是提升模型性能的重要步骤，旨在改善原始图像质量、突出关键特征并减少噪声干扰。常用的预处理方法包括以下几类：
（1）图像标准化（Normalization）
标准化常用于调整图像亮度与对比度，使图像在不同来源或不同拍摄条件下保持较为一致的视觉特性。常见方法包括：
灰度归一化：将像素值映射到统一范围（如 0–1 或 0–255），确保输入特征尺度一致。
亮度均衡（如 CLAHE）：通过局部直方图均衡增强图像对比度，使血管、渗出物等细节更加突出。
这些处理能够减轻环境光照对模型的影响，使特征提取过程更加稳定。
（2）图像增强（Data Augmentation）
为了提高模型的泛化能力，常使用图像增强方法通过人为变换生成更多样式的训练样本。常见增强方式包括：
随机翻转、旋转；
随机裁剪、缩放；
颜色抖动（亮度、饱和度调整）；
高斯噪声扰动。
在医学场景中，增强方法需保持病灶结构不被破坏，因此增强幅度通常较为谨慎。适当的数据增强可有效减少过拟合并提升模型对不同来源图像的适应能力。
医学图像处理在糖尿病视网膜病变的自动诊断系统中具有基础性作用。合理的格式选择与科学的预处理方式不仅能够提升图像质量，还能增强深度学习模型的稳定性和诊断性能，为后续模型构建与系统开发提供支持。
