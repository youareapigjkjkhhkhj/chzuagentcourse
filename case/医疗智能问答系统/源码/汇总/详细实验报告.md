# 糖尿病视网膜病变智能诊断系统实验报告

## 摘要

本实验基于APTOS 2019数据集，对七种深度学习模型在糖尿病视网膜病变（DR）五级分类任务上的性能进行了系统性评估。实验结果表明，EfficientNet系列模型表现最优，其中EfficientNet-B8的加权Kappa系数（QWK）达到0.8751，EfficientNet-B3在保持优异性能（QWK=0.8692）的同时具有最佳的推理效率（18.8ms）。本报告详细记录了实验设计、结果分析及临床应用建议。

## 二、实验方法

### 2.1 模型架构对比

| 模型                | 架构特点     | 参数量 | 核心创新                 |
| ------------------- | ------------ | ------ | ------------------------ |
| **ResNet50**        | 残差连接     | ~23M   | 解决梯度消失             |
| **ResNet152**       | 深层残差网络 | ~60M   | 更深网络结构             |
| **DenseNet121**     | 密集连接     | ~8M    | 特征复用                 |
| **EfficientNet-B3** | 复合缩放     | 10.7M  | 深度×宽度×分辨率协同优化 |
| **EfficientNet-B5** | 复合缩放     | 28.4M  | 更大规模的复合缩放       |
| **EfficientNet-B8** | 复合缩放     | 84.6M  | 最大规模复合缩放         |
| **ViT-Base**        | 自注意力机制 | ~86M   | Transformer架构          |

### 2.2 数据预处理流程

```
原始眼底图像
    ↓
CLAHE对比度增强
    ↓
Resize至256×256
    ↓
CenterCrop至224×224
    ↓
标准化 (ImageNet均值标准差)
    ↓
输入模型
```

### 2.3 评估指标

| 指标               | 定义                   | 应用场景                   |
| ------------------ | ---------------------- | -------------------------- |
| **Accuracy**       | 正确预测比例           | 整体性能评估               |
| **QWK**            | 二次加权Kappa系数      | 有序分类一致性（核心指标） |
| **Precision**      | 精确率                 | 预测为正例中真正例比例     |
| **Recall**         | 召回率                 | 真正例中被正确预测比例     |
| **F1-Score**       | 精确率与召回率调和平均 | 综合性能指标               |
| **Inference Time** | 单张推理时间           | 部署效率评估               |

## 四、结果分析

### 4.1 性能排名分析

**EfficientNet系列优势明显**
- B8在QWK指标上排名第一（0.8751），展现了复合缩放策略的强大能力
- B3在参数效率上表现最佳，仅10.7M参数即可达到QWK=0.8692
- 推理速度B3最快（18.8ms），B5次之（27.5ms），B8最慢（42.9ms）

**ResNet系列稳健可靠**
- ResNet50和ResNet152性能接近，QWK分别为0.8535和0.8593
- 更深的网络（ResNet152）并未带来显著性能提升，可能存在过拟合

**DenseNet121表现中等**
- 参数量最小但性能不是最优，特征复用机制在本任务上优势有限

**ViT-Base表现欠佳**
- 在中小规模数据集上，Transformer架构不如优化良好的卷积网络
- 需要更大规模预训练数据才能发挥潜力

### 4.2 类别不平衡影响

**高样本量类别表现优异**
- 0级（1805例）所有模型准确率均超过92%
- 2级（999例）准确率普遍在70%-83%之间

**低样本量类别表现不佳**
- 1级（370例）准确率约40%-67%
- 3级（193例）准确率约35%-65%
- 4级（295例）准确率约27%-48%

**召回率问题突出**
- 4级（增殖性DR）作为最严重病变，召回率普遍低于50%
- 这是临床应用中最需要改进的方向

### 4.3 混淆模式分析

**主要混淆类型**
1. **相邻类别混淆**: 0↔1、1↔2、2↔3、3↔4
2. **边界病例误判**: 0级与1级之间混淆最频繁
3. **严重漏检**: 4级常被误判为2级或3级

**混淆原因分析**
- 相邻等级病变特征存在过渡性，边界模糊
- 标注一致性存在问题，特别是临界病例
- 罕见类别样本不足，模型学习不充分

## 五、临床应用建议

### 5.1 模型选择决策树

```
应用场景需求
    │
    ├─ 追求最高诊断准确性
    │   └─ 选择 EfficientNet-B8 (QWK=0.8751)
    │
    ├─ 平衡性能与效率（推荐）
    │   └─ 选择 EfficientNet-B3 (QWK=0.8692, 18.8ms)
    │
    ├─ 资源受限环境
    │   └─ 选择 EfficientNet-B3 或进行模型压缩
    │
    └─ 需要可解释性
        └─ 任意模型 + Grad-CAM热力图
```

### 5.2 部署方案建议

| 部署环境   | 推荐模型        | 推理能力 | 适用场景           |
| ---------- | --------------- | -------- | ------------------ |
| 云端服务器 | EfficientNet-B8 | 高性能   | 精准诊断、科研     |
| 边缘设备   | EfficientNet-B3 | 实时处理 | 社区筛查、移动医疗 |
| 移动设备   | 压缩版B3        | 低功耗   | 家庭自检、远程医疗 |

### 5.3 临床工作流程

```
患者眼底图像采集
    ↓
AI模型初筛（EfficientNet-B3）
    │
    ├─ 0级（无DR）→ 建议年度复查
    │
    ├─ 1-2级（轻度/中度）→ 转眼科医师复核
    │
    ├─ 3-4级（重度/增殖性）→ 紧急转诊
    │
    └─ 边界病例（置信度低）→ 优先医师复核
```

## 六、结论

### 6.1 主要发现

1. **EfficientNet-B3是综合最优模型**，在诊断性能（QWK=0.8692）、推理速度（18.8ms）和模型大小（10.7M）之间达到最佳平衡

2. **EfficientNet-B8性能最佳**，QWK系数达到0.8751，但推理时间较长（42.9ms），适合对准确性要求极高的场景

3. **类别不平衡是主要挑战**，罕见类别（3级、4级）的召回率普遍偏低，需要针对性优化

4. **Vision Transformer在本任务上表现不佳**，可能需要针对医学图像进行领域适应或更大规模预训练

5. **模型可解释性分析显示**，Grad-CAM热力图能够有效展示模型关注区域，为临床医师提供参考

### 6.2 局限性

- 数据集规模有限，特别是3级和4级样本较少
- 缺乏多中心数据验证，泛化能力有待进一步评估
- 未考虑眼底图像质量对诊断的影响
- 未进行前瞻性临床验证

### 6.3 未来工作方向

1. **数据增强**: 采用更先进的数据增强策略（如MixUp、CutMix）缓解类别不平衡
2. **损失函数优化**: 引入Focal Loss或序数回归损失提升罕见类别性能
3. **模型集成**: 探索多模型集成策略提升整体性能
4. **领域自适应**: 引入自监督预训练提升特征提取能力
