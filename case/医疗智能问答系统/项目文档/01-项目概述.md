# 01 - 项目概述

## 项目定位

医疗智能问答系统是一个面向眼科医生的辅助诊断平台，核心解决两个问题：

1. **医学知识检索与问答**：医生可以通过自然语言提问，系统从医学知识库中检索相关文档，结合大语言模型生成专业回答（RAG 模式）。
2. **糖尿病视网膜病变图像诊断**：上传眼底图像，系统自动使用 6 个深度学习模型进行集成推理，给出 DR 分级（0-4 级）和临床建议。

## 数据流

### 问答流程（RAG）

```
用户提问 → 向量检索（pgvector） → 构造上下文 Prompt → 调用 LLM → 流式返回回答
              ↑
         知识库文档向量化
```

### 图像分析流程

```
上传眼底图像 → 预处理(224×224) → 6 模型集成推理 → 加权平均 → DR 分级 → 诊断报告
```

## 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| 认证模块 | `routes/auth.py`, `utils/auth.py` | JWT 注册/登录/权限控制 |
| 知识库模块 | `routes/kb.py`, `utils/vector_manager.py`, `utils/file_processor.py` | 文档管理、向量化、检索 |
| 问答模块 | `routes/chat.py`, `services/chat_service.py` | 多轮对话、RAG、流式输出 |
| 图像模块 | `routes/image_analysis.py`, `services/model_manager.py`, `services/image_processor.py` | 图像分析、模型推理 |
| 用户模块 | `routes/users.py`, `models/user.py` | 用户 CRUD、角色管理 |
| 模型配置模块 | `routes/models.py`, `models/model.py` | LLM/Embedding 模型管理 |

## API 概览

| 前缀 | 说明 |

| `/api/kb` | 知识库管理 |

| `/api/settings` | 系统设置 |
