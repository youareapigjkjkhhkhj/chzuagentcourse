# 02 - 项目目标

## 功能目标

| 编号 | 目标 | 对应模块 |
|------|------|----------|
| F1 | 用户注册/登录，JWT 无状态认证 | `routes/auth.py`, `utils/auth.py` |
| F2 | 角色权限控制（admin/doctor/user） | `utils/auth.py` (`login_required`, `admin_required`) |
| F3 | 知识库 CRUD，支持多知识库 | `routes/kb.py`, `models/knowledge_base.py` |
| F4 | 文档上传（txt/md/pdf/docx/xlsx/pptx），自动文本提取 | `utils/file_processor.py` |
| F5 | 文档向量化（pgvector），支持增量同步 | `utils/vector_manager.py`, `models/document_vector.py` |
| F6 | 混合检索（向量 + 全文），搜索结果高亮 | `VectorManager.hybrid_search()` |
| F7 | AI 智能问答，支持 OpenAI/Ollama/千问 | `routes/chat.py` |
| F8 | SSE 流式输出，实时返回回答 | `routes/chat.py` (`send-stream`) |
| F9 | 多轮对话，会话历史持久化 | `services/chat_service.py`, `models/chat.py` |
| F10 | 眼底图像上传与分析 | `routes/image_analysis.py` |
| F11 | 6 模型集成推理，DR 0-4 级分级 | `services/model_manager.py` |
| F12 | 诊断报告生成，含风险评估与建议 | `routes/image_analysis.py`, `models/image_analysis.py` |
| F13 | 模型管理（LLM/Embedding 配置） | `routes/models.py`, `models/model.py` |
| F14 | 前端响应式界面 | `frotend/src/` |

## 非功能目标

| 目标 | 指标 |
|------|------|
| 响应时间 | 普通 API < 500ms，LLM 回答首 token < 2s |
| 并发支持 | ≥ 20 用户同时在线 |
| 数据安全 | 密码 bcrypt 加密，JWT 24h 过期 |
| 文件支持 | 单文件最大 50MB |
| 可扩展性 | 新增 LLM Provider 只需在 `chat.py` 添加调用函数 |
| 可维护性 | 清晰的路由/服务/模型三层架构 |

## 设计原则

1. **RESTful API**：标准 HTTP 方法 + 统一响应格式
2. **前后端分离**：独立部署，CORS 配置
3. **模块化**：路由蓝图隔离，服务层解耦
4. **安全优先**：认证鉴权、输入验证、SQL 注入防护
5. **渐进增强**：功能降级（如向量搜索不可用时回退全文搜索）

## 验收标准

- [x] 用户注册、登录、Token 刷新正常
- [x] 知识库创建、文档上传、向量化流程完整
- [x] AI 问答基于知识库上下文回答，流式输出正常
- [x] 图像分析返回 DR 分级 + 置信度 + 诊断建议
- [x] 前端所有页面路由可正常访问
- [x] API 统一响应格式，错误处理完善
