# 04 - 阶段1：环境搭建与后端基础

## 目标

搭建开发环境，完成 Flask 应用工厂和数据库基础配置。

## 1. 环境准备

### Python 环境

```bash
cd 源码/backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### PostgreSQL + pgvector

```bash
# Ubuntu/Debian
sudo apt-get install postgresql-16 postgresql-16-pgvector

# 或 Docker
docker run -d --name pgvector \
  -e POSTGRES_PASSWORD=123456 \
  -p 5432:5432 \
  pgvector/pgvector:pg16
```

创建数据库：

```sql
CREATE DATABASE vectordb;
CREATE EXTENSION vector;
```

## 2. 环境变量配置

复制 `.env.example` 为 `.env`，编辑关键配置：

```env
# SQLite 元数据库
DATABASE_URL=sqlite:///app.db

# PostgreSQL 向量数据库
VECTOR_DATABASE_URL=postgresql://root:123456@localhost:5432/vectordb

# 安全配置
SECRET_KEY=your-super-secret-key-here

# 应用配置
FLASK_ENV=development
DEBUG=True
HOST=0.0.0.0
PORT=5000

# Embedding 模型
EMBEDDING_MODEL=bge-m3:latest
EMBEDDING_DIMENSION=1024
EMBEDDINGS_API_URL=http://localhost:11434/api/embeddings
```

## 3. Flask 应用工厂

入口文件 `run.py`：

```python
from dotenv import load_dotenv
from app import create_app

load_dotenv()
app = create_app()

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```

应用工厂 `app/__init__.py` 核心逻辑：

```python
def create_app():
    app = Flask(__name__)

    # 1. 数据库配置
    app.config['SQLALCHEMY_DATABASE_URI'] = os.environ.get('DATABASE_URL')

    # 2. CORS 配置
    CORS(app, resources={r"/api/*": {"origins": ["http://localhost:3000"]}})

    # 3. Flask-Login 初始化
    login_manager = LoginManager()
    login_manager.init_app(app)

    # 4. 注册蓝图
    app.register_blueprint(auth_bp, url_prefix='/api/auth')
    app.register_blueprint(users_bp, url_prefix='/api/users')
    app.register_blueprint(chat_bp, url_prefix='/api/chat')
    app.register_blueprint(kb_bp, url_prefix='/api/kb')
    app.register_blueprint(analysis_bp, url_prefix='/api/analysis')
    # ...

    # 5. 创建数据库表
    with app.app_context():
        db.create_all()
        init_vector_db()

    return app
```

## 4. 数据库初始化

```bash
# 一键初始化
python scripts/init_complete_db.py

# 或分步执行
python init_db.py            # 初始化 SQLite 业务库
python init_pgvector_db.py   # 初始化 PostgreSQL 向量库
python scripts/run_migrations.py  # 运行迁移
```
