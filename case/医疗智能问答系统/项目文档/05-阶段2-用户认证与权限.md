# 05 - 阶段2：用户认证与权限控制

## 目标

实现完整的 JWT 认证体系，包括注册、登录、Token 刷新、角色权限控制。

## 1. 用户模型

`models/user.py` 定义用户表：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Integer PK | 自增主键 |
| `username` | String(80) | 唯一索引 |
| `email` | String(120) | 唯一索引 |
| `password_hash` | String(255) | Werkzeug bcrypt 加密 |
| `full_name` | String(100) | 姓名 |
| `phone` | String(20) | 手机号 |
| `role` | String(20) | `admin` / `doctor` / `user` |
| `department` | String(100) | 科室 |
| `title` | String(100) | 职称 |
| `hospital` | String(200) | 医院 |
| `is_active` | Boolean | 账户启用状态 |

## 2. JWT 认证工具

`utils/auth.py` 提供核心认证功能：

```python
def generate_token(user_id, username):
    """生成 JWT Token，有效期 24 小时"""
    payload = {
        'user_id': user_id,
        'username': username,
        'exp': datetime.utcnow() + timedelta(hours=24)
    }
    return jwt.encode(payload, SECRET_KEY, algorithm='HS256')

def verify_token(token):
    """验证并解码 Token"""
    try:
        return jwt.decode(token, SECRET_KEY, algorithms=['HS256'])
    except jwt.InvalidTokenError:
        return None

def login_required(f):
    """登录装饰器，从 Authorization Header 提取 Bearer Token"""
    @wraps(f)
    def decorated(*args, **kwargs):
        token = request.headers.get('Authorization', '').replace('Bearer ', '')
        payload = verify_token(token)
        if not payload:
            return error_response('需要认证', status_code=401)
        request.current_user = payload
        return f(*args, **kwargs)
    return decorated

def admin_required(f):
    """管理员权限装饰器"""
    @wraps(f)
    @login_required
    def decorated(*args, **kwargs):
        if request.current_user.get('role') != 'admin':
            return error_response('需要管理员权限', status_code=403)
        return f(*args, **kwargs)
    return decorated
```

## 3. 认证 API

`routes/auth.py` 注册认证蓝图：

### 注册

```
POST /api/auth/register
Body: {
    "username": "doctor_zhang",
    "email": "zhang@hospital.com",
    "password": "123456",
    "full_name": "张医生",
    "department": "眼科",
    "title": "主治医师",
    "hospital": "某某医院"
}
```

### 登录

```
POST /api/auth/login
Body: {
    "username": "doctor_zhang",
    "password": "123456"
}
Response: {
    "success": true,
    "data": {
        "token": "eyJ...",
        "user": { ... }
    }
}
```

### 验证 Token / 获取当前用户

```
GET /api/auth/verify
Headers: Authorization: Bearer <token>

GET /api/auth/me
Headers: Authorization: Bearer <token>
```

### 刷新 Token

```
POST /api/auth/refresh
Body: { "token": "current_token" }
```

## 4. 用户管理 API

`routes/users.py` 需要 JWT 认证：

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/users/` | 用户列表（分页/搜索） | 登录 |
| GET | `/api/users/<id>` | 用户详情 | 登录 |
| PUT | `/api/users/<id>` | 更新用户 | 登录 |
| DELETE | `/api/users/<id>` | 软删除用户 | admin |
| GET | `/api/users/profile` | 当前用户信息 | 登录 |
| PUT | `/api/users/profile` | 更新当前用户 | 登录 |
| POST | `/api/users/change-password` | 修改密码 | 登录 |

## 5. 统一响应格式

所有 API 使用 `utils/response.py` 标准格式：

```json
// 成功
{
    "success": true,
    "message": "操作成功",
    "data": { ... }
}

// 失败
{
    "success": false,
    "message": "错误信息",
    "error_code": "ERROR_CODE"
}
```

## 6. 输入验证

`utils/validators.py` 提供验证函数：

- `validate_username(username)` — 3-30 字符，字母数字下划线
- `validate_email(email)` — 使用 email-validator 库
- `validate_password(password)` — 6-50 字符
- `validate_phone(phone)` — 中国手机号格式（可选）
- `validate_role(role)` — 仅 admin/doctor/user
