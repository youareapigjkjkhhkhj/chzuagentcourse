## 目标

实现知识库的完整生命周期管理：创建知识库 → 上传文档 → 自动文本提取 → 向量化 → 检索。

## 3. 文件文本提取

`utils/file_processor.py` 支持多格式提取：

| 格式 | 解析库 | 说明 |
|------|--------|------|
| `.txt` | 内置 | 多编码检测（utf-8/gbk/gb2312/latin-1） |
| `.md` | 内置 | 同 txt |
| `.pdf` | pypdf | 逐页提取 |
| `.docx` | python-docx | 段落 + 表格 |
| `.xlsx` | openpyxl | 逐行提取所有工作表 |
| `.pptx` | python-pptx | 幻灯片文本 + 表格 |

核心方法：

```python
class FileProcessor:
    MAX_FILE_SIZE = 50 * 1024 * 1024  # 50MB

    def extract_text(file_path):
        """根据文件后缀分发到对应解析器"""
        ext = os.path.splitext(file_path)[1].lower()
        processors = {
            '.txt': self.process_txt,
            '.md': self.process_markdown,
            '.pdf': self.process_pdf,
            '.docx': self.process_docx,
            '.xlsx': self.process_xlsx,
            '.pptx': self.process_pptx,
        }
        return processors[ext](file_path)
```

## 4. 知识库管理 API

`routes/kb.py`：

### 知识库 CRUD

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/kb` | 列表（分页/搜索） |
| POST | `/api/kb` | 创建知识库 |
| GET | `/api/kb/<kb_id>` | 知识库详情 |
| PUT | `/api/kb/<kb_id>` | 更新知识库 |
| DELETE | `/api/kb/<kb_id>` | 删除（级联删除文档和向量） |
| GET | `/api/kb/<kb_id>/stats` | 统计信息 |

### 文档管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/kb/<kb_id>/documents` | 文档列表 |
| POST | `/api/kb/<kb_id>/documents` | 创建文档（手动） |
| POST | `/api/kb/<kb_id>/documents/upload` | 上传文件创建文档 |
| POST | `/api/kb/<kb_id>/documents/upload-zip` | 批量导入 ZIP |
| POST | `/api/kb/<kb_id>/documents/batch` | 批量操作（删除/发布/同步向量） |
| POST | `/api/kb/<kb_id>/documents/<doc_id>/vectorize` | 向量化单个文档 |
| DELETE | `/api/kb/<kb_id>/documents/<doc_id>` | 删除文档 |

### 搜索

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/kb/<kb_id>/search` | 单库搜索 |
| POST | `/api/kb/search` | 跨库搜索 |

## 5. 文档处理流程

```
上传文件 → FileProcessor.extract_text() → 保存 Document 记录
    ↓
发布文档 → VectorManager.process_document() → 文本分块 → 生成向量 → 存入 pgvector
    ↓
搜索查询 → VectorManager.hybrid_search() → 向量搜索 + 全文搜索 → 结果合并
```
