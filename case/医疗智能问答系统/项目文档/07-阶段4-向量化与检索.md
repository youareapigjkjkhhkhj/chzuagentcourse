# 07 - 阶段4：向量化存储与检索

## 目标

基于 pgvector 实现文档向量化存储和语义检索，支持混合搜索（向量 + 全文）。

## 1. 向量模型

`models/document_vector.py` 使用 pgvector 扩展：

```sql
-- 向量表结构
CREATE TABLE document_vectors (
    id SERIAL PRIMARY KEY,
    document_id VARCHAR(50) REFERENCES documents(id),
    kb_id VARCHAR(50) REFERENCES knowledge_bases(id),
    chunk_index INTEGER,
    chunk_text TEXT,
    embedding vector(1024),  -- 维度取决于 Embedding 模型
    metadata JSON,
    created_at TIMESTAMP
);

-- HNSW 索引（推荐）
CREATE INDEX ON document_vectors
    USING hnsw (embedding vector_cosine_ops);
```

## 2. 向量管理器

`utils/vector_manager.py` 核心类：

### 文本分块

```python
def split_text(self, text, chunk_size=1000, chunk_overlap=200):
    """使用 LangChain RecursiveCharacterTextSplitter"""
    separators = [
        "\n\n",    # 段落
        "\n",      # 换行
        "。",       # 中文句号
        "！",       # 中文感叹号
        "？",       # 中文问号
        ".",        # 英文句号
        " ",        # 空格
    ]
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_overlap,
        separators=separators
    )
    return splitter.split_text(text)
```

### 文档向量化

```python
def process_document(self, doc, kb):
    """处理单个文档的向量化"""
    chunks = self.split_text(doc.content, self.chunk_size, self.chunk_overlap)
    vectors = []
    for i, chunk in enumerate(chunks):
        embedding = self.generate_embedding(chunk)
        vectors.append(DocumentVector(
            document_id=doc.id,
            kb_id=kb.id,
            chunk_index=i,
            chunk_text=chunk,
            embedding=embedding
        ))
    db.session.bulk_save_objects(vectors)
    doc.vector_status = 'completed'
    doc.chunk_count = len(chunks)
```

### 语义搜索

```python
def search_similar(self, query, kb_id, limit=10, threshold=0.7):
    """pgvector 余弦相似度搜索"""
    query_embedding = self.generate_embedding(query)
    results = db.session.query(DocumentVector).filter(
        DocumentVector.kb_id == kb_id,
        # 使用 pgvector 的 <=> 操作符（余弦距离）
        func.cosine_distance(DocumentVector.embedding, query_embedding) < (1 - threshold)
    ).order_by(
        func.cosine_distance(DocumentVector.embedding, query_embedding)
    ).limit(limit).all()
    return results
```

## 3. 配置参数

在 `.env` 或"知识库设置"页面配置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `EMBEDDING_MODEL` | bge-m3:latest | Embedding 模型名 |
| `EMBEDDING_DIMENSION` | 1024 | 向量维度 |
| `CHUNK_SIZE` | 1000 | 文本分块大小 |
| `CHUNK_OVERLAP` | 200 | 分块重叠 |
| `SIMILARITY_THRESHOLD` | 0.7 | 相似度阈值 |
| `MAX_SEARCH_RESULTS` | 10 | 最大返回数 |
