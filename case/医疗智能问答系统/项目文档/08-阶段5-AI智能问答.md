# 08 - 阶段5：AI 智能问答

## 目标

实现基于 RAG 的医疗智能问答，支持多轮对话、多 LLM 提供商、SSE 流式输出。

## 1. 问答流程

```
用户提问
    ↓
创建/获取 ChatSession
    ↓
保存用户消息（ChatMessage）
    ↓
[可选] 向量检索知识库上下文
    ↓
构造 System Prompt + Context + User Message
    ↓
调用 LLM（OpenAI / Ollama / 千问）
    ↓
保存 AI 回复
    ↓
返回结果（同步 / SSE 流式）
```

## 2. 聊天模型

`models/chat.py`：

### ChatSession（会话）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String(36) PK | UUID |
| `user_id` | Integer FK | 所属用户 |
| `title` | String(255) | 会话标题（自动生成） |
| `model_id` | String(50) | 使用的 LLM 模型 |
| `knowledge_base_id` | String(36) | 关联的知识库 |
| `is_active` | Boolean | 是否有效（软删除） |

### ChatMessage（消息）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String(36) PK | UUID |
| `session_id` | String(36) FK | 所属会话 |
| `content` | Text | 消息内容 |
| `message_type` | String(20) | `user` / `ai` / `system` |
| `role` | String(20) | `user` / `assistant` / `system` |
| `tokens` | Integer | Token 消耗数 |
| `model_response_time` | Float | 响应耗时（秒） |
| `from_knowledge_base` | Boolean | 是否来自知识库 |
| `sources` | JSON | 知识库来源引用 |

## 4. LLM 多提供商支持

`routes/chat.py` 中实现了三种 LLM 调用器：

### OpenAI

```python
def call_openai_model(messages, model_name, api_key, endpoint, temperature, max_tokens):
    response = requests.post(
        f"{endpoint}/v1/chat/completions",
        headers={"Authorization": f"Bearer {api_key}"},
        json={"model": model_name, "messages": messages, ...}
    )
    return response.json()['choices'][0]['message']['content']
```

### Ollama（本地）

```python
def call_ollama_model(messages, model_name, endpoint, temperature, max_tokens):
    response = requests.post(
        f"{endpoint}/api/chat",
        json={"model": model_name, "messages": messages, "stream": False}
    )
    return response.json()['message']['content']
```

## 5. RAG 上下文注入

```python
def generate_stream_response(user_message, session, kb_id=None):
    # 1. 如果指定了知识库，进行检索
    if kb_id:
        vector_manager = get_vector_manager()
        search_results = vector_manager.hybrid_search(user_message, kb_id)

        # 2. 构造上下文
        context = "\n\n".join([r['chunk_text'] for r in search_results])
        system_prompt = f"""你是一个专业的医疗助手。请基于以下参考信息回答用户的问题。

参考信息：
{context}

注意：如果参考信息中没有相关信息，请基于你的专业知识回答，并说明这不是来自知识库的信息。"""
    else:
        system_prompt = "你是一个专业的医疗助手，请根据你的专业知识回答用户的问题。"

    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_message}
    ]

    # 3. 调用 LLM 并流式返回
    for chunk in call_chat_model_stream(messages, model_config):
        yield chunk
```
