## 2. 常见问题排查

### 数据库连接失败

```
错误: could not connect to server
```

排查：
1. 检查 PostgreSQL 是否运行：`sudo systemctl status postgresql`
2. 检查 `.env` 中 `VECTOR_DATABASE_URL` 是否正确
3. 检查 pgvector 扩展是否安装：`CREATE EXTENSION vector;`

### Embedding API 不可用

```
错误: Connection refused
```

排查：
1. 检查 Ollama 是否运行：`ollama list`
2. 测试 API：`curl http://localhost:11434/api/embeddings -d '{"model":"bge-m3","prompt":"test"}'`
3. 检查 `.env` 中 `EMBEDDINGS_API_URL` 是否正确

### 向量化失败

排查：
1. 检查文档内容是否为空
2. 检查 Embedding API 是否可用
3. 检查 PostgreSQL 向量表是否创建

### 图像分析失败

排查：
1. 检查 `train_model/` 目录下是否有模型权重文件
2. 检查图像格式是否支持（PNG/JPG/BMP/TIFF）
3. 检查 GPU/CPU 可用性

### CORS 错误

检查 `app/__init__.py` 中 CORS 配置，确保前端地址在允许列表中：

```python
CORS(app, resources={
    r"/api/*": {
        "origins": ["http://localhost:3000", "http://127.0.0.1:3000"]
    }
})
```
