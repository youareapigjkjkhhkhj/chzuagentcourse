## 方式一：手动部署

### 步骤 1：安装系统依赖

**Ubuntu/Debian：**

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-pip python3-venv \
    postgresql postgresql-contrib \
    nodejs npm
```

**安装 pgvector 扩展：**

```bash
sudo apt-get install -y postgresql-16-pgvector
# 或从源码编译
git clone https://github.com/pgvector/pgvector.git
cd pgvector && make && sudo make install
```

### 步骤 2：创建数据库

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建数据库和用户
CREATE DATABASE vectordb;
CREATE USER kb_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE vectordb TO kb_user;

# 启用 pgvector 扩展
\c vectordb
CREATE EXTENSION vector;

# 授权
GRANT ALL ON SCHEMA public TO kb_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO kb_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO kb_user;

\q
```

### 步骤 3：部署后端

```bash
cd 源码/backend

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
```

编辑 `.env` 文件：

```env
# 数据库
DATABASE_URL=sqlite:///app.db
VECTOR_DATABASE_URL=postgresql://kb_user:your_secure_password@localhost:5432/vectordb

# 安全
SECRET_KEY=<使用随机生成的强密钥>
JWT_EXPIRATION_HOURS=24

# 应用
FLASK_ENV=production
DEBUG=False
HOST=0.0.0.0
PORT=5000

# Embedding（根据实际情况修改）
EMBEDDING_MODEL=bge-m3:latest
EMBEDDING_DIMENSION=1024
EMBEDDINGS_API_URL=http://localhost:11434/api/embeddings
```

初始化数据库：

```bash
python scripts/init_complete_db.py
```

启动后端（开发）：

```bash
python run.py
```

启动后端（生产 - Gunicorn）：

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 --timeout 120 run:app
```

### 步骤 4：部署前端

```bash
cd 源码/frotend

# 安装依赖
npm install  # 或 pnpm install

# 开发模式
npm run dev  # 或 pnpm dev

# 生产构建
npm run build  # 输出到 dist/static/
```

### 步骤 5：配置 Ollama（Embedding 服务）

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 拉取 Embedding 模型
ollama pull bge-m3

# 验证
curl http://localhost:11434/api/embeddings \
  -d '{"model":"bge-m3","prompt":"test"}'
```

### 步骤 6：配置为系统服务（可选）

创建 `/etc/systemd/system/medical-qa.service`：

```ini
[Unit]
Description=Medical QA Backend Service
After=network.target postgresql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/path/to/源码/backend
Environment="PATH=/path/to/源码/backend/venv/bin"
ExecStart=/path/to/源码/backend/venv/bin/gunicorn -w 4 -b 0.0.0.0:5000 --timeout 120 run:app
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl start medical-qa
sudo systemctl enable medical-qa
sudo systemctl status medical-qa
```

## 方式二：Docker 部署

### 使用 Docker Compose

创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  postgres:
    image: pgvector/pgvector:pg16
    container_name: medical-qa-postgres
    environment:
      POSTGRES_DB: vectordb
      POSTGRES_USER: kb_user
      POSTGRES_PASSWORD: ${DB_PASSWORD:-your_secure_password}
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped

  ollama:
    image: ollama/ollama
    container_name: medical-qa-ollama
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    restart: unless-stopped

  backend:
    build:
      context: ./源码/backend
      dockerfile: Dockerfile
    container_name: medical-qa-backend
    ports:
      - "5000:5000"
    environment:
      DATABASE_URL: sqlite:///app.db
      VECTOR_DATABASE_URL: postgresql://kb_user:${DB_PASSWORD}@postgres:5432/vectordb
      SECRET_KEY: ${SECRET_KEY:-change-this-in-production}
      FLASK_ENV: production
      DEBUG: "False"
      EMBEDDING_MODEL: bge-m3:latest
      EMBEDDING_DIMENSION: "1024"
      EMBEDDINGS_API_URL: http://ollama:11434/api/embeddings
    depends_on:
      - postgres
      - ollama
    volumes:
      - backend_data:/app/uploads
    restart: unless-stopped

  frontend:
    image: nginx:alpine
    container_name: medical-qa-frontend
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./源码/frotend/dist/static:/usr/share/nginx/html
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - backend
    restart: unless-stopped

volumes:
  postgres_data:
  ollama_data:
  backend_data:
```

启动：

```bash
# 配置环境变量
cp .env.example .env
# 编辑 .env 设置密码和密钥

# 启动
docker-compose up -d

# 初始化数据库
docker-compose exec backend python scripts/init_complete_db.py

# 拉取 Embedding 模型
docker-compose exec ollama ollama pull bge-m3

# 查看日志
docker-compose logs -f
```

## Nginx 配置

### 前端 + 后端反向代理

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/源码/frotend/dist/static;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 流式支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }

    # 上传文件访问
    location /uploads {
        proxy_pass http://127.0.0.1:5000;
    }
}
```

### HTTPS 配置

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/ssl/certs/your-domain.pem;
    ssl_certificate_key /etc/ssl/private/your-domain.key;

    # ... 同上配置 ...
}
```

## 备份与恢复

### 自动备份脚本

创建 `backup.sh`：

```bash
#!/bin/bash
BACKUP_DIR="/backup/medical-qa"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR

# 备份 SQLite
cp 源码/backend/app.db $BACKUP_DIR/app_$DATE.db

# 备份 PostgreSQL
pg_dump -U kb_user -d vectordb > $BACKUP_DIR/vectordb_$DATE.sql

# 保留最近 30 天的备份
find $BACKUP_DIR -name "*.db" -mtime +30 -delete
find $BACKUP_DIR -name "*.sql" -mtime +30 -delete
```

添加 crontab：

```bash
# 每天凌晨 2 点备份
0 2 * * * /path/to/backup.sh
```

### 恢复

```bash
# 恢复 SQLite
cp /backup/medical-qa/app_20241112.db 源码/backend/app.db

# 恢复 PostgreSQL
psql -U kb_user -d vectordb < /backup/medical-qa/vectordb_20241112.sql
```

## 故障排除

### 问题 1：pgvector 扩展未安装

**错误：** `extension "vector" does not exist`

**解决：**

```bash
sudo apt-get install postgresql-16-pgvector
sudo -u postgres psql -d vectordb -c "CREATE EXTENSION vector;"
```

### 问题 2：数据库连接失败

**错误：** `could not connect to server`

**排查：**

```bash
# 检查 PostgreSQL 状态
sudo systemctl status postgresql

# 检查连接
psql -U kb_user -d vectordb -c "SELECT 1;"

# 检查 pg_hba.conf 认证配置
sudo nano /etc/postgresql/16/main/pg_hba.conf
# 确保有：host vectordb kb_user 127.0.0.1/32 md5
```

### 问题 3：Embedding API 不可用

**错误：** `Connection refused` / `timeout`

**排查：**

```bash
# 检查 Ollama 服务
ollama list
curl http://localhost:11434/api/tags

# 检查模型是否已下载
ollama pull bge-m3
```

### 问题 4：模型权重缺失

**错误：** `FileNotFoundError: best_model.pth`

**解决：** 将训练好的模型权重放入 `backend/train_model/<model_name>/best_model.pth`

### 问题 5：前端 CORS 错误

**解决：** 检查 `app/__init__.py` 中 CORS origins 配置，添加前端实际地址：

```python
CORS(app, resources={
    r"/api/*": {
        "origins": [
            "http://localhost:3000",
            "http://your-domain.com"
        ]
    }
})
```

### 问题 6：SSE 流式输出中断

**排查：**

1. Nginx 配置 `proxy_buffering off;`
2. 后端 Gunicorn 增加 `--timeout 300`
3. 检查防火墙是否允许长连接
