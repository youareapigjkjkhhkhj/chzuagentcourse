## 一分钟极速体验

```bash
# 后端
cd 源码/backend
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
# 确认 .env 已存在（已内置 API 配置），然后：
python app.py
# 另开终端构建知识库 + 测试
PYTHONPATH=. .venv/Scripts/python.exe tests/test_full_flow.py

# 前端（可选，已有 dist 静态托管）
cd 源码/frontend && npm install --registry=https://registry.npmmirror.com && npm run dev
```

启动后访问 `http://127.0.0.1:5000` 即可使用（Flask 同源托管前端）。

## 关键事实（避免踩坑）

- 向量库使用 **FAISS**；嵌入模型固定 **text-embedding-3-small（1536 维）**；对话模型 **gpt-5-mini**。
- **FAISS 在 Windows 上对含中文的绝对路径有写入限制**，本项目已在 `src/rag/vectorstore.py` 中通过 `os.chdir` + 相对文件名方式内置修复，使用者无需额外操作。
- 大模型调用走 `OPENAI_BASE_URL` 指向的兼容代理；代理有频率限制，遇 429 请稍后重试（不影响代码正确性）。
