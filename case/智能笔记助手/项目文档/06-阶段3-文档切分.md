# 阶段 3 · 文档切分（面向中文笔记的递归字符切分）

> 本阶段目标：把长笔记切成适合向量检索的小块（chunk）。引入 `splitter.py`，并使用阶段 2 的 `load_document` 做端到端验证。**本阶段结束，你可以把一份笔记切成若干带重叠的语义片段。**

---

## 3.1 目标

- 使用 `RecursiveCharacterTextSplitter`，分隔符优先按 Markdown 标题 / 段落 / 中文标点断句，保证语义完整。
- 切分参数（`CHUNK_SIZE` / `CHUNK_OVERLAP`）来自 `settings`，可在 `.env` 调整。
- **可运行验证**：加载示例笔记 → 切分 → 打印 chunk 数量与每段长度，确认中文断句符合预期。

---

## 3.2 前置

- 阶段 1：`settings`（含 `CHUNK_SIZE=800` / `CHUNK_OVERLAP=120`）。
- 阶段 2：`load_document()` 能读取笔记。

---

## 3.3 核心代码

```python
# 源码/backend/src/rag/splitter.py:1-25（全）
"""文本切分：面向中文笔记的递归字符切分。"""
from langchain_text_splitters import RecursiveCharacterTextSplitter
from src.config import settings


def get_splitter(chunk_size=None, chunk_overlap=None) -> RecursiveCharacterTextSplitter:
    """构造递归字符切分器。

    分隔符优先按 Markdown 标题 / 段落 / 中文标点断句，保证语义完整。
    """
    return RecursiveCharacterTextSplitter(
        chunk_size=chunk_size or settings.CHUNK_SIZE,         # 默认 800
        chunk_overlap=chunk_overlap or settings.CHUNK_OVERLAP, # 默认 120
        separators=[
            "\n## ", "\n### ", "\n\n", "\n",
            "。", "！", "？", "；", "，",
            ". ", " ", "",
        ],
        keep_separator=True,
    )


def split_documents(documents, chunk_size=None, chunk_overlap=None):
    """将加载后的文档切分为适合检索的 chunk。"""
    return get_splitter(chunk_size, chunk_overlap).split_documents(documents)
```

> 设计要点：分隔符列表把中文句号 `。`、逗号 `，`、感叹/疑问号放在英文空格之前，使中文笔记尽量在句末断开，避免把一句话劈成两半。

## 3.4 实操步骤（纯 Python 验证）

```bash
cd 智能笔记助手/源码/backend
PYTHONPATH=. .venv/Scripts/python.exe -c "
from src.rag.loader import load_document
from src.rag.splitter import split_documents
docs = load_document('data/notes/快速开始示例.md')
chunks = split_documents(docs)
print('原始 Document 数:', len(docs))
print('切分后 chunk 数:', len(chunks))
for i, c in enumerate(chunks[:3], 1):
    print(f'--- chunk {i} 长度={len(c.page_content)} 来源={c.metadata.get(\"source\")}')
    print(c.page_content[:80])
"
```

## 3.5 可运行验证（本阶段 checkpoint）

期望输出（示例笔记较短，通常切成 1 个 chunk；长笔记会按 800 字 + 120 重叠切分）：

```
原始 Document 数: 1
切分后 chunk 数: 1
--- chunk 1 长度=NNN 来源=快速开始示例.md
（示例笔记正文前 80 字）
```

> 若你放入一份更长的 `.md`（如 3000 字），应看到多个 chunk，且相邻 chunk 末尾/开头有约 120 字重叠。

**✅ 阶段 3 通过标准**：`split_documents` 返回非空 chunk 列表，每块带正确 `source`；参数可从 `.env` 的 `CHUNK_SIZE` / `CHUNK_OVERLAP` 生效。
