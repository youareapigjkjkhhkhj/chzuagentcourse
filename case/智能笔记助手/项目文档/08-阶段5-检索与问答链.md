# 阶段 5 · 检索与问答链（Retrieval + LLM，非流式）

> 本阶段目标：把「用户提问」变成「带笔记出处的可信回答」。引入 `chain.py`（提示词 + 模型工厂）与 `qa_service.QAService.ask()`（检索 → 拼上下文 → 大模型生成 → 返回来源）。**本阶段结束，你可以用一行 Python 得到带引用来源的回答。**

---

## 5.1 目标

- 检索：用阶段 4 的 `VectorStoreManager.similarity_search` 取 Top-K 相关 chunk。
- 提示词：约束模型「只依据笔记上下文、禁止编造、标注来源」。
- 模型：对话模型固定 `gpt-5-mini`（`CHAT_MODEL`）。
- 溯源：`ask()` 返回 `{answer, sources}`，`sources` 去重并附相似度分数。
- **可运行验证**：`QAService().ask("本助手基于什么技术栈？")` 返回非空 `answer` 与 `sources`。

---

## 5.2 前置

- 阶段 4：已 `build_index()`，磁盘有可用 FAISS 索引。
- `settings.CHAT_MODEL = gpt-5-mini`、`settings.TOP_K = 4`。

## 5.3 核心代码

### 5.3.1 提示词与模型工厂 `src/rag/chain.py`

```python
# 源码/backend/src/rag/chain.py:1-46（节选）
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from src.config import settings

PROMPT_TEMPLATE = """你是一个专业的「智能笔记助手」。请严格依据下方【笔记上下文】回答用户的问题。
要求：
1. 只能使用上下文中提供的信息，禁止编造、禁止引入笔记之外的知识。
2. 若上下文中没有可用信息，请明确告知「笔记中未找到相关内容」，不要猜测。
3. 回答使用简体中文，结构清晰；可在关键结论后标注来源文件，例如（来源：xxx.md）。
4. 如内容较多，请使用分点 / 小标题组织。
【笔记上下文】
{context}
【用户问题】
{question}
【回答】"""                                       # 行 6-20

def get_llm(temperature=0.3, streaming=False) -> ChatOpenAI:  # 行 23
    return ChatOpenAI(
        model=settings.CHAT_MODEL,              # 行 26 → gpt-5-mini
        api_key=settings.OPENAI_API_KEY,
        base_url=settings.OPENAI_BASE_URL,
        temperature=temperature, streaming=streaming)

def build_prompt() -> ChatPromptTemplate:      # 行 34
    return ChatPromptTemplate.from_template(PROMPT_TEMPLATE)

def format_docs(documents) -> str:             # 行 39 拼装带来源的上下文
    blocks = []
    for i, d in enumerate(documents, 1):
        src = d.metadata.get("source", "未知来源")
        blocks.append(f"[笔记 {i} | 来源: {src}]\n{d.page_content}")
    return "\n\n".join(blocks)
```

### 5.3.2 问答编排 `src/services/qa_service.py`（非流式部分）

```python
# 源码/backend/src/services/qa_service.py:14-44（节选）
class QAService:
    def __init__(self):
        self.mgr = VectorStoreManager()

    def _retrieve(self, question, top_k):      # 行 20
        results = self.mgr.similarity_search(question, k=top_k)
        return [(d, score) for d, score in results]

    @staticmethod
    def _sources(results):                     # 行 24 去重 + 分数
        out, seen = [], set()
        for d, score in results:
            src = d.metadata.get("source", "未知")
            if src not in seen:
                seen.add(src)
                out.append({"source": src, "score": round(float(score), 4)})
        return out

    def ask(self, question, top_k=None) -> dict:   # 行 35 非流式
        if not self.mgr.exists():
            raise RuntimeError("知识库尚未构建，请先上传笔记并构建索引。")
        top_k = top_k or settings.TOP_K
        results = self._retrieve(question, top_k)
        context = format_docs([d for d, _ in results])
        chain = build_prompt() | get_llm()         # LCEL 管道
        resp = chain.invoke({"context": context, "question": question})
        return {"answer": resp.content, "sources": self._sources(results)}
```

> `build_prompt() | get_llm()` 是 LangChain 的 LCEL 管道写法：提示词模板的输出直接喂给 ChatModel。
