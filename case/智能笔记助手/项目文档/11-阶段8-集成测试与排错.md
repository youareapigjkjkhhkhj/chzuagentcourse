## 8.3 核心测试代码

### 8.3.1 端到端测试 `tests/test_full_flow.py`

```python
# 源码/backend/tests/test_full_flow.py:30-101（节选）
def main():
    # 1. 笔记列表
    notes = note_service.list_notes()
    print(f"   发现笔记 {len(notes)} 篇")
    if not notes: return 1
    # 2. 构建 FAISS 索引（触发 embedding）
    idx = note_service.build_index()
    if idx.get("chunk_count", 0) == 0: return 1
    # 3. 非流式问答（带溯源）
    ans = QAService().ask("本助手基于什么技术栈？")
    if not ans["answer"]: return 3
    # 4. 流式问答（SSE 逐行解析）
    chunks, sources = [], None
    for sse in QAService().ask_stream("如何构建知识库？"):
        if not sse.startswith("data:"): continue
        payload = json.loads(sse[len("data:"):].strip())
        if payload.get("type") == "token": chunks.append(payload["content"])
        elif payload.get("type") == "done": sources = payload.get("sources")
    if not "".join(chunks): return 4
    return 0
```

## 8.6 常见问题（FAQ）

| 现象 | 原因 / 处理 | 代码依据 |
|------|------------|---------|
| `could not open ... faiss_index.faiss for writing` | FAISS 在 Windows 无法写中文绝对路径；已用 `os.chdir`+相对名+锁修复 | `src/rag/vectorstore.py:36-46` |
| 建库/问答返回 429 | 代理频率/额度限制；稍后重试，代码已捕获不影响进程 | `tests/test_full_flow.py:49` |
| 前端空白 / 资源 404 | `frontend/dist` 未构建或后端从错目录启动 | `app.py:27-35` |
| 跨域 CORS 报错 | 开发态 Vite(5173) 访问后端(5000)；`flask-cors` 已启用放行 | `app.py:18` |
| 上传中文名文件报错 | `_safe_name` 已净化危险字符、保留中文 | `note_service.py:13-19` |

## 8.7 生产部署建议

- **进程管理**：`pip install gunicorn -i 清华源`，`gunicorn -w 2 -b 0.0.0.0:5000 app:app`（替代 `app.run`）。
- **反向代理**：Nginx 前置做 HTTPS，`frontend/dist` 交 Nginx 托管、`/api` 反代到 Flask。
- **增量索引**：笔记量大时把 `note_service.build_index` 的全量重建改为 `VectorStoreManager().add()` 增量。
- **安全**：`.env` 加入 `.gitignore`；生产替换为自有 Key 并限制 CORS 来源。
