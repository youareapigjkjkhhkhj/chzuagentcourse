# 02 · 项目目标 — 研究报告生成器

## 一、功能目标

| 编号 | 功能 | 验收标准 |
|------|------|----------|
| F1 | 多智能体流水线 | 输入主题后自动执行 8 阶段（规划/搜索/阅读/RAG/分析/写作/保存/完成），进度可查询 |
| F2 | 多论文源检索 | arXiv/Semantic Scholar/Europe PMC/Crossref 单源可选；综合开放源自动并集去重 |
| F3 | 中文主题适配 | 中文主题自动生成英文检索词变体（LLM 翻译 + 词典翻译 + 原文 + ASCII） |
| F4 | 本地混合 RAG | 哈希向量 + FAISS + BM25 + 词覆盖率融合排序，输出证据块与相关度标签 |
| F5 | LLM 分析与写作 | 依据证据生成带章节结构报告，禁止编造引用；支持 zh/en/auto 语言 |
| F6 | 导出 | Markdown + PDF（A4）；下载接口返回文件附件 |
| F7 | 前端工作台 | 参数表单/模型 API 面板/任务记录/进度时间线/报告预览/证据与论文卡片 |
| F8 | 兜底可用性 | 无 API Key、断网、PDF 失败时均自动降级产出抽取式报告 |

## 二、非功能目标

| 维度 | 目标 |
|------|------|
| 可运行性 | 清华源一键安装；`test_unit_rag.py` 与 `test_api_smoke.py` 全绿；单端口同源访问 |
| 健壮性 | 所有外部依赖（检索/下载/LLM）失败均捕获降级，主流程不中断 |
| 成本控制 | 本地响应缓存（相同请求复用）+ 本地 RAG（零 embedding API 成本） |
| 确定性 | 哈希向量确定性；相同输入同一次构建内检索结果一致 |
| 安全性 | API Key 仅前端→本地后端单次使用，不落库；报告渲染经 DOMPurify 消毒 |
| 结构规范 | `源码/{backend,frontend}` 前后端分离，与项目一/二一致 |

## 三、8 阶段里程碑（每阶段独立可运行）

| 阶段 | 手册 | 内容 | 达成标志 |
|------|------|------|----------|
| 1 | 04 | 环境与最小后端 | `/api/health` 返回 ok |
| 2 | 05 | LLM 客户端与规划代理 | 配置解析命中 `.env`；5 步任务 |
| 3 | 06 | 论文检索工具 | 4+1 源检索 + 中文翻译 |
| 4 | 07 | PDF 阅读与阅读代理 | 真实 PDF 抽取文本 |
| 5 | 08 | 本地混合 RAG | 证据检索 + 相关度标签 |
| 6 | 09 | 分析与写作代理 | 有/无 Key 均产出报告 |
| 7 | 10 | API 层与异步任务 | 任务轮询 + 下载 + 静态托管 |
| 8 | 11 | 前端与集成测试 | dist 构建 + 两套测试全绿 |

## 四、验收测试清单（实测结果）

| 测试 | 覆盖 | 结果 |
|------|------|------|

## 五、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 论文源限流/失效 | 检索失败 | 双通道代理回退 + 多源候选 + 空结果降级 |
| PDF 扫描版 | 无法抽取文本 | 跳过 + warning；保留元数据 |
| LLM 代理 429/超时 | 分析与写作失败 | 本地响应缓存 + 兜底报告 |
| Playwright 未装 Chromium | PDF 导出失败 | 仅 warn，Markdown 不受影响；文档提供安装命令 |
| 任务进程内存储 | 重启丢失列表 | 预期行为；文件持久化于 `generated_reports/` |

## 六、范围外（后续增强）

- 任务队列持久化（Celery/Redis）与多机部署。
- 接入更多论文源（OpenAlex/PubMed/bioRxiv/DBLP）与来源 API Key。
- 更强 embedding（本地 bge / 远程 text-embedding-3-small 可选）。
- 引用级溯源与证据高亮、Word/LaTeX/BibTeX 导出。
- 用户鉴权与多用户任务隔离。
