# 04 · 阶段 1 — 环境与最小后端

> 本阶段目标：建立项目三（研究报告生成器）的独立运行环境，配置大模型服务，并用 Uvicorn 启动一个最小 FastAPI 后端（健康检查）。

---

## 1. 目标

- 创建项目独立虚拟环境 `.venv`（隔离依赖，不污染系统 Python）。
- 用**清华源**安装全部后端依赖（`requirements.txt`）。
- 编写 `.env`：配置大模型服务（OpenAI 兼容代理 + `gpt-5-mini`）。
- 启动 FastAPI 服务，验证 `/api/health` 返回 `{"status": "ok"}`。

## 2. 目录结构（本阶段涉及）

```text
研究报告生成器/
└── 源码/
    ├── backend/
    │   ├── api/app.py          # FastAPI 入口（阶段 1 仅健康检查，阶段 7 扩展全路由）
    │   ├── requirements.txt    # 精简依赖清单
    │   ├── .env                # 大模型配置（不入库）
    │   └── .venv/              # 虚拟环境（不入库）
    └── frontend/               # 阶段 8 使用
```

## 3. 实操步骤

### 3.1 创建虚拟环境

```bash
cd 源码/backend
python -m venv .venv
```

### 3.2 用清华源安装依赖

`requirements.txt` 是**按实际代码精简**的清单（不再包含项目内未使用的 langchain/langgraph/streamlit）：

```text
# requirements.txt
fastapi>=0.115
uvicorn>=0.30
pydantic>=2.7
requests>=2.31
arxiv>=2.1
pdfplumber>=0.11
numpy>=1.26
faiss-cpu>=1.8
markdown>=3.5
openai>=1.30
playwright>=1.44
```

```bash
.venv/Scripts/python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.3 配置 `.env`

`agents/llm_client.py:69-100` 的 `resolve_llm_settings()` 负责解析模型配置：请求体优先，其次 `.env`，最后内置默认值。`.env` 示例（OpenAI 兼容代理）：

```env
OPENAI_API_KEY=sk-你的key
OPENAI_BASE_URL=https://api.chatanywhere.tech
OPENAI_MODEL=gpt-5-mini
LLM_RESPONSE_CACHE=1
```

> 适配点：`llm_client.py:94` 增加 `OPENAI_BASE_URL` 环境变量回退，使 OpenAI 兼容代理开箱即用（原版仅支持 provider 内置地址）。

### 3.4 启动最小后端

```bash
.venv/Scripts/python.exe -m uvicorn api.app:app --host 127.0.0.1 --port 8000 --reload
```

## 6. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| `pip` 升级报 `SAFE_DELETE_FAIL_CLOSED` | Windows 沙箱回收站不可用 | 跳过升级，直接 `pip install -r requirements.txt`；若 pip 丢失用 `python -m ensurepip` 恢复 |
| `No module named pip` | 升级中断导致 pip 被移除 | `python -m ensurepip --upgrade` |
| 端口被占用 | 上一个服务未退出 | 换端口或结束占用进程 |
