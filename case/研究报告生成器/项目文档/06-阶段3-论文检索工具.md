# 06 · 阶段 3 — 论文检索工具

> 本阶段目标：实现多论文源检索（arXiv / Semantic Scholar / Europe PMC / Crossref / 综合开放源），并支持中文主题自动转英文检索词。

---

## 1. 目标

- 掌握 `tools/arxiv_search.py`：arXiv API 客户端封装（超时 Session、时间范围、双通道重试）。
- 掌握 `tools/paper_sources.py`：统一检索入口 `search_papers()` 与 4+1 论文源。
- 掌握 `agents/search_agent.py`：中文主题 → 英文检索词变体（LLM 翻译 + 词典翻译 + 原文 + ASCII）。
- 命令行实测：用真实主题检索论文并输出元数据。

## 2. 关键设计

### 2.1 arXiv 检索（`tools/arxiv_search.py`）

| 锚点 | 作用 |
|------|------|
| `arxiv_search.py:7-14` | `TimeoutSession`：为 requests 统一 20s 超时 |
| `arxiv_search.py:25-34` | `_build_search_query`：追加 `submittedDate:[start TO end]` 时间过滤 |
| `arxiv_search.py:63-81` | `search_arxiv`：**双通道重试**（先系统代理/环境，再直连），返回 `[]` 而非抛错 |

### 2.2 统一检索入口（`tools/paper_sources.py`）

`search_papers(query, source, max_results, years_back)`（`paper_sources.py:23-45`）：

- 5 个来源映射到 `PAPER_SOURCE_LABELS`（`paper_sources.py:10-16`）。
- `source="all_open"`（综合开放源）：依次查 4 个直连源并去重（`paper_sources.py:26-37`，去重见 `_dedupe_papers` `paper_sources.py:199-208`）。
- 各源 handler：`_search_arxiv:52` / `_search_semantic_scholar:57` / `_search_europe_pmc:96` / `_search_crossref:137`。
- 网络失败统一走 `_get_json`（`paper_sources.py:170-186`）代理/直连双通道。

### 2.3 检索词变体（`agents/search_agent.py`）

`search_agent()`（`search_agent.py:35-58`）：依次尝试检索词变体，第一个有结果的返回。

变体生成 `_query_variants()`（`search_agent.py:69-89`）：
1. **LLM 翻译**（`_translate_query` `search_agent.py:96-113`）：调 `invoke_llm` 把中文主题译为英文检索词（失败静默）。
2. **词典翻译**（`_dictionary_translate` `search_agent.py:116-124`）：内置 22 组常见术语映射（`_COMMON_TRANSLATIONS` `search_agent.py:9-32`），如 `量子计算→quantum computing`。
3. 原文。
4. ASCII 过滤（`_ascii_only` `search_agent.py:127-128`）。

## 3. 实操步骤

### 3.1 命令行实测检索

```bash
cd 源码/backend
.venv/Scripts/python.exe -c "
from tools.paper_sources import search_papers
papers = search_papers('graph neural networks', source='arxiv', max_results=3, years_back=2)
print('命中', len(papers), '篇')
for p in papers:
    print('-', p['title'][:60], '|', p['published'], '| source=', p['source'])
"
# 期望：返回 3 篇含 title/published/source=arXiv 的论文
```

### 3.2 实测中文主题自动翻译

```bash
.venv/Scripts/python.exe -c "
from agents.search_agent import _dictionary_translate, _query_variants
print('词典翻译:', _dictionary_translate('量子计算最新进展'))
print('变体列表:', _query_variants('量子计算最新进展'))
"
# 期望：词典翻译含 quantum computing；变体列表含英文词与原文
```

### 3.3 综合开放源

```bash
.venv/Scripts/python.exe -c "
from tools.paper_sources import search_papers
papers = search_papers('federated learning', source='all_open', max_results=5)
print('综合源命中', len(papers), '篇，来源去重后:', set(p.get('source') for p in papers))
"
```
