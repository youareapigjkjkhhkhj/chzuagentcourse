# 07 · 阶段 4 — PDF 阅读与阅读代理

> 本阶段目标：实现论文 PDF 的下载与文本抽取（带代理回退），并由阅读代理批量安全处理论文列表。

---

## 1. 目标

- 掌握 `tools/pdf_reader.py`：PDF 下载（双通道代理回退）→ 类型校验 → 临时文件 → `pdfplumber` 逐页抽取。
- 掌握 `agents/reader_agent.py`：批量阅读论文，跳过无 PDF / 空内容条目，统一追加 `text` 字段。
- 命令行实测：对公开 PDF 抽取文本并控制最大长度。

## 2. 关键设计

### 2.1 PDF 下载与校验（`tools/pdf_reader.py`）

| 锚点 | 作用 |
|------|------|
| `pdf_reader.py:8-22` | `_download_with_proxy_fallback`：先系统代理/环境，再直连（`trust_env` True/False 双通道），全部失败抛异常 |
| `pdf_reader.py:44-47` | 内容类型校验：`Content-Type` 含 `application/pdf` **或** 字节以 `%PDF` 开头 |
| `pdf_reader.py:49-51` | 写入 `tempfile.NamedTemporaryFile(suffix=".pdf")` |
| `pdf_reader.py:54-59` | `pdfplumber` 逐页 `extract_text()`，累计达 `max_length` 即停止 |
| `pdf_reader.py:60` | 返回截断到 `max_length` 的文本 |
| `pdf_reader.py:66-68` | `finally` 清理临时文件 |

> 设计取舍：抽取文本而非保留整页——内存可控；扫描版 PDF 无法抽取（文本层缺失），由调用方警告兜底。

### 2.2 阅读代理（`agents/reader_agent.py`）

`reader_agent(papers, max_length=3000)`（`reader_agent.py:4-33`）：

- 无 `pdf_url` → `[跳过]` 日志，继续下一篇。
- 抽取成功 → `item = dict(paper)` 保留元数据并加 `text`。
- 抽取失败/为空 → `[跳过]` 日志。

## 3. 实操步骤

### 3.1 实测单篇 PDF 抽取

```bash
cd 源码/backend
.venv/Scripts/python.exe -c "
from tools.pdf_reader import read_pdf_from_url
# 用 arXiv 公开 PDF 示例（需要网络）
text = read_pdf_from_url('https://arxiv.org/pdf/1706.03762.pdf', max_length=500)
print('抽取字符数 =', len(text) if text else 0)
print('开头预览   =', repr((text or '')[:120]))
"
# 期望：返回 >0 字符（Transformer 论文公开 PDF）
```

### 3.2 实测阅读代理批量处理

```bash
.venv/Scripts/python.exe -c "
from agents.reader_agent import reader_agent
papers = [
    {'title': '有PDF', 'pdf_url': 'https://arxiv.org/pdf/1706.03762.pdf'},
    {'title': '无PDF', 'pdf_url': ''},
]
contents = reader_agent(papers, max_length=300)
print('成功阅读 =', len(contents), '/ 2')
print('保留元数据 =', set(contents[0].keys()) >= {'title', 'text'})
"
# 期望：成功阅读 1/2（无 PDF 条目被跳过）；contents[0] 含 title+text
```

## 4. 可运行验证

| 验证项 | 命令 | 期望 |
|--------|------|------|
| 单篇抽取 | 3.1 | 返回文本且长度 ≤ max_length |
| 非 PDF 拒绝 | 传入 html 链接 | 返回 `None`（`[警告] URL 不是 PDF`） |
| 代理回退 | 断网环境 | `_download_with_proxy_fallback` 双通道失败抛错 → `read_pdf_from_url` 捕获返回 `None` |

**Checkpoint 达成标准**：网络可用时能抽取真实 PDF 文本；不可用/非 PDF 时静默返回 `None`，不中断流程。
