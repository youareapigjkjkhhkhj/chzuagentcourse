# 08 · 阶段 5 — 本地混合 RAG

> 本阶段目标：实现**不依赖远程 embedding API** 的本地混合检索：哈希特征向量 + FAISS 内积召回 + BM25 + 查询词覆盖率加权排序，并封装为证据上下文。

---

## 1. 目标

- 掌握 `vectorstore/embeddings.py`：中英文分词（token + bigram）与哈希特征向量（512 维、确定性、零依赖）。
- 掌握 `vectorstore/faiss_store.py`：FAISS 内积召回 + BM25 + overlap 三项融合排序与相关度分级。
- 掌握 `agents/rag_agent.py`：论文正文切块（带重叠）、检索文本组装、证据上下文格式化。
- 命令行实测：对构造语料检索，输出证据与相关度分数。

## 2. 关键设计

### 2.1 分词与哈希向量（`vectorstore/embeddings.py`）

`tokenize_for_retrieval(text)`（`embeddings.py:36-52`）产出四种 token：英文单词、英文 bigram、中文字符、中文 bigram（过滤停用词 `_STOP_WORDS` `embeddings.py:9-33`）。

`HashingEmbeddingModel`（`embeddings.py:55-84`）：
- `embed_query`（`embeddings.py:72-84`）：每个 token 用 `blake2b` 哈希映射到 512 维向量的一个槽位，符号由哈希高位决定，最后 L2 归一化。
- 特性：**确定性**（同文本同向量）、**无远程调用**、支持中英文混合。

### 2.2 混合检索（`vectorstore/faiss_store.py`）

`ResearchVectorStore`（`faiss_store.py:9`）：
- `add_documents`（`faiss_store.py:19-30`）：批量向量化 → `faiss.IndexFlatIP`（内积）→ 构建词法索引（`_build_lexical_index` `faiss_store.py:79-100`，含 IDF）。
- `search`（`faiss_store.py:32-77`）三项融合：

```python
# faiss_store.py:64-68
hybrid_score = (
    0.42 * normalized_vector[index]   # FAISS 内积（minmax 归一化）
    + 0.43 * normalized_bm25[index]   # BM25 词法（minmax 归一化）
    + 0.15 * overlap_scores[index]    # 查询词覆盖率
)
```

- 相关度分级 `_relevance_label`（`faiss_store.py:145-152`）：`≥0.72 高度相关 / ≥0.48 较相关 / ≥0.25 可参考 / 其余 弱相关`。
- `_bm25_score`（`faiss_store.py:102-120`）k1=1.4、b=0.72；`_overlap_score`（`faiss_store.py:122-129`）为查询词集合交集占比。

### 2.3 证据上下文（`agents/rag_agent.py`）

- `chunk_papers`（`rag_agent.py:4-36`）：正文按 1200 字符、180 重叠切块；`retrieval_text` 由「标题+摘要+检索词+来源+正文」拼接（`rag_agent.py:11-17`），提升召回。
- `build_rag_context`（`rag_agent.py:39-61`）：建库 → 检索 → 格式化为 `[Evidence N] 标题 / Relevance(xx%) / Source / 文本` 上下文块。
- `_build_query`（`rag_agent.py:64-84`）：主题 + 通用关注点 + 命中论文的检索词。

### 3.2 检索验证（构造语料）

```bash
.venv/Scripts/python.exe -c "
from agents.rag_agent import build_rag_context
contents = [
  {'title': 'GNN 推荐', 'abstract': 'graph neural networks for recommender systems',
   'search_query': 'graph neural networks', 'arxiv_url': 'https://arxiv.org/abs/1',
   'text': 'Graph neural networks propagate messages over user-item graphs. They improve collaborative filtering for recommender systems.'},
  {'title': '医学影像', 'abstract': 'deep learning for medical image segmentation',
   'search_query': 'medical image segmentation', 'arxiv_url': 'https://arxiv.org/abs/2',

ctx, ev = build_rag_context('graph neural networks recommendation', contents, top_k=3)
print('证据数 =', len(ev))
print('Top1   =', ev[0]['title'], '| 相关度', round(ev[0]['score'], 2), '|', ev[0]['relevance'])
print('上下文前80字 =', ctx[:80].replace(chr(10), ' '))
"
# 期望：Top1=GNN 推荐，相关度标签命中，上下文含 [Evidence 1]
```
