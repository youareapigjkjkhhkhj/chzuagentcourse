# 09 · 阶段 6 — 分析与写作代理

> 本阶段目标：实现「分析代理」（LLM 总结证据）与「写作代理」（LLM 生成结构化学术报告），并在未配置 API Key 时自动降级为**抽取式兜底报告**，保证系统始终可用。

---

## 1. 目标

- 掌握 `agents/analyst_agent.py`：`analyze()` 调 LLM 分析证据，`_fallback_analyze()` 无 Key 时抽取式总结。
- 掌握 `agents/writer_agent.py`：`write_report()` 生成带章节的报告，`_fallback_report()` 兜底 + 参考文献格式化。
- 命令行实测：无 API Key 走兜底链路产出完整 Markdown 报告。

## 2. 关键设计

### 2.1 分析代理（`agents/analyst_agent.py`）

- `analyze(contents, topic, rag_context, llm_config)`（`analyst_agent.py:26-44`）：构造分析 prompt（主题 + 证据 + 论文内容，要求基于证据回答），调 `invoke_llm`。
- 捕获 `LLMNotConfiguredError`（`analyst_agent.py:43`）→ `_fallback_analyze()`（`analyst_agent.py:4-23`）：抽取前 5 篇论文各 900 字符 + RAG 证据前 2500 字符，拼接为「问题设定/方法/实证发现/局限/开放问题」角度的抽取式总结。

### 2.2 写作代理（`agents/writer_agent.py`）

- `write_report(summary, topic, references, rag_context, language, llm_config)`（`writer_agent.py:63-103`）：
  - 语言控制（`writer_agent.py:71-75`）：`zh/en/auto`。
  - 写作要求（`writer_agent.py:88-96`）：Markdown、清晰标题、基于证据、含 background/findings/methods/limitations/future/conclusion，**禁止编造论文标题与引用**。
- 捕获 `LLMNotConfiguredError` → `_fallback_report()`（`writer_agent.py:33-60`）：抽取式兜底报告（Summary + Analysis + Research Notes + Evidence Excerpts + References）。
- 参考文献 `_format_references()`（`writer_agent.py:4-25`）：`[标题](链接) - 作者, 日期, 来源` 列表，链接优先 arXiv URL。

### 2.3 保存（`utils/file_utils.py`）

| 锚点 | 作用 |
|------|------|
| `file_utils.py:16-19` | `safe_filename`：非法字符替换为 `_`，最长 80 字符 |
| `file_utils.py:28-38` | `save_report`：写 `{topic}_report.md` |
| `file_utils.py:51-131` | `save_pdf`：Markdown→HTML→Playwright Chromium 渲染→A4 PDF；失败抛异常由上层捕获降级 |

## 3. 实操步骤

### 3.1 无 Key 兜底链路验证

```bash
cd 源码/backend
.venv/Scripts/python.exe -c "
from agents.analyst_agent import analyze
from agents.writer_agent import write_report
contents = [{'title': 'GNN', 'abstract': 'a', 'arxiv_url': 'https://arxiv.org/abs/1',
             'text': 'Graph neural networks improve recommendation systems.'}]
summary = analyze(contents, topic='graph neural networks', rag_context='[Evidence 1] GNN 文本', llm_config=None)
print('=== 分析(兜底) ===')
print(summary[:150], '...')
report = write_report(summary, 'graph neural networks', references=contents, rag_context='[Evidence 1]', language='zh', llm_config=None)
print('=== 报告(兜底) ===')
print(report[:200], '...')
print('包含 References:', '## References' in report)
"
# 期望：summary/report 均非空，report 含 # 标题与 References，且为中文（language=zh）
```

### 3.2 配置 Key 走 LLM 链路（需网络）

```bash
.venv/Scripts/python.exe -c "
from agents.llm_client import resolve_llm_settings
s = resolve_llm_settings({'provider': 'openai'})
print('将使用:', s['provider'], s['model'], s['base_url'])
from agents.writer_agent import write_report
r = write_report('short summary', 'quantum computing', language='zh', llm_config=None)
print('LLM 报告前 120 字:', r[:120].replace(chr(10), ' '))
"
```
