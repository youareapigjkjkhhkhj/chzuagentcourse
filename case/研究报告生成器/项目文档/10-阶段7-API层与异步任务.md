# 10 · 阶段 7 — API 层与异步任务

> 本阶段目标：把全部代理串成 FastAPI 异步任务流水线（JobStore 内存任务表 + 后台线程 + 轮询进度 + 下载），并同源托管前端构建产物。

---

## 1. 目标

- 掌握 `api/app.py`：`JobStore` 线程安全任务表、6 个 REST 路由、后台线程 `_run_report_job`。
- 掌握任务状态机：`queued → running(8%→94%) → completed|failed`。
- 掌握前端同源托管：`源码/frontend/dist` 由 FastAPI 静态挂载。
- 命令行实测：创建任务 → 轮询 → 下载 Markdown/PDF。

## 2. 关键设计

### 2.1 数据模型（`api/app.py`）

- `LLMConfig`（`api/app.py:33-37`）：provider 枚举 `deepseek|openai|custom` + key/model/base_url。
- `ReportRequest`（`api/app.py:40-55`）：主题（2–200 字符）、论文数 1–10、时间范围 0–20 年、论文源枚举、每篇字符 1000–20000、证据数 1–20、语言、是否启用 RAG、LLM 配置。

### 2.2 JobStore（`api/app.py:58-124`）

线程安全（`_lock`）的任务字典：`create`（生成 `uuid4` 任务与初始字段）/ `get` / `list`（按创建时间倒序）/ `update` / `log` / `warn`。

> 注意：任务保存在**进程内**，重启服务后列表清空，但已生成的报告文件仍保留在 `generated_reports/`。

### 2.3 路由

| 路由 | 锚点 | 作用 |
|------|------|------|
| `GET /api/health` | `api/app.py:148-150` | 健康检查 |
| `POST /api/reports` | `api/app.py:153-158` | 创建任务并立即启动后台线程 |
| `GET /api/reports` | `api/app.py:161-163` | 任务列表 |
| `GET /api/reports/{job_id}` | `api/app.py:166-171` | 任务详情（进度/证据/报告） |
| `GET /api/reports/{job_id}/download/{kind}` | `api/app.py:174-184` | 下载 markdown/pdf，404 兜底 |

### 2.4 流水线（`_run_report_job`，`api/app.py:192-285`）

```text
Planning 8% → Searching 22% → Reading 42% → RAG 58% → Analyzing 72%
→ Writing 86% → Saving 94% → Completed 100%  (任一步异常 → failed)
```

- 无论文 → `jobs.warn`（`api/app.py:212-213`）；无 PDF 内容 → warn（`:217-218`）；PDF 生成失败 → warn 但保留 Markdown（`:264-265`）。
- 证据字段裁剪为前端展示所需（`_slim_evidence` `api/app.py:288-304`）。
- 静态托管（`api/app.py:319-321`）：`frontend_dist = ROOT.parent / "frontend" / "dist"`（与 backend 平级，镜像项目一/二约定）。

## 3. 实操步骤

### 3.1 启动服务

```bash
cd 源码/backend
.venv/Scripts/python.exe -m uvicorn api.app:app --host 127.0.0.1 --port 8000
```

### 3.2 创建任务并轮询（需网络；无 Key/断网走兜底）

```bash
# 创建
curl -s -X POST http://127.0.0.1:8000/api/reports \
  -H "Content-Type: application/json" \
  -d '{"topic":"graph neural networks for recommendation","max_results":3,"paper_source":"arxiv","language":"zh","llm":{"provider":"openai","api_key":"","model":"","base_url":""}}'

# 轮询（替换 report_id）
curl -s http://127.0.0.1:8000/api/reports/<report_id> | python -m json.tool
# 观察 stage/progress 直到 completed

# 下载
curl -s -o report.md  http://127.0.0.1:8000/api/reports/<report_id>/download/markdown
curl -s -o report.pdf http://127.0.0.1:8000/api/reports/<report_id>/download/pdf
```

### 3.3 前端同源访问

```bash
curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:8000/
# 期望 200（阶段 8 构建 dist 后生效）
```
