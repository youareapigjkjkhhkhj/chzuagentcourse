### 2.2 服务层与后端路由对应（`src/services/api.js`）

| 前端函数 | 锚点 | 后端路由 |
|----------|------|----------|
| `createReport(payload)` | `api.js:20-25` | `POST /api/reports` |
| `getReport(id)` | `api.js:27-29` | `GET /api/reports/{id}` |
| `listReports()` | `api.js:31-33` | `GET /api/reports` |
| `downloadUrl(id, kind)` | `api.js:35-37` | `GET /api/reports/{id}/download/{kind}` |

### 2.3 核心交互（`App.vue`）

- 默认服务商 **OpenAI + gpt-5-mini**（`App.vue:30-34, 53-59`），API Key 留空走后端 `.env`。
- 任务轮询：`startPolling`（`App.vue:175-188`）每 1.4s 拉取，终态自动停止并刷新列表。
- 表单校验：主题必填；custom 服务商必填 Base URL（`App.vue:153-156`）。
- API Key 可勾选「记住在本机浏览器」（localStorage，不落后端）。

## 4. 排错速查（FAQ）

| 现象 | 原因 | 处理 |
|------|------|------|
| `GET /` 返回 404/JSON | `frontend/dist` 未构建 | `cd 源码/frontend && npm run build` |
| 前端接口 502 | 后端未启动/端口不对 | 确认 8000 端口 uvicorn 运行 |
| PDF 下载 404 | Playwright Chromium 未安装 | `playwright install chromium`；失败仅 warn，Markdown 不受影响 |
| 报告全英文 | `language=auto` 且主题英文 | 前端选「中文」或主题用中文 |
| `runtime_cache` 文件多 | 本地响应缓存 | `.env` 设 `LLM_RESPONSE_CACHE=0` |
| 任务列表重启后为空 | JobStore 为进程内存储 | 属预期；报告文件仍在 `generated_reports/` |
| 沙箱报 `SAFE_DELETE_FAIL_CLOSED` | 临时 html 删除被拦截 | 仅开发沙箱现象；残留 `*_report_temp.html` 可手动清理，生产环境无此问题 |

## 5. 部署建议

- 生产：`npm run build` 后仅需后端单进程（uvicorn 8000 同源托管），无需 Node 环境。
- 反代：Nginx `location / { proxy_pass http://127.0.0.1:8000; }`。
- 多任务：后台线程按任务隔离，可扩展为 Celery/RQ 队列持久化。
