# 01 - 安装与环境配置

本篇目标：在本机装好 AgentScope 2.0，并验证版本与 API Key 配置，为后续所有教程扫清环境障碍。

## 1.1 前置要求

- **Python ≥ 3.11**（官方硬性要求，3.10 及以下无法安装 2.0）
- 包管理器：`pip`（推荐 `uv`，更快）
- 一个模型厂商 API Key（本文以阿里云 **DashScope** 为例，其他厂商见 [03-模型Model.md](03-模型Model.md)）

检查 Python 版本：

```bash
python --version
# 期望输出：Python 3.11.x 或更高
```

## 1.2 安装 AgentScope

**方式一：PyPI（推荐）**

```bash
# 基础 SDK（核心框架，含 Agent / Model / Tool / 事件系统）
pip install agentscope

# 完整依赖（额外含 Runtime、Studio、各模型提供商、MCP、Mem0 等）
pip install agentscope[full]
```

> Windows 用户若遇到引号转义问题，用：`pip install "agentscope[full]"`。

**方式二：源码安装（追新特性）**

```bash
git clone -b main https://github.com/agentscope-ai/agentscope.git
cd agentscope
pip install -e .
```

**方式三：uv（更快）**

```bash
uv pip install agentscope          # 或 uv pip install agentscope[full]
```

## 1.3 验证安装

```bash
python -c "import agentscope; print(agentscope.__version__)"
```

期望输出：`2.0.x`（如 `2.0.4`）。

> ⚠️ **2.0 注意事项**：若输出 `1.0.x` 或 `0.1.x`，说明装的是旧版，请升级：
> ```bash
> pip install -U agentscope
> ```
> 本教程全部代码基于 **2.0** API，旧版运行会报错。

## 1.4 配置 API Key（环境变量）

AgentScope 2.0 推荐通过**环境变量**注入密钥，不写死在代码里。以 DashScope 为例：

**Linux / macOS**

```bash
export DASHSCOPE_API_KEY="sk-你的密钥"
```

**Windows（PowerShell）**

```powershell
$env:DASHSCOPE_API_KEY="sk-你的密钥"
```

**Windows（CMD）**

```cmd
set DASHSCOPE_API_KEY=sk-你的密钥
```

其他厂商对应的环境变量（选你用的即可）：

| 厂商 | 环境变量 | 对应 Credential |
|------|----------|----------------|
| 阿里云 DashScope | `DASHSCOPE_API_KEY` | `DashScopeCredential` |
| OpenAI | `OPENAI_API_KEY` | `OpenAICredential` |
| Anthropic | `ANTHROPIC_API_KEY` | `AnthropicCredential` |
| Google Gemini | `GEMINI_API_KEY` | `GeminiCredential` |
| DeepSeek | `DEEPSEEK_API_KEY` | `DeepSeekCredential` |
| Moonshot | `MOONSHOT_API_KEY` | `MoonshotCredential` |
| xAI | `XAI_API_KEY` | `XAICredential` |
| Ollama（本地） | 无需 Key | `OllamaChatModel`（本机 `http://localhost:11434`） |

> 提示：Credential 类的确切命名遵循 `{Provider}Credential` 约定（如 `OpenAICredential`），与 `ChatModel` 一一配对。详见 [03-模型Model.md](03-模型Model.md)。

## 1.5 推荐的项目结构

```text
my_agentscope_app/
├── main.py              # 入口脚本
├── agents/              # 自定义智能体
├── tools/               # 自定义 @tool 函数
├── workspace/           # AgentScope 工作区（文件/代码落盘处）
└── .env                 # 本地环境变量（不提交到 Git）
```

## 关键 API 速查

| 操作 | 命令 / 代码 |
|------|------------|
| 安装 | `pip install agentscope[full]` |
| 验证版本 | `import agentscope; print(agentscope.__version__)` |
| 注入 Key | `export DASHSCOPE_API_KEY=sk-xxx` |

## 2.0 注意事项

- **Python 必须 3.11+**，低于此版本无法安装 2.0。
- 旧版用 `pip install agentscope[all]` / `agentscope[dev]`，2.0 统一为 `agentscope[full]`。
- 2.0 **不再需要** `agentscope.init()` 与 `model_config.json`，模型以对象形式直接传入 `Agent(model=...)`。
