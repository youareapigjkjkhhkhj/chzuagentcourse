# 02 - 快速开始

本篇目标：用最短代码跑通两个「最小闭环」——（A）终端交互式对话；（B）脚本内调用并流式打印。代码全部基于 2.0 官方 API。

## 2.1 前置准备

```bash
pip install agentscope          # 已完成 01 篇安装
export DASHSCOPE_API_KEY="sk-你的密钥"   # 已配置 Key
```

## 2.2 方式 A：终端交互（launch_console）

最简的「会聊天」智能体，只需把模型塞进 `Agent`，交给 `launch_console` 即可。流式渲染、Ctrl+C 中断、工具确认都由它包办，你**不用写任何 UI 代码**。

```python
# main.py
import os
import asyncio

from agentscope.agent import Agent
from agentscope.console import launch_console
from agentscope.credential import DashScopeCredential
from agentscope.model import DashScopeChatModel


async def main() -> None:
    # 一个会聊天的智能体，就三件事：名字、人设、模型
    agent = Agent(
        name="Friday",
        system_prompt="You're a helpful assistant named Friday.",
        model=DashScopeChatModel(
            credential=DashScopeCredential(api_key=os.environ["DASHSCOPE_API_KEY"]),
            model="qwen3.6-plus",
        ),
    )
    # 在终端直接开聊：流式输出、中断都已内置
    await launch_console(agent)


asyncio.run(main())
```

运行：

```bash
python main.py
```

终端里直接输入消息即可与 Friday 对话；按 `Ctrl+C` 可优雅中断。

## 2.3 方式 B：脚本内调用（reply / reply_stream）

如果你要**在代码里调用**而非开终端，用 `Agent.reply()`（等最终回复）或 `Agent.reply_stream()`（流式事件）。

```python
# quickstart_script.py
import os
import asyncio

from agentscope.agent import Agent
from agentscope.credential import DashScopeCredential
from agentscope.event import EventType
from agentscope.message import UserMsg
from agentscope.model import DashScopeChatModel
from agentscope.tool import Toolkit, Bash, Read, Write, Edit


async def main() -> None:
    agent = Agent(
        name="Friday",
        system_prompt="You are a helpful assistant named Friday.",
        model=DashScopeChatModel(
            credential=DashScopeCredential(api_key=os.environ["DASHSCOPE_API_KEY"]),
            model="qwen-plus",
        ),
        toolkit=Toolkit(tools=[Bash(), Read(), Write(), Edit()]),
    )

    user_msg = UserMsg(name="user", content="Hello, who are you?")

    # 方式一：等待最终回复
    reply_msg = await agent.reply(user_msg)
    print(reply_msg.content)

    # 方式二：流式获取增量事件
    async for event in agent.reply_stream(user_msg):
        match event.type:
            case EventType.TEXT_BLOCK_DELTA:
                # 流式文本片段
                print(event.delta, end="")
            case EventType.TOOL_CALL_START:
                # 智能体即将调用工具
                print(f"\n[调用工具: {event.tool_name}]")
            case _:
                pass


asyncio.run(main())
```

运行：

```bash
python quickstart_script.py
```

## 2.4 代码逐行解读

| 行 | 作用 |
|----|------|
| `Agent(name=, system_prompt=, model=, toolkit=)` | 2.0 核心智能体；模型与工具都是**对象**，不再是 1.0 的字符串 `config_name` |
| `DashScopeChatModel(credential=DashScopeCredential(api_key=...), model=...)` | 模型即对象，`credential` 封装密钥 |
| `UserMsg(name="user", content=...)` | 2.0 的消息类型（**不是** 1.0 的 `Msg`） |
| `await agent.reply(msg)` | 异步运行推理-行动循环，返回最终消息 |
| `async for event in agent.reply_stream(msg)` | 异步生成器，逐事件流式产出 |
| `EventType.TEXT_BLOCK_DELTA` / `TOOL_CALL_START` | 事件类型，用于驱动 UI / 日志 |

## 关键 API 速查

| API | 说明 |
|-----|------|
| `Agent(name, system_prompt, model, toolkit=)` | 创建智能体 |
| `await launch_console(agent)` | 终端交互（流式 + 中断内置） |
| `await agent.reply(UserMsg)` | 同步等待最终回复 |
| `async for e in agent.reply_stream(UserMsg)` | 流式事件循环 |
| `UserMsg(name, content)` | 构造用户输入消息 |

## 2.0 注意事项

- **务必 `await`**：`reply` / `reply_stream` / `launch_console` 都是 `async`，入口函数用 `asyncio.run(main())` 驱动。
- **消息用 `UserMsg`**，不是 `Msg`（1.0 写法，2.0 已移除）。
- 模型**直接传对象** `model=DashScopeChatModel(...)`，不再用 `model_config_name="xxx"`（1.0 写法）。
