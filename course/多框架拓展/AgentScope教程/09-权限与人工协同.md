# 09 - 权限与人工协同

本篇目标：让智能体「管得住」。2.0 的权限系统在工具调用前加一道闸——**确认 / 拒绝 / 按规则放行**，解决「它会不会干危险的事」的担忧。

## 9.1 为什么需要权限

文件删除、命令执行、API 写入，全靠模型自觉是不可接受的。AgentScope 2.0 提供**三重防护**（官方描述）：

1. **工具级审查**：每个工具可声明危险等级
2. **人工协同（HITL）**：调用前弹确认
3. **沙箱隔离**：工具在隔离环境执行（见 [11-工作区与沙箱Workspace.md](11-工作区与沙箱Workspace.md)）

## 9.2 交互式确认（launch_console）

用 `launch_console` 开终端对话时，工具调用会**自动弹确认**：

```python
import os
import asyncio

from agentscope.agent import Agent
from agentscope.console import launch_console
from agentscope.credential import DashScopeCredential
from agentscope.model import DashScopeChatModel
from agentscope.tool import Toolkit, Bash, Read, Write, Edit


async def main() -> None:
    agent = Agent(
        name="Friday",
        system_prompt="You are a helpful assistant. Use tools when needed.",
        model=DashScopeChatModel(
            credential=DashScopeCredential(api_key=os.environ["DASHSCOPE_API_KEY"]),
            model="qwen-plus",
        ),
        toolkit=Toolkit(tools=[Bash(), Read(), Write(), Edit()]),
    )
    await launch_console(agent)  # 工具调用时终端弹确认


asyncio.run(main())
```

确认交互行为：

| 输入 | 含义 |
|------|------|
| `y` | 放行**这一次**调用 |
| `a` | 接受建议的权限规则，之后**同类调用不再询问** |
| `n` / 拒绝 | 拒绝本次调用 |

**默认策略**：只读工具（`Read` / `Grep`）静默放行；写操作（`Write` / `Edit` / `Bash`）弹窗确认。

## 9.3 bypass 模式（无人值守）

批量跑批 / 可信环境想端到端全自动，切到 **bypass 模式**：按既定规则自动放行，不再逐次确认。

```python
# 通过权限配置开启 bypass（具体配置项以官方文档为准）
# 思路：设置权限模式为 bypass，框架按规则端到端执行，不阻塞对话
```

> bypass 模式会跳过人工确认，**仅在可信环境 / 沙箱内**使用，避免误删或越权。

## 9.4 细粒度权限

2.0 权限系统支持对**工具与资源**做细粒度控制（确认、bypass、拒绝等模式）。典型配置维度：

- 按工具类型：只读 vs 写操作
- 按资源：特定目录 / 特定命令前缀
- 按会话/租户：多租户下不同权限边界（见 [16-AgentService与部署.md](16-代理Service与部署.md)）

## 关键机制速查

| 机制 | 说明 |
|------|------|
| 工具调用确认（`y`/`a`/`n`） | 交互式 HITL |
| 默认静默放行只读工具 | 安全与效率平衡 |
| bypass 模式 | 无人值守端到端执行 |
| 沙箱隔离 | 危险操作限制在容器内 |

## 2.0 注意事项

- 权限是 2.0 的**一等公民**，生产环境务必启用；默认为交互式确认，不要直接 bypass 到生产。
- 危险操作（删除/执行命令）必须配合**沙箱**（见 11 篇），即便确认过也应隔离。
- 权限的精确对象级 API（如 `PermissionMiddleware` 构造参数）以官方文档 [docs.agentscope.io](https://docs.agentscope.io/) 为准；本文描述其机制与交互行为。
