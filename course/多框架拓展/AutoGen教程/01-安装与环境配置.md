# 01 - 安装与环境配置

本篇目标：装好 AutoGen 三件套、验证版本、配置 API Key，理解 v0.2 与 v0.4/0.7 的环境隔离。

## 1.1 前置要求

| 项 | 要求 |
|----|------|
| Python | **3.10 及以上**（官方文档明确要求） |
| 包管理 | pip（或 uv / poetry，官方仓库同时提供 `pyproject.toml`） |
| 模型 | 任意 OpenAI 兼容服务（OpenAI / Azure / Gemini / Llama API / Ollama…） |

## 1.2 安装

```bash
# 必须：AgentChat 高层 API + OpenAI 模型客户端扩展
pip install -U "autogen-agentchat" "autogen-ext[openai]"

# 可选：Azure OpenAI
pip install -U "autogen-ext[openai,azure]"

# 可选：本地 Ollama 模型
pip install -U "autogen-ext[ollama]"

# 可选：无代码 GUI（AutoGen Studio）
pip install -U "autogenstudio"
```

三个包的职责：

| 包 | 作用 |
|----|------|
| `autogen-agentchat` | 高层 API：预设 Agent、团队、终止条件、UI（Console） |
| `autogen-core` | 底层：模型客户端协议、agent runtime、消息与序列化（作为依赖自动安装） |
| `autogen-ext` | 扩展：模型客户端、代码执行、MCP、Memory、缓存等 |

> 三个包**同版本号发布**（当前稳定版 0.7.5）。若手动指定版本，请保持一致：
> `pip install autogen-agentchat==0.7.5 autogen-core==0.7.5 autogen-ext==0.7.5`

## 1.3 验证安装

```bash
python -c "import autogen_agentchat, autogen_core, autogen_ext; print(autogen_agentchat.__version__)"
```

```python
# 验证导入路径（v0.4 起的新路径）
from autogen_agentchat.agents import AssistantAgent
from autogen_ext.models.openai import OpenAIChatCompletionClient
print("✅ AutoGen v0.4+ 环境正常")
```

> 若看到 `ModuleNotFoundError: No module named 'autogen'` 而你写的是 `from autogen import ...`，说明你用的是 **v0.2 旧写法**——请改用新路径（见 README 的迁移表）。

## 1.4 配置 API Key

推荐用环境变量，避免硬编码：

```bash
# Windows PowerShell
$env:OPENAI_API_KEY="sk-你的密钥"

# Linux / macOS
export OPENAI_API_KEY="sk-你的密钥"
```

设置了 `OPENAI_API_KEY` 后，代码中可省略 `api_key` 参数：

```python
from autogen_ext.models.openai import OpenAIChatCompletionClient

model_client = OpenAIChatCompletionClient(model="gpt-4o")  # 自动读取环境变量
```

## 1.5 v0.2 与 v0.4 环境隔离（重要）

两个版本 API 不兼容，**不要装在同一环境**：

```bash
# v0.4/0.7 环境
python -m venv autogen07_env
autogen07_env\Scripts\activate          # Windows
pip install -U "autogen-agentchat" "autogen-ext[openai]"

# v0.2 环境（仅维护旧项目时使用）
python -m venv autogen02_env
autogen02_env\Scripts\activate
pip install "autogen-agentchat~=0.2"
```

| 检查项 | v0.2 | v0.4 / 0.7 |
|--------|------|-----------|
| 安装 | `pip install autogen-agentchat~=0.2` | `pip install -U "autogen-agentchat"` |
| 导入 | `from autogen import AssistantAgent` | `from autogen_agentchat.agents import AssistantAgent` |
| `pyautogen` | 0.2.34 起官方不再维护 | — |

## 1.6 关闭客户端（必做）

所有模型客户端用完必须 `close()`，释放底层 HTTP 连接：

```python
await model_client.close()
```

## 关键 API 速查

| API | 说明 |
|-----|------|
| `pip install -U "autogen-agentchat" "autogen-ext[openai]"` | 标准安装 |
| `OpenAIChatCompletionClient(model=...)` | OpenAI 兼容客户端（读 `OPENAI_API_KEY`） |
| `await model_client.close()` | 关闭连接 |

## 注意事项

- AutoGen 全异步：脚本中用 `asyncio.run(main())`，Jupyter 中可直接 `await`。
- v0.2 的 `llm_config` / `config_list` 在 v0.4 已移除，改为模型客户端对象。
- 工具调用在 **同一个 Agent 内部**完成，不再需要 `UserProxyAgent` 执行代码（除非你要真的人工输入）。
