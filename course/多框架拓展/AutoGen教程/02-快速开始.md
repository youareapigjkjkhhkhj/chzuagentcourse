# 02 - 快速开始

本篇目标：跑通 AutoGen 的两个最小闭环——**非流式**拿到结果、**流式**实时观察 Agent 的思考与工具调用。

## 2.1 前置准备

```bash
pip install -U "autogen-agentchat" "autogen-ext[openai]"
export OPENAI_API_KEY="sk-你的密钥"
```

## 2.2 最小 Agent（非流式）

```python
import asyncio

from autogen_agentchat.agents import AssistantAgent
from autogen_ext.models.openai import OpenAIChatCompletionClient


async def main() -> None:
    model_client = OpenAIChatCompletionClient(model="gpt-4o")
    agent = AssistantAgent("assistant", model_client=model_client)
    print(await agent.run(task="Say 'Hello World!'"))
    await model_client.close()


asyncio.run(main())
```

`run()` 返回 `TaskResult`，其中 `messages` 记录了 Agent 的**全部消息**（含最终回复）。

## 2.3 流式输出（推荐）

`run_stream()` 是异步生成器，逐条产出消息/事件，最后一项是 `TaskResult`。配合 `Console` 可直接格式化打印：

```python
import asyncio

from autogen_agentchat.agents import AssistantAgent
from autogen_agentchat.ui import Console
from autogen_ext.models.openai import OpenAIChatCompletionClient


async def main() -> None:
    model_client = OpenAIChatCompletionClient(
        model="gpt-4o",
        # api_key="YOUR_API_KEY",   # 已设环境变量可省略
    )
    agent = AssistantAgent(
        name="weather_agent",
        model_client=model_client,
        system_message="You are a helpful assistant.",
        model_client_stream=True,   # 逐 token 流式
    )

    await Console(agent.run_stream(task="What is the weather in New York?"))
    await model_client.close()


asyncio.run(main())
```

## 2.4 带工具的完整闭环（官方 Quickstart 示例）

定义一个异步函数作为工具，Agent 会自主决定是否调用它：

```python
from autogen_agentchat.agents import AssistantAgent
from autogen_agentchat.ui import Console
from autogen_ext.models.openai import OpenAIChatCompletionClient

model_client = OpenAIChatCompletionClient(
    model="gpt-4o",
    # api_key="YOUR_API_KEY",
)

# 定义工具（async def + 类型注解 + docstring，缺一不可）
async def get_weather(city: str) -> str:
    """Get the weather for a given city."""
    return f"The weather in {city} is 73 degrees and Sunny."

agent = AssistantAgent(
    name="weather_agent",
    model_client=model_client,
    tools=[get_weather],
    system_message="You are a helpful assistant.",
    reflect_on_tool_use=True,   # 拿到工具结果后再生成自然语言总结
    model_client_stream=True,
)

# 在脚本中：asyncio.run(main())；在 Notebook 中可直接 await
await Console(agent.run_stream(task="What is the weather in New York?"))
await model_client.close()
```

运行后控制台依次显示：用户任务 → `ToolCallRequestEvent`（模型决定调用 `get_weather`）→ `ToolCallExecutionEvent`（工具返回 73 度）→ Agent 最终回答。

## 2.5 run() 返回了什么

`run()` 返回的 `TaskResult.messages` 是一个消息列表，例如工具调用场景：

```python
result = await agent.run(task="Find information on AutoGen")
for msg in result.messages:
    print(type(msg).__name__, "->", msg.source)
```

输出类似：

```text
TextMessage              -> user
ToolCallRequestEvent     -> assistant      # 模型请求调用工具
ToolCallExecutionEvent   -> assistant      # 工具执行结果
ToolCallSummaryMessage   -> assistant      # 最终自然语言总结
```

## 2.6 脚本 vs Notebook

| 环境 | 写法 |
|------|------|
| Python 脚本 | `asyncio.run(main())` |
| Jupyter / 已有事件循环 | 直接 `await main()` |

## 关键 API 速查

| API | 说明 |
|-----|------|
| `AssistantAgent(name, model_client=, tools=, system_message=)` | 创建助手 Agent |
| `await agent.run(task="...")` | 非流式运行，返回 `TaskResult` |
| `async for m in agent.run_stream(task="...")` | 流式产出消息，末项为 `TaskResult` |
| `await Console(agent.run_stream(...))` | 格式化打印到控制台 |
| `reflect_on_tool_use=True` | 工具结果后再反思总结 |
| `await model_client.close()` | 关闭客户端 |

## 注意事项

- **Agent 是有状态的**：`run()` 会把消息追加进内部历史；再次 `run(task=...)` 会在此基础上继续。
- 不传 `task` 调用 `run()`，可让 Agent 基于当前状态继续生成。
- 工具必须用 `async def`，带类型注解和 docstring（框架据此生成 JSON Schema 给模型）。
- 与 v0.2 不同：工具由 **Agent 自己**执行，不需要另一个 Agent 代跑。
