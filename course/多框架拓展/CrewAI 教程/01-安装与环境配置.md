# 01 - 安装与环境配置

本篇目标：在本机装好 CrewAI，创建第一个项目脚手架，配置 API Key，为后续所有教程扫清环境障碍。

## 1.1 前置要求

- **Python ≥ 3.10**
- 包管理器：`uv`（官方推荐，比 pip 更快）
- 一个模型厂商的 API Key（OpenAI / Anthropic / Gemini / DeepSeek / Ollama 均可）
- 可选：Serper.dev API Key（`SERPER_API_KEY`，用于网络搜索工具）

检查 Python 版本：

```bash
python --version
# 期望：Python 3.10.x 或更高
```

## 1.2 安装 uv（推荐）

CrewAI 使用 `uv` 作为依赖管理和包处理工具。

**macOS / Linux**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows（PowerShell）**

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**Windows（pip 方式）**

```bash
pip install uv
```

验证安装：

```bash
uv --version
```

## 1.3 安装 CrewAI

使用 uv 创建并安装：

```bash
# 创建虚拟环境并安装 crewai
uv install crewai
```

或用 pip：

```bash
pip install crewai
```

安装额外工具包（用于 Agent 的工具集）：

```bash
pip install crewai-tools
```

验证安装：

```bash
crewai version
```

## 1.4 配置 API Key（环境变量）

以 OpenAI 为例：

**Linux / macOS**

```bash
export OPENAI_API_KEY="sk-你的密钥"
```

**Windows（PowerShell）**

```powershell
$env:OPENAI_API_KEY="sk-你的密钥"
```

**Windows（CMD）**

```cmd
set OPENAI_API_KEY=sk-你的密钥
```

推荐在项目根目录创建 `.env` 文件（不提交 Git）：

```env
# .env
OPENAI_API_KEY=sk-你的密钥
SERPER_API_KEY=your_serper_key
```

其他常用厂商环境变量：

| 厂商 | 环境变量 | 说明 |
|------|----------|------|
| OpenAI | `OPENAI_API_KEY` | 最常用 |
| Anthropic | `ANTHROPIC_API_KEY` | Claude 系列 |
| Google Gemini | `GEMINI_API_KEY` | Gemini 系列 |
| DeepSeek | `DEEPSEEK_API_KEY` | 中文场景 |
| Ollama（本地） | 无需 Key | 本机 `http://localhost:11434` |

## 1.5 创建第一个项目

CrewAI v1.15+ 默认创建 **JSON-first** 项目：

```bash
crewai create crew my_first_crew
cd my_first_crew
```

生成的项目结构：

```
my_first_crew/
├── agents/               # 每个 Agent 一个 .jsonc 文件
│   └── (agent_name).jsonc
├── crew.jsonc            # Crew 级设置 + 任务定义
├── main.py               # Flow 入口（如果创建了 flow）
├── pyproject.toml        # 项目配置
└── .env                  # 环境变量
```

经典 YAML 方式（`--classic` 标志）：

```bash
crewai create crew my_first_crew --classic
```

生成的结构：

```
my_first_crew/
├── crew.py               # @CrewBase 装饰器定义
├── config/
│   ├── agents.yaml       # Agent 配置
│   └── tasks.yaml        # 任务配置
├── pyproject.toml
└── .env
```

## 1.6 运行项目

```bash
crewai run
```

`crewai run` 自动检测 `crew.jsonc` 或 `crew.json`，加载引用的 Agent 文件，提示缺失的占位值，然后启动 Crew。

## 关键 API 速查

| 操作 | 命令 / 代码 |
|------|------------|
| 创建项目 | `crewai create crew my_crew` |
| 运行项目 | `crewai run` |
| 查看版本 | `crewai version` |
| 注入 Key | `export OPENAI_API_KEY=sk-xxx` |
| YAML 项目 | `crewai create crew my_crew --classic` |

## 常见问题

- **`crewai` 命令找不到**：确认 CrewAI 已安装，且虚拟环境已激活。
- **API Key 无效**：检查环境变量名称是否正确、值与官网密钥一致。
- **网络问题**：确保能访问模型 API 端点（国内如使用 OpenAI 需代理）。
