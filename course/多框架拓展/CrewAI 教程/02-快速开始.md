# 02 - 快速开始

本篇目标：创建你的第一个 **Flow**（包含一个 Crew、一个 Agent、一个 Task），端到端跑通：输入研究主题 → Agent 搜索网络 → 生成 Markdown 报告。

## 2.1 项目结构

```text
my_flow_app/
├── agents/
│   └── researcher.jsonc       # 研究人员 Agent
├── crew.jsonc                  # Crew 配置 + 任务
├── main.py                     # Flow 入口
├── pyproject.toml
└── .env
```

## 2.2 创建项目

```bash
# 创建 crew-only 项目
crewai create crew latest_ai_flow
cd latest_ai_flow
```

或者创建带 Flow 的项目：

```bash
crewai create flow latest_ai_flow
```

## 2.3 配置 Agent（agents/researcher.jsonc）

```jsonc
{
  "name": "researcher",
  "role": "科技研究员",
  "goal": "深入调研最新的人工智能领域进展",
  "backstory": "你是一位资深科技分析师，擅长追踪前沿 AI 技术并将其转化为通俗易懂的报告。",
  "tools": ["serper_dev_tool"],
  "llm": "openai/gpt-4o"
}
```

> 关键字段：`name`（必须与引用处一致）、`role`、`goal`、`backstory` 定义行为，`tools` 挂载工具，`llm` 指定模型。

## 2.4 配置 Crew 和任务（crew.jsonc）

```jsonc
{
  "agents": ["researcher"],
  "tasks": [
    {
      "name": "research_latest_ai",
      "description": "研究「{topic}」这个主题在 2026 年的最新进展，包括主要突破、关键公司和核心论文。",
      "expected_output": "一份结构化的研究摘要，包含 5 个要点，每个要点 3-4 句。",
      "agent": "researcher",
      "output_file": "output/report.md"
    }
  ],
  "process": "sequential",
  "verbose": true
}
```

> `{topic}` 是占位符，运行时由 Flow 注入实际值。`output_file` 将任务结果写入磁盘。

## 2.5 创建 Flow 入口（main.py）

```python
from crewai.flow import Flow, listen, start
from pydantic import BaseModel
from crewai import Crew

class LatestAIState(BaseModel):
    topic: str = ""
    report: str = ""

class LatestAiFlow(Flow[LatestAIState]):

    @start()
    def prepare_topic(self):
        self.state.topic = "2026年多模态大模型的最新进展"
        print(f"研究主题：{self.state.topic}")

    @listen(prepare_topic)
    def run_research(self):
        print(f"Crew 开始研究：{self.state.topic}")
        crew = Crew(
            agents=[],
            tasks=[],
            process="sequential",
        )
        result = kickoff_content_crew(self.state.topic)
        self.state.report = result

    @listen(run_research)
    def summarize(self):
        print(f"研究报告完成：{self.state.topic}")
        print(self.state.report)

def kickoff_content_crew(topic: str) -> str:
    from crewai import Crew, Agent, Task
    # 实际代码中加载 crew.jsonc
    crew = Crew(
        agents=[Agent(
            name="researcher",
            role="科技研究员",
            goal="深入调研最新AI进展",
            backstory="资深科技分析师"
        )],
        tasks=[Task(
            name="research_latest_ai",
            description=f"研究「{topic}」的最新进展",
            expected_output="结构化的研究摘要",
        )],
    )
    return crew.kickoff(inputs={"topic": topic})

# 运行 Flow
if __name__ == "__main__":
    latest_ai_flow = LatestAiFlow()
    latest_ai_flow.kickoff()
```

## 2.6 运行

```bash
crewai run
# 或
python main.py
```

## 2.7 如何理解：Flow 与 Crew 如何配合

```
Flow ──► prepare_topic（准备主题）
  │
  ├──► run_research（调用 Crew 执行研究任务）
  │        └── Crew ──► researcher Agent ──► Serper 搜索 ──► 生成报告
  │                                                          │
  └──► summarize（获取结果，写入 output/report.md ◄──────┘
```

- **Flow** 持有状态（`state.topic`、`state.report`），决定执行顺序
- **Crew** 内的 Agent 协作执行具体任务
- 每个 `@listen()` 装饰的方法监听上一步的输出并自动触发

## 2.8 命名一致性（关键！）

`crew.jsonc` 中的名称必须与文件、任务引用完全一致：

| 位置 | 名称 | 要求 |
|------|------|------|
| `agents: ["researcher"]` | researcher | 加载 `agents/researcher.jsonc` |
| `tasks[].agent: "researcher"` | researcher | 指向 Agent 名称 |
| `researcher.jsonc` 文件 | `name` 字段 | 应与引用一致 |

## 关键 API 速查

| 操作 | API |
|------|-----|
| Flow 起始步骤 | `@start()` |
| 监听上一步 | `@listen(previous_method)` |
| 运行 Flow | `flow.kickoff()` |
| 状态管理 | `self.state.xxx`（Pydantic Model） |
| Crew 执行 | `crew.kickoff(inputs={...})` |
| 任务输出到文件 | `"output_file": "output/report.md"` |
