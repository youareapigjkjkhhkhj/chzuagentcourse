# 15 - 测试与训练

本篇目标：掌握 CrewAI 的 **测试（Testing）** 和 **训练（Training）** 机制，确保你的 Crew 达到预期性能，并通过人工反馈持续优化。

## 15.1 测试（Testing）

### 概述

**测试**评估 Crew 的性能是否符合预期。CrewAI 内置测试能力，可按指定次数运行 Crew 并给出详细的**性能指标**。

### 使用 CLI 测试

```bash
# 默认测试（2 次迭代，gpt-4o-mini 评估）
crewai test

# 指定迭代次数和模型
crewai test -n 5 -m gpt-4o
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `n_iterations` | 测试迭代次数 | 2 |
| `model` | 评估模型 | `gpt-4o-mini` |

> ⚠️ 目前测试仅支持 **OpenAI** 作为评估提供商。

### 测试输出

测试结束后，显示**性能指标表格**：

```
┌──────────────────────────────────────────────────────────────────┐
│ Task            │  Run 1  │  Run 2  │  Average  │  Total       │
├──────────────────────────────────────────────────────────────────┤
│ research_ai     │  0.85   │  0.87   │   0.86    │  1.72        │
│ write_report    │  0.78   │  0.82   │   0.80    │  1.60        │
├──────────────────────────────────────────────────────────────────┤
│ Crew Overall    │  0.82   │  0.85   │   0.83    │  3.32        │
└──────────────────────────────────────────────────────────────────┘
```

每个任务和 Crew 整体的平均得分说明了性能水平。

### 编程方式测试

```python
from crewai import Crew

result = crew.test(
    n_iterations=5,
    model="gpt-4o",
    inputs={"topic": "AI"},
)
```

## 15.2 训练（Training）

### 概述

**训练**通过 CLI 运行，利用技术优化 Agent 性能，并结合**人工反馈**（human feedback）：

- Agent 理解改进、决策能力和问题解决能力
- 训练基于 `human_input` 任务提供交互式反馈

### CLI 训练

```bash
# 默认训练 5 次迭代
crewai train

# 指定次数和文件
crewai train -n 10 -f my_training_data.pkl
```

### 编程方式训练

```python
from crewai import Crew

try:
    crew.train(
        n_iterations=10,
        filename="trained_agents_data.pkl",
        inputs={"topic": "AGI"},
    )
except Exception as e:
    print(f"训练失败: {e}")
```

### 训练数据流

训练期间，系统为每个 Agent 记录：

| 数据 | 说明 |
|------|------|
| `initial_output` | Agent 的**首次回答** |
| `human_feedback` | 你被提示时给出的**内联反馈** |
| `improved_output` | 反馈后 Agent 的**改进回答** |

数据存储在工作文件中：`training_data.pkl`，按 Agent 内部 ID 和迭代索引。

**训练期间行为**：
- Agent 自动将你之前的人工反馈**附加到 prompt** 中
- 强制执行这些指令到后续尝试
- 任务需设置 `human_input = true`，非交互环境会阻塞等待输入

### 训练完成后

`train(...)` 完成后，CrewAI 评估每个 Agent 的收集数据，产出一份**整合结果**：

- **suggestions**：从你的人类反馈中提炼出的清晰可操作指令
- 这些建议被**持久化**，供后续运行使用

### 如何利用训练后的数据

Agent 使用训练产物的两种方式：
1. **训练期间**：将你的反馈合并到 prompt 中强制执行
2. **训练之后**：用整合的 suggestions 引导 Agent 的后续表现

## 15.3 在 JSONC 项目中使用

```jsonc
{
  "agents": ["researcher"],
  "tasks": [
    {
      "name": "research_task",
      "description": "...",
      "expected_output": "...",
      "agent": "researcher",
      "human_input": true   // 训练/测试时需要人工反馈
    }
  ]
}
```

## 15.4 实操对比：测试 vs 训练

| 维度 | 测试（Test） | 训练（Train） |
|------|-------------|---------------|
| 目的 | 评估当前性能 | 通过反馈改进性能 |
| 输入 | 无人工干预 | 需要人工反馈 |
| 交互性 | 自动运行 | 交互式（需 `human_input=true`） |
| 产出 | 指标评分表 | 训练数据 + suggestions |
| 迭代次数 | 默认 2 | 默认 5 |
| 评估模型 | `gpt-4o-mini` | 无（使用反馈本身） |

## 15.5 最佳实践

1. **先测后炼**：先用 `crewai test` 评估基线，再针对性训练
2. **多迭代训练**：训练 5-10 次迭代，每次提供高质量反馈
3. **分离测试/训练数据**：不要用测试场景数据做训练
4. **注意交互环境**：训练需要 `human_input=true`，确保在交互环境运行
5. **保存训练产物**：定期备份 `trained_agents_data.pkl`

## 关键 API 速查

| API | 用途 |
|-----|------|
| `crewai test -n 5 -m gpt-4o` | CLI 测试 |
| `crew.kickoff(inputs)` | 带参数执行 |
| `crewai train -n 10` | CLI 训练 |
| `crew.train(n_iterations=)` | 编程训练 |
| `Task(human_input=True)` | 允许人工反馈 |
| `trained_agents_data.pkl` | 训练数据文件 |
