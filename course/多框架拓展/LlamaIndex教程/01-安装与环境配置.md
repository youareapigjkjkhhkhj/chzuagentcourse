# 01 - 安装与环境配置

本篇目标：正确安装 LlamaIndex（理解伞包 vs 命名空间包）、锁版本、配置 API Key，并了解本地模型路线。

## 1.1 前置要求

| 项 | 要求 |
|----|------|
| Python | **>=3.10, <4.0**（官方包硬要求） |
| API Key | 使用 OpenAI 时设 `OPENAI_API_KEY`；也可用其他远程或本地模型 |
| 磁盘/内存 | 仅用 API 的 RAG 很轻量；本地 embedding/LLM 取决于模型体积 |

官方说明：`llama-index-core` 预置了 NLTK 与 tiktoken 数据，运行时不会再去联网下载这些资源。

## 1.2 安装方式

### 方式一：starter bundle（推荐入门）

```bash
pip install llama-index
```

官方说明：这个伞包会拉取

- `llama-index-core`
- `llama-index-llms-openai`
- `llama-index-embeddings-openai`
- `llama-index-readers-file`

### 方式二：按需安装（生产推荐）

```bash
# 不用 OpenAI：核心 + 文件读取 + 本地模型
pip install llama-index-core llama-index-readers-file \
            llama-index-llms-ollama llama-index-embeddings-huggingface

# 需要向量数据库时再装对应包
pip install llama-index-vector-stores-postgres   # 举例
```

命名规律：

| 类别 | 包名前缀 |
|------|----------|
| LLM | `llama-index-llms-<provider>` |
| Embedding | `llama-index-embeddings-<provider>` |
| 数据读取 | `llama-index-readers-<source>` |
| 向量存储 | `llama-index-vector-stores-<db>` |
| 工具/代理 | `llama-index-tools-<name>` |

## 1.3 锁版本

```bash
# 锁定伞包
pip install "llama-index==0.14.24"

# 或更精细：核心 + 各集成包分别锁定
pip install "llama-index-core==0.14.24" "llama-index-llms-openai==0.14.24"
```

> 生产建议同时锁定伞包和你直接 import 的包，避免伞包升级导致行为漂移。

## 1.4 虚拟环境（强烈建议）

```bash
# Windows PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip setuptools wheel
pip install llama-index
```

## 1.5 配置 API Key

```bash
# Windows PowerShell
$env:OPENAI_API_KEY="sk-..."

# Windows CMD
set OPENAI_API_KEY=sk-...

# macOS / Linux
export OPENAI_API_KEY="sk-..."
```

在代码里用 `.env`（需 `pip install python-dotenv`）：

```python
from dotenv import load_dotenv
load_dotenv()
```

## 1.6 验证安装

放一个 `.txt` / `.md` / `.pdf` 到 `./data`，然后：

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

documents = SimpleDirectoryReader("data").load_data()
index = VectorStoreIndex.from_documents(documents)
query_engine = index.as_query_engine()
print(query_engine.query("What is this document about?"))
```

> 首次运行会调用 Embedding API（默认 OpenAI）生成向量，需要联网与余额。

## 1.7 本地模型路线（无需 API Key）

```bash
# Ollama（本地服务，需先启动 ollama）
pip install llama-index-llms-ollama llama-index-embeddings-ollama

# 或 HuggingFace 本地 embedding
pip install llama-index-embeddings-huggingface
```

详见 [06-模型配置Settings.md](06-模型配置Settings.md)。

## 1.8 升级与卸载

```bash
pip install -U llama-index
pip uninstall llama-index -y
```

## 关键命令速查

| 命令 | 说明 |
|------|------|
| `pip install llama-index` | 安装 starter bundle |
| `pip install "llama-index==0.14.24"` | 锁定版本 |
| `pip install llama-index-core llama-index-readers-file ...` | 按需组合 |
| `export OPENAI_API_KEY=...` | 配置密钥 |

## 注意事项

- 不要在系统 Python 上直接安装，务必用虚拟环境。
- 不要混用不同版本来源的包（pip 与 poetry 混装易冲突）。
- 包名是 `llama-index`（短横线），导入是 `llama_index`（下划线）。
- 从源码安装（贡献者路线）用 Poetry：`pip install -e llama-index-core`。
