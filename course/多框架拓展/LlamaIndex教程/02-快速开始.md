# 02 - 快速开始

本篇目标：用官方著名的 **5 行 starter** 跑通第一个 RAG 应用，并给出远程 API 与本地模型两条完整路线。

## 2.1 前置准备

```bash
pip install llama-index
export OPENAI_API_KEY="sk-..."     # 官方示例默认用 OpenAI
```

## 2.2 官方 5 行 starter

把文档放进 `./data` 目录，然后：

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

documents = SimpleDirectoryReader("data").load_data()
index = VectorStoreIndex.from_documents(documents)
query_engine = index.as_query_engine()

response = query_engine.query("Some question about the data should go here")
print(response)
```

逐行解读：

| 行 | 作用 | 对应 RAG 阶段 |
|----|------|---------------|
| `SimpleDirectoryReader("data").load_data()` | 读取目录下所有支持的文件 → `Document` 列表 | **Loading** |
| `VectorStoreIndex.from_documents(documents)` | 切分成 `Node` → 生成 embedding → 建索引 | **Indexing** |
| `index.as_query_engine()` | 得到一个端到端问答接口 | **Querying** 准备 |
| `query_engine.query(...)` | 检索相关节点 + 交给 LLM 合成答案 | **Querying** |
| `print(response)` | 输出答案 | — |

## 2.3 完整可运行脚本

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

# 1) 加载数据
documents = SimpleDirectoryReader("data").load_data()
print(f"Loaded {len(documents)} document(s)")

# 2) 建索引（会调用 Embedding API）
index = VectorStoreIndex.from_documents(documents)

# 3) 建查询引擎
query_engine = index.as_query_engine()

# 4) 多轮提问
for question in ["这份文档讲了什么？", "有哪些关键结论？"]:
    response = query_engine.query(question)
    print(f"Q: {question}")
    print(f"A: {response}\n")
```

## 2.4 避免重复付费：索引持久化

每次运行都重建索引会重复调用 Embedding。持久化一次，之后直接加载：

```python
from llama_index.core import (
    VectorStoreIndex,
    SimpleDirectoryReader,
    StorageContext,
    load_index_from_storage,
)

PERSIST_DIR = "./storage"


def build_index():
    documents = SimpleDirectoryReader("data").load_data()
    index = VectorStoreIndex.from_documents(documents)
    index.storage_context.persist(persist_dir=PERSIST_DIR)   # 落盘
    return index


def load_index():
    storage_context = StorageContext.from_defaults(persist_dir=PERSIST_DIR)
    return load_index_from_storage(storage_context)
```

详见 [08-存储与持久化.md](08-存储与持久化.md)。

## 2.5 本地模型路线（无 API Key）

官方也提供"在笔记本上跑"的起步方式：

```bash
# 先启动 Ollama 服务（https://ollama.com），并拉取模型
ollama pull llama3.2
ollama pull nomic-embed-text
```

```bash
pip install llama-index-core llama-index-readers-file \
            llama-index-llms-ollama llama-index-embeddings-ollama
```

```python
from llama_index.core import Settings, VectorStoreIndex, SimpleDirectoryReader
from llama_index.llms.ollama import Ollama
from llama_index.embeddings.ollama import OllamaEmbedding

Settings.llm = Ollama(model="llama3.2", request_timeout=120.0)
Settings.embed_model = OllamaEmbedding(model_name="nomic-embed-text")

documents = SimpleDirectoryReader("data").load_data()
index = VectorStoreIndex.from_documents(documents)

print(index.as_query_engine().query("这份文档讲了什么？"))
```

> 官方提醒：Agents 需要能力较强的模型，小模型可靠性会下降。

## 2.6 流式输出

```python
query_engine = index.as_query_engine(streaming=True)
response = query_engine.query("总结一下文档要点")
response.print_response_stream()
```

## 2.7 查看检索到的来源

```python
response = query_engine.query("关键结论是什么？")

for node in response.source_nodes:
    print("-" * 40)
    print("score:", node.score)
    print("file :", node.metadata.get("file_name"))
    print("text :", node.text[:200])
```

这是调试 RAG 质量最常用的手段——**先看召回，再看生成**。

## 关键 API 速查

| API | 说明 |
|-----|------|
| `SimpleDirectoryReader(path).load_data()` | 从目录加载文档 |
| `VectorStoreIndex.from_documents(docs)` | 建向量索引（含切分+嵌入） |
| `index.as_query_engine()` | 转查询引擎 |
| `query_engine.query(str)` | 提问，返回 `Response` |
| `index.as_query_engine(streaming=True)` + `response.print_response_stream()` | 流式输出 |
| `response.source_nodes` | 查看召回节点与分数 |

## 注意事项

- 首次 `from_documents` 会批量调用 Embedding API，文档多时会较慢——请持久化。
- 默认 LLM/Embedding 都是 OpenAI；切换见 [06-模型配置Settings.md](06-模型配置Settings.md)。
- 脚本中若用 async API，需要 `asyncio.run(main())`。
