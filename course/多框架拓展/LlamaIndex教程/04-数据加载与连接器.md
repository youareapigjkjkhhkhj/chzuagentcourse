# 04 - 数据加载与连接器

本篇目标：把各种来源的数据读进 LlamaIndex——本地文件目录、单个文件、程序化文本，以及 LlamaHub 生态的上百种连接器。

## 4.1 前置准备

```bash
pip install llama-index                       # 已含 llama-index-readers-file
```

## 4.2 SimpleDirectoryReader（最常用）

读取整个目录，自动按扩展名选择解析器：

```python
from llama_index.core import SimpleDirectoryReader

documents = SimpleDirectoryReader("data").load_data()
print(f"Loaded {len(documents)} document(s)")
print(documents[0].text[:200])
print(documents[0].metadata)
```

### 常用参数

| 参数 | 说明 |
|------|------|
| `input_dir` / `input_files` | 目录路径，或显式指定文件列表 |
| `recursive` | 是否递归子目录（默认 False） |
| `required_exts` | 只读取指定扩展名，如 `[".pdf", ".md"]` |
| `exclude` | 排除的文件/目录 |
| `file_extractor` | 为指定扩展名指定解析器（如 PDF 用 LlamaParse） |
| `num_files_limit` | 限制读取文件数（调试用） |
| `filename_as_id` | 用文件名作为 doc id |

```python
reader = SimpleDirectoryReader(
    input_dir="data",
    recursive=True,
    required_exts=[".pdf", ".md", ".txt", ".docx"],
    exclude=["**/draft/**"],
)
documents = reader.load_data()
```

### 惰性/分块加载（大目录）

```python
# 逐文件迭代，避免一次性占满内存
for docs in SimpleDirectoryReader("data", recursive=True).iter_data():
    index.insert_nodes(...)   # 或逐个处理
```

## 4.3 支持的常见格式

`llama-index-readers-file` 提供（部分）：PDF、DOCX、PPTX、XLSX、CSV、Markdown、HTML、JSON、图片（配多模态）、音视频（转录）、EPUB、Notebook(.ipynb) 等。

需要其他格式就装对应 reader 包：

```bash
pip install llama-index-readers-notion     # Notion
pip install llama-index-readers-google     # Google Docs / Drive
pip install llama-index-readers-web        # 网页抓取
pip install llama-index-readers-github     # GitHub 仓库
pip install llama-index-readers-database   # 数据库
```

## 4.4 从字符串/程序化数据构造 Document

数据已经在内存里时，直接构造：

```python
from llama_index.core import Document, VectorStoreIndex

text_list = ["LlamaIndex 是数据编排框架。", "RAG 让 LLM 用上你的数据。"]
documents = [Document(text=t, metadata={"source": "manual"}) for t in text_list]

index = VectorStoreIndex.from_documents(documents)
```

## 4.5 复杂文档：LlamaParse

扫描件、嵌套表格、图表、手写体等复杂 PDF，普通解析器效果差，官方推荐 **LlamaParse**（基于 VLM 的文档解析）：

```bash
pip install llama-parse
```

```python
from llama_parse import LlamaParse
from llama_index.core import SimpleDirectoryReader

parser = LlamaParse(result_type="markdown")   # 需要 LLAMA_CLOUD_API_KEY

file_extractor = {".pdf": parser}
documents = SimpleDirectoryReader("data", file_extractor=file_extractor).load_data()
```

> LlamaParse 每月有免费额度（详见 [17-评估与部署.md](17-评估与部署.md) 与官方定价）。

## 4.6 LlamaHub：连接器市场

[LlamaHub](https://llamahub.ai) 收录了大量社区与官方连接器（Reader）、工具（Tools）、向量存储与 LLM 集成。使用方式通常是：

```bash
pip install llama-index-readers-<name>
```

然后按该包的文档导入对应 Reader 类。

## 4.7 加载后的下一步

`load_data()` 返回的是 `Document` 列表；索引时会被切分成 `Node`（见 [05-文档节点与切分.md](05-文档节点与切分.md)）。

## 关键 API 速查

| API | 说明 |
|-----|------|
| `SimpleDirectoryReader(path).load_data()` | 加载目录为 Document 列表 |
| `SimpleDirectoryReader(..., recursive=, required_exts=, exclude=)` | 过滤与递归 |
| `reader.iter_data()` | 惰性迭代 |
| `Document(text=, metadata=)` | 手工构造文档 |
| `file_extractor={".pdf": parser}` | 指定解析器（如 LlamaParse） |

## 注意事项

- 默认不递归子目录——需要子目录内容请显式 `recursive=True`。
- 二进制/不支持的格式会被跳过，注意检查 `len(documents)`。
- 复杂 PDF 优先用 LlamaParse，别指望纯文本抽取能保住表格与版式。
- 生产管线建议把"解析产物"也缓存下来，避免重复解析付费。
