# 10 - 节点后处理与重排

本篇目标：掌握检索之后的加工环节——过滤、重排（Rerank）、上下文替换与裁剪，这是提升 RAG 质量性价比最高的一步。

## 10.1 前置准备

```bash
pip install llama-index
```

## 10.2 什么是 Node Postprocessor（官方定义）

> A node postprocessor takes in a set of retrieved nodes and applies transformations, filtering, or re-ranking logic to them.

位置在检索器之后、响应合成之前：

```
查询 → Retriever（召回 N 条）→ Postprocessors（过滤/重排/裁剪）→ Response Synthesizer（生成）
```

## 10.3 相似度阈值过滤

```python
from llama_index.core.postprocessor import SimilarityPostprocessor

postprocessor = SimilarityPostprocessor(similarity_cutoff=0.7)

query_engine = index.as_query_engine(
    similarity_top_k=10,
    node_postprocessors=[postprocessor],
)
```

先多召回（top_k=10），再用阈值剔除低分节点——比直接减小 top_k 更稳健。

## 10.4 关键词过滤

```python
from llama_index.core.postprocessor import KeywordNodePostprocessor

postprocessor = KeywordNodePostprocessor(
    required_keywords=["定价", "折扣"],
    exclude_keywords=[" deprecated ", "草稿"],
)
```

## 10.5 重排 Rerank（效果提升最明显）

Rerank 用**交叉编码器**（cross-encoder）对"查询-候选"对逐一打分，精度远高于向量余弦。

```bash
# 本地 BAAI rerank 模型
pip install llama-index-postprocessor-flag-embedding-reranker
```

```python
from llama_index.postprocessor.flag_embedding_reranker import FlagEmbeddingReranker

reranker = FlagEmbeddingReranker(
    model="BAAI/bge-reranker-large",
    top_n=3,                 # 重排后保留 3 条
)

query_engine = index.as_query_engine(
    similarity_top_k=10,
    node_postprocessors=[reranker],
)
response = query_engine.query("Q3 定价策略有哪些调整？")
```

其他选择：

| 包 | 模型/服务 |
|----|-----------|
| `llama-index-postprocessor-cohere-rerank` | Cohere Rerank API |
| `llama-index-postprocessor-flag-embedding-reranker` | 本地 BGE reranker |
| `llama-index-postprocessor-bge-rerank` | 本地 BGE（另一实现） |
| `llama-index-postprocessor-colbert-rerank` | ColBERT |

## 10.6 长上下文重排（解决"中间迷失"）

LLM 对长上下文中部内容关注度较低。`LongContextReorder` 把最相关的节点放到首尾：

```python
from llama_index.core.postprocessor import LongContextReorder

query_engine = index.as_query_engine(
    similarity_top_k=8,
    node_postprocessors=[LongContextReorder()],
)
```

## 10.7 句子窗口替换（小窗口检索、大窗口生成）

配合 `SentenceWindowNodeParser`：

```python
from llama_index.core.node_parser import SentenceWindowNodeParser
from llama_index.core.postprocessor import MetadataReplacementPostProcessor

# 索引阶段：每个节点只存一句，但 metadata 里存前后窗口
node_parser = SentenceWindowNodeParser.from_defaults(
    window_size=3,
    window_metadata_key="window",
    original_text_metadata_key="original_sentence",
)

# 查询阶段：召回单句后，把文本替换为更宽的窗口
postprocessor = MetadataReplacementPostProcessor(target_metadata_key="window")

query_engine = index.as_query_engine(node_postprocessors=[postprocessor])
```

## 10.8 上下文裁剪

```python
from llama_index.core.postprocessor import SentenceEmbeddingOptimizer

postprocessor = SentenceEmbeddingOptimizer(
    embed_model=Settings.embed_model,
    percentile_cutoff=0.5,       # 去掉相关度低于分位的句子
    threshold_cutoff=0.7,
)
```

## 10.9 组合多个后处理器

顺序很重要：通常**先重排/过滤，再重排顺序/裁剪**。

```python
from llama_index.core.postprocessor import (
    SimilarityPostprocessor,
    LongContextReorder,
)

query_engine = index.as_query_engine(
    similarity_top_k=12,
    node_postprocessors=[
        SimilarityPostprocessor(similarity_cutoff=0.65),
        reranker,                 # 精排
        LongContextReorder(),     # 位置优化
    ],
)
```

## 10.10 与低层 API 组合

检索器 + 后处理器 + 响应合成器可手工组装（见 [11](11-响应合成与提示词.md)、[12](12-查询引擎QueryEngine.md)）：

```python
from llama_index.core import get_response_synthesizer
from llama_index.core.query_engine import RetrieverQueryEngine

retriever = index.as_retriever(similarity_top_k=10)
response_synthesizer = get_response_synthesizer()

query_engine = RetrieverQueryEngine(
    retriever=retriever,
    response_synthesizer=response_synthesizer,
    node_postprocessors=[SimilarityPostprocessor(similarity_cutoff=0.7)],
)
```

## 关键 API 速查

| API | 说明 |
|-----|------|
| `SimilarityPostprocessor(similarity_cutoff=)` | 相似度阈值过滤 |
| `KeywordNodePostprocessor(required_keywords=, exclude_keywords=)` | 关键词过滤 |
| `FlagEmbeddingReranker(model=, top_n=)` | 本地 BGE rerank |
| `LongContextReorder()` | 长上下文位置重排 |
| `MetadataReplacementPostProcessor(target_metadata_key=)` | 窗口替换 |
| `SentenceEmbeddingOptimizer(...)` | 句子级裁剪 |
| `index.as_query_engine(node_postprocessors=[...])` | 挂载后处理器 |

## 注意事项

- 先**加大多召回**，再用后处理器筛选，比一开始就小 top_k 效果好。
- Rerank 会增加延迟（每个候选都要过模型），top_k 不宜过大（10–20 为宜）。
- 本地 rerank 模型首次会下载权重；生产要考虑显存/内存与并发。
- 中文场景推荐 BGE 系列（`bge-reranker-large`、`bge-reranker-v2-m3`）。
