# 11 - 响应合成与提示词

本篇目标：掌握 RAG 的最后一环——**Response Synthesizer** 如何把查询与检索到的文本块变成答案，以及如何定制提示词与引用。

## 11.1 前置准备

```bash
pip install llama-index
```

## 11.2 什么是 Response Synthesizer（官方定义）

> A response synthesizer generates a response from an LLM, using a user query and a given set of retrieved text chunks.

流程：拿到检索结果 → 组织成提示词 → 调用 LLM → 返回 `Response`（含 `response` 文本与 `source_nodes`）。

## 11.3 response_mode：合成策略

```python
query_engine = index.as_query_engine(response_mode="compact")
```

| 模式 | 行为 | 适用 |
|------|------|------|
| `compact`（默认） | 尽可能把多个 chunk 塞进一次 LLM 调用，超出则分多次再合并 | 通用、性价比高 |
| `refine` | 逐个 chunk 迭代精炼答案 | 答案质量高，但调用次数多、慢 |
| `tree_summarize` | 自底向上树形归纳 | 长文档摘要、需要全局视角 |
| `simple_summarize` | 截断到单个 LLM 调用能容纳的长度后总结 | 快速但可能丢信息 |
| `no_text` | 只返回检索到的节点，不调用 LLM | 纯检索/调试 |
| `accumulate` | 每个 chunk 单独生成答案再拼接 | 需要逐段观点 |
| `compact_accumulate` | compact 与 accumulate 结合 | 折中 |

```python
# 摘要场景
summary_engine = index.as_query_engine(response_mode="tree_summarize")

# 只想看召回了什么（不花钱调用 LLM）
retrieval_only = index.as_query_engine(response_mode="no_text")
```

## 11.4 定制提示词

```python
from llama_index.core import PromptTemplate
from llama_index.core import get_response_synthesizer

qa_prompt_tmpl = PromptTemplate(
    "上下文信息如下。\n"
    "---------------------\n"
    "{context_str}\n"
    "---------------------\n"
    "仅依据上述上下文，用简体中文回答用户问题。\n"
    "若上下文中没有答案，请明确回答“资料中未提及”，不要编造。\n"
    "问题：{query_str}\n"
    "答案："
)

synthesizer = get_response_synthesizer(
    text_qa_template=qa_prompt_tmpl,
    response_mode="compact",
)

query_engine = index.as_query_engine(response_synthesizer=synthesizer)
print(query_engine.query("文档中说明了哪些限制条件？"))
```

提示词中的占位符：

| 占位符 | 含义 |
|--------|------|
| `{context_str}` | 检索到的上下文文本 |
| `{query_str}` | 用户问题 |

对 `refine` / `tree_summarize` 模式，还可定制 `refine_template` 与 `summary_template`。

## 11.5 引用与溯源

普通 `query` 已经带 `source_nodes`，可自行渲染来源：

```python
response = query_engine.query("关键结论是什么？")

print(response)
print("\n来源：")
for i, node in enumerate(response.source_nodes, 1):
    meta = node.metadata
    print(f"[{i}] {meta.get('file_name', 'unknown')} p.{meta.get('page_label', '-')} (score={node.score:.3f})")
```

### CitationQueryEngine（逐句引用）

```python
from llama_index.core.query_engine import CitationQueryEngine

citation_engine = CitationQueryEngine.from_args(
    index,
    similarity_top_k=3,
    citation_chunk_size=512,
)

response = citation_engine.query("文档的核心观点是什么？")
print(response)

for src in response.source_nodes:
    print("cited:", src.node.metadata.get("file_name"))
```

它会在答案中插入引用标记，并只返回真正被引用到的来源。

## 关键 API 速查

| API | 说明 |
|-----|------|
| `index.as_query_engine(response_mode=...)` | 指定合成策略 |
| `get_response_synthesizer(text_qa_template=, response_mode=)` | 低层构造 |
| `PromptTemplate("...{context_str}...{query_str}...")` | 提示词模板 |
| `response.source_nodes` | 召回来源与分数 |
| `CitationQueryEngine.from_args(index, ...)` | 带引用的查询引擎 |
| `query_engine.query(...)`, `streaming=True` + `print_response_stream()` | 流式 |

## 注意事项

- 事实性问答建议 `temperature=0` 并在提示词中明确"不允许编造"。
- `refine`/`tree_summarize` 会显著增加 LLM 调用次数与成本。
- 引用要基于 `source_nodes` 的真实元数据，不要靠 LLM 自己编文件名。
- 提示词改动后要用固定问题集做回归（见 [17-评估与部署.md](17-评估与部署.md)）。
