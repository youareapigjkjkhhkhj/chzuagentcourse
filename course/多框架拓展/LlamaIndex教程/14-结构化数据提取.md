# 14 - 结构化数据提取

本篇目标：从非结构化文档（PDF、网页、扫描件）中抽取**类型安全的结构化数据**——Pydantic 抽取器与官方 LlamaExtract 服务。

## 14.1 前置准备

```bash
pip install llama-index
```

## 14.2 为什么需要结构化提取（官方定义）

> Pydantic extractors allow you to specify a precise data structure to extract from your data and use LLMs to fill in the missing pieces in a type-safe way. This is useful for extracting structured data from unstructured sources like PDFs, websites, and more, and is **key to automating workflows**.

典型场景：发票字段抽取、合同要点提取、简历解析、研究报告结构化、商品参数表化。

## 14.3 定义 Schema

```python
from typing import List, Optional
from pydantic import BaseModel, Field


class LineItem(BaseModel):
    """发票行项目"""
    name: str = Field(description="商品或服务名称")
    quantity: int = Field(description="数量")
    unit_price: float = Field(description="单价")


class Invoice(BaseModel):
    """发票"""
    invoice_no: str = Field(description="发票号码")
    issue_date: str = Field(description="开票日期，YYYY-MM-DD")
    seller: str = Field(description="销售方名称")
    total_amount: float = Field(description="价税合计金额")
    items: List[LineItem] = Field(description="行项目列表")
    currency: Optional[str] = Field(default="CNY", description="币种")
```

> `Field(description=...)` 的描述会直接进入提示词，写得越清楚抽取越准。

## 14.4 用结构化 LLM 直接抽取

```python
from llama_index.llms.openai import OpenAI

llm = OpenAI(model="gpt-4o-mini")
sllm = llm.as_structured_llm(Invoice)      # 绑定输出类型

response = await sllm.acomplete(
    "发票号 INV-2025-0817，开票日期 2025-08-17，销售方：示例科技有限公司。"
    "包含两项：咨询服务 2 项 单价 1500；培训服务 1 项 单价 3000。"
    "价税合计 6000 元。"
)

invoice = response.raw        # Invoice 实例（已校验）
print(invoice.invoice_no, invoice.total_amount)
for item in invoice.items:
    print(" -", item.name, item.quantity, item.unit_price)
```

## 14.5 结合 RAG：从文档库抽取

把 `output_cls` 传给查询引擎，检索到的上下文会自动喂给结构化输出：

```python
query_engine = index.as_query_engine(
    output_cls=Invoice,
    similarity_top_k=3,
)

response = query_engine.query("从合同附件中提取发票信息")
invoice: Invoice = response.response        # Pydantic 对象
print(invoice.model_dump())
```

## 14.6 低层：StructuredLLM + 自定义提示

```python
from llama_index.core import PromptTemplate
from llama_index.llms.openai import OpenAI

sllm = OpenAI(model="gpt-4o-mini").as_structured_llm(Invoice)

prompt = PromptTemplate(
    "请从以下合同文本中抽取发票信息；缺失字段留空。\n"
    "---------------------\n{text}\n---------------------\n"
)

resp = await sllm.acomplete(prompt.format(text=contract_text))
print(resp.raw.model_dump_json(indent=2))
```

## 14.7 批量抽取与容错

```python
import asyncio
from pydantic import ValidationError

sllm = OpenAI(model="gpt-4o-mini").as_structured_llm(Invoice)


async def extract_one(text: str) -> Invoice | None:
    try:
        resp = await sllm.acomplete(text)
        return resp.raw
    except (ValidationError, Exception) as e:
        print("extraction failed:", e)
        return None


texts = [t1, t2, t3]
results = await asyncio.gather(*[extract_one(t) for t in texts])
```

## 14.8 复杂文档：先解析再抽取

复杂 PDF（嵌套表格、图表、手写）建议先用 LlamaParse 得到干净 Markdown/文本，再结构化抽取：

```bash
pip install llama-parse
```

```python
from llama_parse import LlamaParse

parser = LlamaParse(result_type="markdown")
documents = parser.load_data("scan_invoice.pdf")

text = "\n".join(d.text for d in documents)
invoice = (await sllm.acomplete(text)).raw
```

## 关键 API 速查

| API | 说明 |
|-----|------|
| `pydantic.BaseModel` + `Field(description=)` | 定义抽取 schema |
| `llm.as_structured_llm(Cls)` | 绑定结构化输出类型 |
| `response.raw` | 取回 Pydantic 对象 |
| `index.as_query_engine(output_cls=Cls)` | RAG + 结构化输出 |
| `obj.model_dump()` / `model_dump_json()` | 导出为字典/JSON |
| `LlamaParse(result_type="markdown")` | 复杂文档解析 |

## 注意事项

- schema 字段的 `description` 直接影响抽取质量，务必写清楚单位、格式、枚举含义。
- 嵌套结构能提升一致性，但过深会增加失败率——控制在 2–3 层。
- 抽取失败要显式捕获（`ValidationError`），不要让整个批处理中断。
- 对关键字段（金额、日期）建议加业务校验（如日期可解析、金额非负）。
