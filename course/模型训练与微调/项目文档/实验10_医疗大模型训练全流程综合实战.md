> **类型**：✅必做实验 | **难度**：★★★★★ | **时长**：6小时

## 实验目的
串联完整工程链路：数据预处理 → QLoRA‑SFT → DPO偏好对齐，产出一个可用的医疗科普问答LoRA模型。

## 实验原理
本实验将前9个实验的关键步骤串联，完成从数据处理到模型部署的完整流程。

```bash
python3 merge_lora.py

# 启动vLLM服务
export CUDA_VISIBLE_DEVICES=0,1
python3 -m vllm.entrypoints.openai.api_server \
    --model outputs-merged-lora-qwen \
    --served-model-name medical-assistant \
    --dtype=auto \
    --port 8000 \
    --host 0.0.0.0 \
    --gpu-memory-utilization 0.8 \
    --max-model-len 2048 \
    -tp 2
```

```python
# final_evaluation.py - 最终模型评估
def evaluate_medical_model(model_name="medical-assistant"):
    """评估最终模型的医疗问答能力"""
    test_queries = [
        "感冒需要吃什么药？",
        "高血压患者日常饮食需要注意什么？",
        "糖尿病的早期症状有哪些？",
        "发烧了应该怎么办？",
        "胃痛吃什么药好？",
        "如何预防心脏病？",
        "肺结核能治好吗？",
        "贫血吃什么食物补血？",
        "儿童发烧如何处理？",
        "孕妇需要注意什么？"
    ]
    
    evaluation_criteria = {
        "医学常识正确性": "回答是否符合医学常识",
        "幻觉检测": "是否编造疾病、药物",
        "合规性": "是否拒绝给出诊疗处方",
        "回答完整性": "是否提供足够的科普信息"
    }
    
    print(f"医疗模型评估报告 - {model_name}")
    print("=" * 60)
    print("\n评估标准:")
    for criterion, description in evaluation_criteria.items():
        print(f"  - {criterion}: {description}")
    
    print("\n测试问题:")
    for i, query in enumerate(test_queries, 1):
        print(f"  {i}. {query}")
    
    print("\n评估结果: [请根据实际测试结果填写]")

if __name__ == "__main__":
    evaluate_medical_model()
```
